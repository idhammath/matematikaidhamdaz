Berikut adalah soal tingkat ... materi Limit

Diberikan barisan fungsi menara pangkat: \[f_n(x)=\underbrace{x^{x^{x^{\cdot^{\cdot^{\cdot^x}}}}}}_{\text{ada }n\text{ buah }x}\] Tentukan nilai dari: \[\lim_{x\to0^+}\left(f_{2016}(x)+f_{2017}(x)+f_{2018}(x)\right)\]

Matematika Zone Id
Pembahasan:

Mari kita selidiki perilaku nilai limit \(\lim_{x\to0^+}f_n(x)\) untuk beberapa nilai \(n\) awal:

1. Untuk \(n = 1\):

\[ \lim_{x\to0^+} f_1(x) = \lim_{x\to0^+} x = 0 \]

2. Untuk \(n = 2\):

\[ \lim_{x\to0^+} f_2(x) = \lim_{x\to0^+} x^x \] Misalkan \(y = x^x\), maka \(\ln y = x\ln x\). Menggunakan aturan L'Hôpital: \[ \lim_{x\to0^+} x\ln x = \lim_{x\to0^+} \dfrac{\ln x}{\frac{1}{x}} = \lim_{x\to0^+} \dfrac{\frac{1}{x}}{-\frac{1}{x^2}} = \lim_{x\to0^+} (-x) = 0 \] Sehingga \(\lim_{x\to0^+} x^x = e^0 = 1\).

3. Untuk \(n = 3\):

\[ \lim_{x\to0^+} f_3(x) = \lim_{x\to0^+} x^{f_2(x)} = \left(\lim_{x\to0^+} x\right)^{\lim_{x\to0^+} f_2(x)} = 0^1 = 0 \]

4. Untuk \(n = 4\):

\[ \lim_{x\to0^+} f_4(x) = \lim_{x\to0^+} x^{f_3(x)} = \lim_{x\to0^+} x^0 = 1 \]

Secara umum melalui induksi matematika:

  • Jika \(n\) genap, maka \(\displaystyle\lim_{x\to0^+} f_n(x) = 1\)
  • Jika \(n\) ganjil, maka \(\displaystyle\lim_{x\to0^+} f_n(x) = 0\)

Karena \(2016\) dan \(2018\) adalah bilangan genap, sedangkan \(2017\) adalah bilangan ganjil, maka:

\[ \begin{aligned} \lim_{x\to0^+}\left(f_{2016}(x)+f_{2017}(x)+f_{2018}(x)\right) &= 1 + 0 + 1\\[3.7pt] &= 2 \end{aligned} \]
Jadi, \(\displaystyle\lim_{x\to0^+}\left(f_{2016}(x)+f_{2017}(x)+f_{2018}(x)\right)=2\).
