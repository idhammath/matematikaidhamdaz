ALTERNATIF PENYELESAIAN
Substitusikan x = 0,
\(\begin{aligned} 2(0)^4+3(0)^3-9(0)+4&=\left(2(0)^2-3(0)+1\right)\left(0^2+p(0)+q\right)\\ 4&=\left(1\right)\left(q\right)\\ q&=4 \end{aligned}\)

Substitusikan x = −1,
\(\begin{aligned} 2(-1)^4+3(-1)^3-9(-1)+4&=\left(2(-1)^2-3(-1)+1\right)\left((-1)^2+p(-1)+4\right)\\ 2-3+9+4&=(2+3+1)(1-p+4)\\ 12&=6(-p+5)\\ 2&=-p+5\\ p&=3 \end{aligned}\)

\(\begin{aligned} p^2-q&=3^2-4\\ &=9-4\\ &=\color{blue}\boxed{\boxed{\color{black}5}} \end{aligned}\)
Jadi, p2 − q = 5.

ALTERNATIF PENYELESAIAN
\(\begin{aligned} P(x)&=x^3+Ax^2+Bx+5\\ &=x\left(x^2+3\right)+A\left(x^2+3\right)+Bx+5-3x-3A\\ &=x\left(x^2+3\right)+A\left(x^2+3\right)+\left(B-3\right)x+5-3A \end{aligned}\)
didapat B − 3 = 2, dan 5 − 3A = −1.
Sehingga, A = 2 dan B = 5.
Maka, A + B = 2 + 5 = 7.
Jadi, nilai dari A + B = 7.
