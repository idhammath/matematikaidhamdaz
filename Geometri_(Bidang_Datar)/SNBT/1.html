Perhatikan gambar persegi panjang \(ABCD\) berikut:

Titik \(E\) terletak pada sisi \(CD\) sedemikian sehingga perbandingan \(DE : EC = 1 : 2\). Ruas garis \(AE\) dan diagonal \(BD\) berpotongan di titik \(F\). Jika luas daerah segitiga \(DEF\) yang diarsir adalah \(6\text{ cm}^2\), maka luas seluruh persegi panjang \(ABCD\) adalah ....

  1. \(96\text{ cm}^2\)
  2. \(108\text{ cm}^2\)
  3. \(120\text{ cm}^2\)
  4. \(144\text{ cm}^2\)
  5. \(180\text{ cm}^2\)
SNBT / UTBK
Pembahasan:

Langkah 1: Menentukan rasio perbandingan sisi \(DE\) dan \(AB\)

Pada persegi panjang \(ABCD\), sisi \(AB = CD\) dan \(AB \parallel CD\). Diketahui \(DE : EC = 1 : 2\), sehingga:

\[ DE = \frac{1}{1 + 2} CD = \frac{1}{3} CD = \frac{1}{3} AB \implies \frac{DE}{AB} = \frac{1}{3} \]

Langkah 2: Menggunakan prinsip kesebangunan segitiga

Karena garis \(AB \parallel DE\), maka sudut-sudut dalam berseberangan bernilai sama besar:

  • \(\angle FDE = \angle FBA\) (berseberangan dalam)
  • \(\angle FED = \angle FAB\) (berseberangan dalam)
  • \(\angle DFE = \angle BFA\) (bertolak belakang)

Sehingga segitiga \(\triangle DEF\) dan \(\triangle BAF\) adalah sebangun (\(\triangle DEF \sim \triangle BAF\)) dengan rasio kesebangunan:

\[ \frac{DF}{FB} = \frac{EF}{FA} = \frac{DE}{AB} = \frac{1}{3} \]

Langkah 3: Menghitung luas \(\triangle BAF\) dan \(\triangle DAF\)

  • Luas \(\triangle BAF\): Perbandingan luas dua segitiga yang sebangun sebanding dengan kuadrat perbandingan sisinya: \[ \frac{\text{Luas } \triangle BAF}{\text{Luas } \triangle DEF} = \left(\frac{AB}{DE}\right)^2 = 3^2 = 9 \] \[ \text{Luas } \triangle BAF = 9 \times 6 = 54\text{ cm}^2 \]
  • Luas \(\triangle DAF\): Segitiga \(\triangle DAF\) dan \(\triangle DEF\) memiliki garis tinggi yang sama ditarik dari titik puncak \(D\) ke garis \(AE\). Maka perbandingan luasnya sama dengan perbandingan alasnya: \[ \frac{\text{Luas } \triangle DAF}{\text{Luas } \triangle DEF} = \frac{FA}{EF} = \frac{3}{1} \] \[ \text{Luas } \triangle DAF = 3 \times 6 = 18\text{ cm}^2 \]

Langkah 4: Menghitung luas persegi panjang \(ABCD\)

Perhatikan bahwa segitiga \(\triangle ABD\) dibentuk dari gabungan \(\triangle DAF\) dan \(\triangle BAF\):

\[ \text{Luas } \triangle ABD = \text{Luas } \triangle DAF + \text{Luas } \triangle BAF = 18 + 54 = 72\text{ cm}^2 \]

Karena diagonal \(BD\) membagi persegi panjang \(ABCD\) menjadi dua segitiga siku-siku dengan luas yang sama, maka luas seluruh persegi panjang \(ABCD\) adalah:

\[ \text{Luas } ABCD = 2 \times \text{Luas } \triangle ABD = 2 \times 72 = 144\text{ cm}^2 \]

(Cara alternatif: Luas \(\triangle DAE = 6 + 18 = 24\text{ cm}^2\). Karena alas \(DE = \frac{1}{3} CD\), maka luas \(\triangle DAE = \frac{1}{2} \cdot \frac{1}{3} CD \cdot AD = \frac{1}{6} \text{Luas } ABCD \implies \text{Luas } ABCD = 6 \times 24 = 144\text{ cm}^2\)).

Jadi, luas seluruh persegi panjang \(ABCD\) adalah \(144\text{ cm}^2\).
