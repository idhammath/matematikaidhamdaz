Fungsi \(f(x) = 2 - 5\sin\left(\dfrac{\pi}{6}x\right)\) untuk \(-5 \le x \le 1\) mempunyai nilai maksimum \(p\) di titik \(x = q\). Nilai \(p + q =\) ....

  1. 7
  2. 6
  3. 5
  4. 4
  5. 3
Grup Matematika Zone Indonesia
Pembahasan:
Diberikan fungsi: \[ f(x) = 2 - 5\sin\left(\dfrac{\pi}{6}x\right), \quad -5 \le x \le 1 \] Cara 1: Menggunakan Nilai Ekstrem Trigonometri
Rentang nilai fungsi sinus dasar adalah \(-1 \le \sin(\theta) \le 1\).
Karena koefisien sinus bertanda negatif (\(-5\)), fungsi \(f(x)\) akan mencapai nilai maksimum saat nilai sinusnya bernilai minimum, yaitu: \[ \sin\left(\dfrac{\pi}{6}x\right) = -1 \] Sehingga nilai maksimum \(p\) adalah: \[ p = 2 - 5(-1) = 2 + 5 = 7 \] Nilai sinus bernilai \(-1\) ketika sudutnya memenuhi: \[\begin{aligned} \dfrac{\pi}{6}x &= -\dfrac{\pi}{2} + 2k\pi \quad (\text{dikalikan } \dfrac{6}{\pi}) \\[4pt] x &= -3 + 12k \end{aligned}\] Untuk \(k = 0\), diperoleh: \[ x = -3 \] Karena \(-3 \in [-5, 1]\), maka titik absis yang menghasilkan nilai maksimum adalah \(q = -3\).

Pemeriksaan Titik Batas Interval:
  • Untuk \(x = -5\): \[ f(-5) = 2 - 5\sin\left(-\dfrac{5\pi}{6}\right) = 2 - 5\left(-\dfrac{1}{2}\right) = 2 + 2{,}5 = 4{,}5 \]
  • Untuk \(x = 1\): \[ f(1) = 2 - 5\sin\left(\dfrac{\pi}{6}\right) = 2 - 5\left(\dfrac{1}{2}\right) = 2 - 2{,}5 = -0{,}5 \]
Terbukti bahwa nilai maksimum mutlak pada interval tersebut adalah \(p = 7\) yang dicapai pada \(q = -3\).

Maka nilai \(p + q\) adalah: \[ p + q = 7 + (-3) = 4 \]
Jadi, nilai \(p + q = 4\).
