Diketahui \(f(x) = x^2 + ax + b\) dengan \(f(3) = 1\). Jika \[\lim_{x\to3}\dfrac{x-3}{f(x)-f(3)}=\dfrac{1}{2}\] maka nilai \(a + b = \dots\)

  1. \(8\)
  2. \(0\)
  3. \(-2\)
  4. \(-4\)
  5. \(-8\)
Pembahasan:

Perhatikan bahwa bentuk limit tersebut merupakan kebalikan dari definisi turunan fungsi di \(x = 3\):

\[ \lim_{x\to3}\dfrac{x-3}{f(x)-f(3)} = \lim_{x\to3}\dfrac{1}{\dfrac{f(x)-f(3)}{x-3}} = \dfrac{1}{f'(3)} = \dfrac{1}{2} \implies f'(3) = 2 \]

Karena \(f(x) = x^2 + ax + b\), maka \(f'(x) = 2x + a\):

\[ \begin{aligned} f'(3) &= 2(3) + a = 2\\[3.7pt] 6 + a &= 2 \implies a = -4 \end{aligned} \]

Diketahui pula \(f(3) = 1\):

\[ \begin{aligned} f(3) = 3^2 + (-4)(3) + b &= 1\\[3.7pt] 9 - 12 + b &= 1\\[3.7pt] -3 + b &= 1 \implies b = 4 \end{aligned} \]

Sehingga nilai \(a + b\) adalah:

\[ a + b = -4 + 4 = 0 \]
Jadi, nilai \(a + b = 0\).

Diketahui suku banyak \(f(x) = ax^2 - (a + b)x - 3\) habis dibagi oleh \(x + 1\). Jika \[\lim_{x\to-1}\dfrac{f(x)}{x^2-x-2}=2\] maka nilai \(a + b\) adalah ....

  1. \(-1\)
  2. \(2\)
  3. \(5\)
  4. \(4\)
  5. \(0\)
Pembahasan:

1. Karena \(f(x)\) habis dibagi \(x + 1\), maka \(f(-1) = 0\):

\[ \begin{aligned} f(-1) &= a(-1)^2 - (a+b)(-1) - 3 = 0\\[3.7pt] a + a + b - 3 &= 0\\[3.7pt] 2a + b &= 3 \quad \dots\text{(Persamaan 1)} \end{aligned} \]

2. Karena \(f(-1) = 0\) dan penyebut \((-1)^2 - (-1) - 2 = 0\), gunakan aturan L'Hôpital pada limit:

\[ \begin{aligned} \lim_{x\to-1}\dfrac{f(x)}{x^2-x-2} &= \lim_{x\to-1}\dfrac{f'(x)}{2x-1} = 2\\[3.7pt] \dfrac{f'(-1)}{2(-1)-1} &= 2 \implies \dfrac{f'(-1)}{-3} = 2 \implies f'(-1) = -6 \end{aligned} \] Dari \(f'(x) = 2ax - (a+b)\): \[ \begin{aligned} f'(-1) = 2a(-1) - a - b &= -6\\[3.7pt] -3a - b &= -6 \implies 3a + b = 6 \quad \dots\text{(Persamaan 2)} \end{aligned} \]

3. Eliminasi Persamaan 2 dan Persamaan 1:

\[ \begin{aligned} (3a + b) - (2a + b) &= 6 - 3\\[3.7pt] a &= 3 \end{aligned} \] Substitusi ke Persamaan 1: \[ 2(3) + b = 3 \implies 6 + b = 3 \implies b = -3 \] Maka nilai \(a + b\): \[ a + b = 3 + (-3) = 0 \]
Jadi, nilai \(a + b\) adalah \(0\).

  1. \(-\dfrac{3}{2}\)
  2. \(-\dfrac{2}{3}\)
  3. \(\dfrac{2}{3}\)
  4. \(1\)
  5. \(\dfrac{3}{2}\)

Pembahasan:

Faktorkan penyebut suku kedua \(x - x^3 = x(1-x^2) = x(1-x)(1+x)\), lalu samakan penyebut:

\[ \begin{aligned} \lim_{x\to1}\left(\dfrac{1}{1-x}-\dfrac{2}{x-x^3}\right)&=\lim_{x\to1}\left(\dfrac{x(1+x)}{x(1-x)(1+x)}-\dfrac{2}{x(1-x)(1+x)}\right)\\[3.7pt] &=\lim_{x\to1}\dfrac{x^2+x-2}{x(1-x)(1+x)}\\[3.7pt] &=\lim_{x\to1}\dfrac{(x+2)(x-1)}{x(1-x)(1+x)}\\[3.7pt] &=\lim_{x\to1}\dfrac{-(x+2)(1-x)}{x(1-x)(1+x)}\\[3.7pt] &=\lim_{x\to1}\dfrac{-(x+2)}{x(1+x)}\\[3.7pt] &=\dfrac{-(1+2)}{1(1+1)} = -\dfrac{3}{2} \end{aligned} \]
Jadi, \(\displaystyle\lim_{x\to1}\left(\dfrac{1}{1-x}-\dfrac{2}{x-x^3}\right)=-\dfrac{3}{2}\).

  1. \(\sqrt{3}+\sqrt{2}\)
  2. \(5-2\sqrt{6}\)
  3. \(2\sqrt{6}\)
  4. \(5\)
  5. \(5+2\sqrt{6}\)
Grup WhatsApp
Pembahasan:

Cara 1: Menyederhanakan Bentuk Akar dalam Akar

Ingat identitas \(\sqrt{(a+b)\pm 2\sqrt{ab}} = \sqrt{a}\pm\sqrt{b}\). Perhatikan bahwa:

\[ x = (x+1) + 1 - 1 \] Sehingga \(x+2\sqrt{x+1} = (x+1)+2\sqrt{x+1}+1 = (\sqrt{x+1}+1)^2\), dan \(x-2\sqrt{x+1} = (\sqrt{x+1}-1)^2\). Maka: \[ \dfrac{\sqrt{x+2\sqrt{x+1}}}{\sqrt{x-2\sqrt{x+1}}} = \dfrac{\sqrt{x+1}+1}{\sqrt{x+1}-1} \] Substitusi \(x = 5\): \[ \dfrac{\sqrt{5+1}+1}{\sqrt{5+1}-1} = \dfrac{\sqrt{6}+1}{\sqrt{6}-1} \cdot \dfrac{\sqrt{6}+1}{\sqrt{6}+1} = \dfrac{6+2\sqrt{6}+1}{6-1} = \dfrac{7+2\sqrt{6}}{5} \]

Cara 2: Mengalikan dengan Sekawan Bentuk Perkalian Akar

\[ \begin{aligned} \lim_{x\to5}\dfrac{\sqrt{x+2\sqrt{x+1}}}{\sqrt{x-2\sqrt{x+1}}}&=\lim_{x\to5}\dfrac{\sqrt{x+2\sqrt{x+1}}\cdot\sqrt{x+2\sqrt{x+1}}}{\sqrt{\left(x-2\sqrt{x+1}\right)\left(x+2\sqrt{x+1}\right)}}\\[3.7pt] &=\lim_{x\to5}\dfrac{x+2\sqrt{x+1}}{\sqrt{x^2-4(x+1)}}\\[3.7pt] &=\dfrac{5+2\sqrt{5+1}}{\sqrt{5^2-4(6)}} = \dfrac{5+2\sqrt{6}}{\sqrt{25-24}} = 5+2\sqrt{6} \end{aligned} \]
Jadi, hasilnya adalah \(5+2\sqrt{6}\).

Jika \(f(x) = ax + b\) dan \(\displaystyle\lim_{x\to4}\left(\dfrac{3x\cdot f(x)}{x-4}\right)=24\), maka nilai dari \(f(5) = \dots\)

  1. \(0\)
  2. \(1\)
  3. \(2\)
  4. \(3\)
  5. \(4\)
Pembahasan:

Karena limit bernilai terhingga (\(24\)) sementara penyebut bernilai nol saat \(x\to4\), maka pembilang harus bernilai nol saat \(x = 4\):

\[ 3(4)\cdot f(4) = 0 \implies f(4) = 0 \]

Karena \(f(x)\) adalah fungsi linear berderajat 1 dengan akar \(x = 4\), maka dapat ditulis:

\[ f(x) = p(x - 4) \] Substitusikan ke dalam limit: \[ \begin{aligned} \lim_{x\to4}\left(\dfrac{3x\cdot p(x-4)}{x-4}\right) &= 24\\[3.7pt] \lim_{x\to4} (3px) &= 24\\[3.7pt] 3p(4) &= 24\\[3.7pt] 12p &= 24 \implies p = 2 \end{aligned} \] Sehingga fungsi \(f(x) = 2(x - 4)\). Maka nilai \(f(5)\) adalah: \[ f(5) = 2(5 - 4) = 2(1) = 2 \]
Jadi, nilai \(f(5) = 2\).

Diketahui nilai \(\displaystyle\lim_{x\to a}\left(5f(x)-3g(x)\right)=11\) dan \(\displaystyle\lim_{x\to a}\left(2f(x)+3g(x)\right)=17\). Maka nilai \(\displaystyle\lim_{x\to a}\left(f(x)\cdot g(x)\right)=\dots\)

  1. \(21\)
  2. \(16\)
  3. \(15\)
  4. \(14\)
  5. \(12\)
Pembahasan:

Misalkan \(F = \lim_{x\to a}f(x)\) dan \(G = \lim_{x\to a}g(x)\). Dari sifat-sifat limit diperoleh sistem persamaan linear:

\[ \begin{aligned} 5F - 3G &= 11\\[3.7pt] 2F + 3G &= 17 \end{aligned} \]

Jumlahkan kedua persamaan:

\[ \begin{aligned} 7F &= 28 \implies F = 4 \end{aligned} \]

Substitusikan nilai \(F = 4\) ke persamaan kedua:

\[ \begin{aligned} 2(4) + 3G &= 17\\[3.7pt] 8 + 3G &= 17\\[3.7pt] 3G &= 9 \implies G = 3 \end{aligned} \]

Maka berdasarkan sifat limit perkalian:

\[ \lim_{x\to a}\left(f(x)\cdot g(x)\right) = F \cdot G = 4 \cdot 3 = 12 \]
Jadi, \(\displaystyle\lim_{x\to a}\left(f(x)\cdot g(x)\right)=12\).
Jawaban: E

Jika \(\displaystyle\lim_{x\to1}\dfrac{\sqrt{ax^4+b}-2}{x-1}=M\), maka nilai dari \[\lim_{x\to1}\dfrac{\sqrt{ax^4+b}-2x}{x^2+2x-3}=\dots\]

  1. \(2M - 1\)
  2. \(\dfrac{1}{2}(M-1)\)
  3. \(\dfrac{1}{4}(M-2)\)
  4. \(2M + 2\)
  5. \(4M - 2\)
Pembahasan:

Cara 1: Manipulasi Aljabar Limit

Uraikan pembilang dengan menambah dan mengurang \(2\):

\[ \sqrt{ax^4+b}-2x = \left(\sqrt{ax^4+b}-2\right) - (2x-2) = \left(\sqrt{ax^4+b}-2\right) - 2(x-1) \] Penyebut dapat difaktorkan menjadi \(x^2+2x-3 = (x-1)(x+3)\). Maka: \[ \begin{aligned} \lim_{x\to1}\dfrac{\sqrt{ax^4+b}-2x}{x^2+2x-3} &= \lim_{x\to1}\dfrac{\left(\sqrt{ax^4+b}-2\right) - 2(x-1)}{(x-1)(x+3)}\\[3.7pt] &= \lim_{x\to1}\left[\dfrac{\dfrac{\sqrt{ax^4+b}-2}{x-1} - 2}{x+3}\right]\\[3.7pt] &= \dfrac{M - 2}{1 + 3} = \dfrac{1}{4}(M - 2) \end{aligned} \]

Cara 2: Aturan L'Hôpital

Dari limit pertama diketahui bahwa turunan pembilang di \(x = 1\) bernilai \(M\):

\[ \left.\dfrac{d}{dx}\left(\sqrt{ax^4+b}\right)\right|_{x=1} = M \] Terapkan aturan L'Hôpital pada limit kedua: \[ \begin{aligned} \lim_{x\to1}\dfrac{\sqrt{ax^4+b}-2x}{x^2+2x-3} &= \lim_{x\to1}\dfrac{\dfrac{d}{dx}\left(\sqrt{ax^4+b}\right)-2}{2x+2}\\[3.7pt] &= \dfrac{M - 2}{2(1)+2} = \dfrac{1}{4}(M - 2) \end{aligned} \]
Jadi, hasilnya adalah \(\dfrac{1}{4}(M-2)\).
Jawaban: C

Diketahui suku banyak \(g(x) = ax^2 + (a - b)x + 1\) habis dibagi \(x + 1\). Jika \[\lim_{x\to-1}\dfrac{g(x)}{x^2+3x+2}=4\] maka nilai \(2a - b\) adalah ....

  1. \(3\)
  2. \(4\)
  3. \(-5\)
  4. \(-6\)
  5. \(-7\)
Pembahasan:

1. Karena \(g(x)\) habis dibagi \(x + 1\), maka \(g(-1) = 0\):

\[ \begin{aligned} g(-1) &= a(-1)^2 + (a-b)(-1) + 1 = 0\\[3.7pt] a - a + b + 1 &= 0 \implies b = -1 \end{aligned} \] Sehingga suku banyak menjadi \(g(x) = ax^2 + (a+1)x + 1\).

2. Gunakan aturan L'Hôpital karena menghasilkan bentuk \(\frac{0}{0}\):

\[ \begin{aligned} \lim_{x\to-1}\dfrac{ax^2+(a+1)x+1}{x^2+3x+2} &= \lim_{x\to-1}\dfrac{2ax + (a+1)}{2x + 3} = 4\\[3.7pt] \dfrac{2a(-1) + a + 1}{2(-1) + 3} &= 4\\[3.7pt] \dfrac{-a + 1}{1} &= 4\\[3.7pt] -a + 1 &= 4 \implies a = -3 \end{aligned} \]

3. Hitung nilai \(2a - b\):

\[ 2a - b = 2(-3) - (-1) = -6 + 1 = -5 \]
Jadi, nilai \(2a - b = -5\).
Jawaban: C

Nilai \(\displaystyle\lim_{x\to a}\left(5f(x)-3g(x)\right)= 11\) dan \(\displaystyle\lim_{x\to a}\left(2f(x)+3g(x)\right)= 17\), maka nilai dari \(\displaystyle\lim_{x\to a}\left(4f(x)\right)=\dots\)

  1. \(16\)
  2. \(18\)
  3. \(20\)
  4. \(22\)
  5. \(24\)
Pembahasan:

Misalkan \(L_f = \lim_{x\to a}f(x)\) dan \(L_g = \lim_{x\to a}g(x)\). Diketahui:

\[ \begin{aligned} 5L_f - 3L_g &= 11\\[3.7pt] 2L_f + 3L_g &= 17 \end{aligned} \] Jumlahkan kedua persamaan: \[ \begin{aligned} 7L_f &= 28\\[3.7pt] L_f &= 4 \end{aligned} \] Maka nilai yang dicari: \[ \lim_{x\to a}\left(4f(x)\right) = 4 L_f = 4(4) = 16 \]
Jadi, \(\displaystyle\lim_{x\to a}\left(4f(x)\right)=16\).

Diketahui: \[\lim_{x\to3}\dfrac{f(x)\cdot g(x)-5g(x)+f(x)-5}{\left(f(x)-5\right)(x-3)}=0\] Nilai dari \(g'(3)\) adalah ....

  1. \(-1\)
  2. \(1\)
  3. \(-3\)
  4. \(3\)
  5. \(0\)
Pembahasan:

Faktorkan pembilang pecahan:

\[ \begin{aligned} f(x)\cdot g(x)-5g(x)+f(x)-5 &= g(x)\left(f(x)-5\right) + 1\cdot\left(f(x)-5\right)\\[3.7pt] &= \left(f(x)-5\right)\left(g(x)+1\right) \end{aligned} \] Substitusikan ke bentuk limit: \[ \begin{aligned} \lim_{x\to3}\dfrac{\left(f(x)-5\right)\left(g(x)+1\right)}{\left(f(x)-5\right)(x-3)} &= 0\\[3.7pt] \lim_{x\to3}\dfrac{g(x)+1}{x-3} &= 0 \end{aligned} \]

Karena penyebut menuju nol saat \(x\to3\) dan limit bernilai nol, maka \(g(3) + 1 = 0 \implies g(3) = -1\). Bentuk ini setara dengan definisi turunan \(g'(3)\):

\[ g'(3) = \lim_{x\to3}\dfrac{g(x)-g(3)}{x-3} = \lim_{x\to3}\dfrac{g(x)-(-1)}{x-3} = \lim_{x\to3}\dfrac{g(x)+1}{x-3} = 0 \]
Jadi, nilai \(g'(3) = 0\).
