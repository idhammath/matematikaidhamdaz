Buktikan dengan induksi matematika bahwa untuk \(n \ge 5\) bilangan asli berlaku: \[2n - 3 < 2^{n - 2}\]

Grup Telegram
Pembahasan:

Langkah 1: Basis Induksi (Membuktikan untuk nilai awal \(n = 5\))

Substitusikan \(n = 5\) ke kedua ruas pertidaksamaan:

\[\begin{aligned} \text{Ruas Kiri} &= 2(5) - 3 = 10 - 3 = 7 \\ \text{Ruas Kanan} &= 2^{5 - 2} = 2^3 = 8 \end{aligned}\]

Karena \(7 < 8\), maka pernyataan bernilai BENAR untuk \(n = 5\).

Catatan Penjelasan: Mengapa dibatasi untuk \(n \ge 5\)? Sebab untuk \(n = 3\), \(2(3) - 3 = 3 > 2^{3-2} = 2\) (salah). Untuk \(n = 4\), \(2(4) - 3 = 5 > 2^{4-2} = 4\) (salah). Pertidaksamaan baru mulai benar pada \(n = 5\).

Langkah 2: Hipotesis Induksi

Asumsikan pernyataan bernilai benar untuk \(n = k \ge 5\) bilangan asli, yaitu:

\[2k - 3 < 2^{k - 2}\]

Langkah 3: Langkah Induksi (Membuktikan benar untuk \(n = k + 1\))

Akan dibuktikan bahwa untuk \(n = k + 1\) berlaku: \[2(k + 1) - 3 < 2^{(k + 1) - 2} = 2^{k - 1}\]

Jabarkan ruas kiri:

\[\begin{aligned} 2(k + 1) - 3 &= 2k + 2 - 3 \\ &= (2k - 3) + 2 \end{aligned}\]

Gunakan hipotesis induksi bahwa \(2k - 3 < 2^{k - 2}\):

\[(2k - 3) + 2 < 2^{k - 2} + 2\]

Karena \(k \ge 5\), maka pangkat \(k - 2 \ge 3\), sehingga \(2^{k - 2} \ge 2^3 = 8 > 2\). Akibatnya berlaku \(2 < 2^{k - 2}\). Dengan mengganti konstanta \(2\) dengan bentuk yang lebih besar (\(2^{k - 2}\)), diperoleh:

\[\begin{aligned} 2(k + 1) - 3 &< 2^{k - 2} + 2 \\ &< 2^{k - 2} + 2^{k - 2} \\ &= 2 \cdot 2^{k - 2} \\ &= 2^{1 + (k - 2)} \\ &= 2^{k - 1} \end{aligned}\]

Dengan demikian, terbukti benar bahwa \(2(k + 1) - 3 < 2^{k - 1}\).

Visualisasi grafik perbandingan \(f(n) = 2n - 3\) dan \(g(n) = 2^{n - 2}\) yang menunjukkan awal keabsahan induksi pada \(n \ge 5\)

Jadi, terbukti benar bahwa untuk setiap bilangan asli \(n \ge 5\) berlaku \(2n - 3 < 2^{n - 2}\).

Buktikan bahwa untuk \(n\) bilangan bulat positif berlaku: \[4 + 8 + 12 + \dots + 4n = 2n^2 + 2n\]

Grup Telegram
Pembahasan:

Langkah 1: Basis Induksi (Membuktikan untuk \(n = 1\))

Substitusikan \(n = 1\) ke kedua ruas:

\[\begin{aligned} \text{Ruas Kiri} &= 4(1) = 4 \\ \text{Ruas Kanan} &= 2(1)^2 + 2(1) = 2(1) + 2 = 4 \end{aligned}\]

Karena kedua ruas menghasilkan nilai yang sama (\(4 = 4\)), maka pernyataan bernilai BENAR untuk \(n = 1\).

Langkah 2: Hipotesis Induksi

Asumsikan pernyataan bernilai benar untuk \(n = k\) dengan \(k\) bilangan bulat positif, yaitu:

\[4 + 8 + 12 + \dots + 4k = 2k^2 + 2k\]

Langkah 3: Langkah Induksi (Membuktikan benar untuk \(n = k + 1\))

Akan dibuktikan bahwa rumus berlaku untuk \(n = k + 1\), yaitu: \[4 + 8 + 12 + \dots + 4k + 4(k + 1) = 2(k + 1)^2 + 2(k + 1)\]

Buktikan dengan mengolah ruas kiri:

\[\begin{aligned} \underbrace{4 + 8 + 12 + \dots + 4k}_{\text{Hipotesis Induksi}} + 4(k + 1) &= (2k^2 + 2k) + 4(k + 1) \\ &= 2k^2 + 2k + 4k + 4 \\ &= 2k^2 + 6k + 4 \end{aligned}\]

Faktorkan bentuk kuadrat tersebut ke dalam suku-suku \((k + 1)\):

\[\begin{aligned} 2k^2 + 6k + 4 &= 2(k^2 + 3k + 2) \\ &= 2(k + 1)(k + 2) \\ &= 2(k + 1)\big((k + 1) + 1\big) \\ &= 2(k + 1)(k + 1) + 2(k + 1) \\ &= 2(k + 1)^2 + 2(k + 1) \end{aligned}\]

Hasil di atas persis sama dengan bentuk ruas kanan untuk \(n = k + 1\). Dengan demikian, langkah induksi TERBUKTI BENAR.

Visualisasi geometris luas: persegi panjang \(2k \times (k + 1)\) dengan luas \(2k^2 + 2k\) bertambah lapisan tepi sebesar \(4(k + 1)\) menjadi \(2(k + 1) \times (k + 2)\)

Jadi, terbukti benar bahwa untuk setiap bilangan bulat positif \(n\) berlaku:
\(4 + 8 + 12 + \dots + 4n = 2n^2 + 2n\).
