Sementara itu, untuk membuat benda B memerlukan waktu 4 menit pada mesin I dan 14 menit pada mesin II. Mesin I dapat bekerja paling lama 4.060 menit dan mesin II dapat bekerja paling lama 1.820 menit. Jika banyak benda A adalah \(x\) unit dan banyak benda B adalah \(y\) unit, model matematika dari permasalahan tersebut adalah ....

Pembahasan:

Mesin Benda A (\(x\)) Benda B (\(y\)) Waktu Maksimum
Mesin I 6 menit 4 menit 4.060 menit
Mesin II 10 menit 14 menit 1.820 menit

  • Mesin I: \[6x + 4y \le 4060 \iff 3x + 2y \le 2030\]

  • Titik \(B(150, 150)\)
  • Titik \(C(150, 250)\) (perpotongan \(x = 150\) dan \(x + y = 400\))
  • Titik \(D(100, 300)\) (perpotongan \(x = 100\) dan \(x + y = 400\))
Uji nilai fungsi tujuan pada setiap titik sudut:
Titik \(10.000x\) \(5.000y\) \(f(x,y) = 10.000x + 5.000y\)

\(B(150, 150)\) Rp1.500.000,00 Rp750.000,00 Rp2.250.000,00

\(D(100, 300)\) Rp1.000.000,00 Rp1.500.000,00 Rp2.500.000,00

Jika dalam satu jam tidak ada kendaraan yang pergi dan datang, pendapatan maksimum tempat parkir tersebut dalam satu jam adalah ....
  1. Rp36.000,00
  2. Rp66.000,00

  4. Rp104.000,00
  5. Rp116.000,00

Pembahasan:
Misalkan \(x\) adalah banyak sedan dan \(y\) adalah banyak minibus.
Kategori Sedan (\(x\)) Minibus (\(y\)) Kapasitas
Daya Tampung 1 1 26
Luas Lahan (m\(^2\)) 4 16 176
Tarif Parkir Rp4.000,00 Rp6.000,00 -
Model Matematika:
  • \(x + y \le 26\)
  • \(4x + 16y \le 176 \iff x + 4y \le 44\)
  • \(x \ge 0, y \ge 0\)
  • Fungsi tujuan: \(f(x, y) = 4.000x + 6.000y\)
Titik potong kedua garis batas: \[\begin{aligned} x + y &= 26\\ x + 4y &= 44\\ \hline -3y &= -18 \implies y = 6\\ x &= 26 - 6 = 20 \implies (20, 6) \end{aligned}\] Titik-titik sudut DHP:
  • \((0, 0) \implies f = 0\)
  • \((26, 0) \implies f = 4.000(26) + 0 = \text{Rp}104.000,00\)
  • \((20, 6) \implies f = 4.000(20) + 6.000(6) = 80.000 + 36.000 = \text{Rp}116.000,00\)
  • \((0, 11) \implies f = 0 + 6.000(11) = \text{Rp}66.000,00\)
Jadi, pendapatan maksimum tempat parkir tersebut dalam satu jam adalah Rp116.000,00.

Setiap hari seorang pengrajin tas memproduksi dua jenis tas. Modal untuk tas model I adalah Rp20.000,00 dengan keuntungan 50%. Modal untuk tas model II adalah Rp40.000,00 dengan keuntungan 40%. Jika modal yang tersedia setiap harinya Rp1.200.000,00 dan ia hanya dapat memproduksi paling banyak 40 tas, persentase keuntungan terbesar yang dapat dicapai pengrajin tas tersebut adalah ....
Matematika Zone Indonesia
Pembahasan:
Misalkan:
  • \(x\) = banyak tas model I (modal Rp20.000,00; keuntungan \(50\% \times 20.000 = \text{Rp}10.000,00\))
  • \(y\) = banyak tas model II (modal Rp40.000,00; keuntungan \(40\% \times 40.000 = \text{Rp}16.000,00\))
Sistem pertidaksamaan:
  • Batasan modal: \(20.000x + 40.000y \le 1.200.000 \iff x + 2y \le 60\)
  • Batasan jumlah tas: \(x + y \le 40\)
  • \(x \ge 0, y \ge 0\)
  • Fungsi laba: \(f(x, y) = 10.000x + 16.000y\)
Titik potong garis \(x + 2y = 60\) dan \(x + y = 40\): \[\begin{aligned} (x + 2y) - (x + y) &= 60 - 40\\ y &= 20 \implies x = 20 \implies (20, 20) \end{aligned}\] Titik-titik sudut DHP:
  • \((0, 30) \implies f = 16.000(30) = \text{Rp}480.000,00\)
  • \((20, 20) \implies f = 10.000(20) + 16.000(20) = 200.000 + 320.000 = \text{Rp}520.000,00\) (Maksimum)
  • \((40, 0) \implies f = 10.000(40) = \text{Rp}400.000,00\)
Pada titik maksimum \((20, 20)\), modal yang terpakai: \[20(20.000) + 20(40.000) = 400.000 + 800.000 = \text{Rp}1.200.000,00\] Persentase keuntungan: \[\text{Persentase} = \dfrac{520.000}{1.200.000} \times 100\% = \dfrac{13}{30} \times 100\% \approx 43{,}33\%\]
Jadi, keuntungan terbesar yang dapat dicapai adalah 43,33%.

Jika ingin memperoleh keuntungan yang sebesar-besarnya, berapa banyak masing-masing cokelat yang harus ia beli?
Grup Telegram
Pembahasan:
Misalkan \(x\) adalah banyak cokelat A dan \(y\) adalah banyak cokelat B.
Jenis Harga Beli Kapasitas Laba
Cokelat A Rp2.500,00 \(x\) Rp300,00
Cokelat B Rp6.000,00 \(y\) Rp600,00
Batas Maksimum Rp3.000.000,00 640 batang -
Model Matematika:
  • Batasan modal: \(2500x + 6000y \le 3000000 \iff 5x + 12y \le 6000\)
  • Batasan daya tampung: \(x + y \le 640\)
  • Non-negatif: \(x \ge 0, y \ge 0\)
  • Fungsi tujuan: \(f(x, y) = 300x + 600y\)
Titik potong kedua garis: \[\begin{aligned} 5x + 12y &= 6000\\ 5(x + y) &= 5(640) \implies 5x + 5y = 3200\\ \hline 7y &= 2800 \implies y = 400\\ x &= 640 - 400 = 240 \implies B(240, 400) \end{aligned}\] Titik sudut DHP:
  • \(A(640, 0) \implies f = 300(640) + 0 = \text{Rp}192.000,00\)
  • \(B(240, 400) \implies f = 300(240) + 600(400) = 72.000 + 240.000 = \text{Rp}312.000,00\) (Maksimum)
  • \(C(0, 500) \implies f = 0 + 600(500) = \text{Rp}300.000,00\)
Jadi, untuk memperoleh keuntungan sebesar-besarnya, pedagang harus membeli 240 batang cokelat A dan 400 batang cokelat B.

Udin akan membuat 2 buah kue yaitu kue bolu dan kue pukis. Banyak kue bolu yang akan dibuat sedikitnya 15 buah dan paling banyak 25 buah. Kue pukis paling banyak dibuat 100 buah. Total produksi masing-masing kue adalah paling banyak 200 buah. Jika kue bolu dilambangkan \(x\) dan kue pukis dilambangkan \(y\), tentukan model matematikanya.
Latihan Mandiri
Pembahasan:
Misalkan:
  • \(x\) = banyak kue bolu
  • \(y\) = banyak kue pukis
Berdasarkan batasan pada soal:
  • Kue bolu dibuat paling sedikit 15 buah dan paling banyak 25 buah: \[15 \le x \le 25\]
  • Kue pukis paling banyak dibuat 100 buah (dan tidak boleh negatif): \[0 \le y \le 100\]
  • Total produksi kedua kue paling banyak 200 buah: \[x + y \le 200\]
Jadi, model matematikanya adalah \(15 \le x \le 25\), \(0 \le y \le 100\), dan \(x + y \le 200\).
