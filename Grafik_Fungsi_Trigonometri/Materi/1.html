Ringkasan dan penjelasan lengkap materi Grafik Fungsi Trigonometri

1. Pengertian & Karakteristik Grafik Dasar ($\sin x, \cos x, \tan x$)

Fungsi Trigonometri adalah fungsi periodik (berulang secara teratur pada setiap selang sudut tertentu) yang memetakan besar sudut $x$ (dalam radian atau derajat) ke nilai perbandingan trigonometrinya. Satu putaran penuh pada lingkaran satuan setara dengan $2\pi\text{ radian} = 360^\circ$.

Perbandingan Kurva Baku $y = \sin x$ dan $y = \cos x$:

  • Grafik $y = \sin x$ (Hijau Teal): Dimulai dari titik asal $(0, 0)$, naik mencapai puncak maksimum $(90^\circ, 1)$, turun memotong sumbu-$X$ di $(180^\circ, 0)$, mencapai lembah minimum $(270^\circ, -1)$, dan kembali ke $(360^\circ, 0)$. Satu gelombang penuh terdiri dari 1 bukit dan 1 lembah.
  • Grafik $y = \cos x$ (Kuning Mustard): Dimulai dari puncak maksimum $(0, 1)$, turun ke $(90^\circ, 0)$, mencapai lembah minimum $(180^\circ, -1)$, naik ke $(270^\circ, 0)$, dan kembali ke puncak $(360^\circ, 1)$. Kurva $\cos x$ sebenarnya adalah kurva $\sin x$ yang digeser ke kiri sejauh $90^\circ$ ($\cos x = \sin(x + 90^\circ)$).
Karakteristik Fungsi Sinus ($y = \sin x$) Fungsi Cosinus ($y = \cos x$) Fungsi Tangen ($y = \tan x$)
Domain (Daerah Asal) $x \in \mathbb{R}$ $x \in \mathbb{R}$ $x \neq \frac{\pi}{2} + k\pi \quad (k \in \mathbb{Z})$

Simetri Fungsi Fungsi Ganjil: $\sin(-x) = -\sin x$ Fungsi Genap: $\cos(-x) = \cos x$ Fungsi Ganjil: $\tan(-x) = -\tan x$

Karakteristik Khusus Grafik $y = \tan x$:

  • Karena $\tan x = \frac{\sin x}{\cos x}$, nilai fungsi tidak terdefinisi ketika penyebutnya bernilai nol ($\cos x = 0$).
  • Akibatnya, grafik $y = \tan x$ memiliki asimtot tegak (vertikal) pada garis $x = \pm 90^\circ, \pm 270^\circ, \dots$ atau $x = (2k + 1)\frac{\pi}{2}$.
  • Grafik selalu monoton naik di setiap interval di antara dua asimtot tegaknya dan berulang setiap periode $T = \pi = 180^\circ$.

2. Unsur-Unsur Transformasi Grafik Fungsi Trigonometri

Secara umum, fungsi trigonometri yang telah mengalami peregangan (dilatasi) dan pergeseran (translasi) dituliskan dalam bentuk umum: $$y = A \sin(kx \pm b) + C \quad \text{atau} \quad y = A \cos(kx \pm b) + C$$ Untuk membaca pergeseran horizontal dengan tepat, keluarkan koefisien $k$ terlebih dahulu sehingga bentuknya menjadi: $$y = A \sin\big(k(x - \alpha)\big) + C \quad \text{dengan } \alpha = \mp\frac{b}{k}$$

Berikut adalah arti geometris dari setiap parameter pada persamaan di atas (perhatikan anatomi gelombang di samping):

  1. Amplitudo ($|A|$): Simpangan terjauh gelombang dari garis setimbangnya: $$\text{Amplitudo} = |A| = \frac{y_{\text{maks}} - y_{\text{min}}}{2}$$ Catatan: Jika $A < 0$, grafik mengalami pencerminan (terbalik) terhadap garis tengahnya.
  2. Garis Tengah / Pergeseran Vertikal ($C$): Menggeser grafik ke atas ($C > 0$) atau ke bawah ($C < 0$): $$C = \frac{y_{\text{maks}} + y_{\text{min}}}{2}$$
  3. Nilai Maksimum & Minimum: $$y_{\text{maks}} = |A| + C \quad \text{dan} \quad y_{\text{min}} = -|A| + C$$
  4. Periode ($T$): Panjang satu gelombang penuh (untuk $\sin$ dan $\cos$): $$T = \frac{2\pi}{|k|} = \frac{360^\circ}{|k|} \iff |k| = \frac{2\pi}{T} = \frac{360^\circ}{T}$$ Sedangkan untuk fungsi tangen dan cotangen ($y = A \tan(kx \pm b) + C$), periodenya adalah: $$T_{\tan} = \frac{\pi}{|k|} = \frac{180^\circ}{|k|}$$
  5. Pergeseran Fase / Horizontal ($\alpha$): Pada bentuk $k(x - \alpha)$, jika $\alpha > 0$ (tanda di dalam kurung minus, yaitu $x - \alpha$), grafik bergeser ke kanan sejauh $\alpha$. Jika tanda di dalam kurung plus ($x + \alpha$), grafik bergeser ke kiri sejauh $\alpha$.
💡 Hubungan Cepat Jarak Antar Titik Ekstrem pada Grafik Sinus/Cosinus:
• Jarak horizontal antara dua puncak berurutan (atau dua lembah berurutan) adalah $1$ periode ($T$).
• Jarak horizontal antara puncak ke lembah terdekat adalah setengah periode ($\frac{1}{2}T$).
• Jarak horizontal antara puncak ke titik potong garis tengah terdekat adalah seperempat periode ($\frac{1}{4}T$).

3. Strategi Menyusun Persamaan dari Gambar Grafik

Jika di dalam soal diberikan gambar grafik gelombang dan kita diminta menentukan rumus fungsinya, ikuti 4 langkah sistematis berikut:

  1. Langkah 1 (Cari $A$ dan $C$ dari Puncak & Lembah):
    Baca nilai tertinggi $y_{\text{maks}}$ dan nilai terendah $y_{\text{min}}$ pada sumbu-$Y$, lalu hitung: $$|A| = \frac{y_{\text{maks}} - y_{\text{min}}}{2} \quad \text{dan} \quad C = \frac{y_{\text{maks}} + y_{\text{min}}}{2}$$
  2. Langkah 2 (Cari $k$ dari Periode $T$):
    Hitung panjang 1 gelombang penuh $T$ (atau gunakan $T = 2 \times |x_{\text{puncak}} - x_{\text{lembah}}|$), lalu tentukan $k = \frac{360^\circ}{T}$ atau $k = \frac{2\pi}{T}$.
  3. Langkah 3 (Pilih Acuan Awal Fase $x = \alpha$):
    Perhatikan titik awal gelombang yang paling mudah dibaca koordinatnya:
    • Jika memilih titik pada garis tengah $y = C$ yang sedang bergerak naik di $x = \alpha$, gunakan $+A \sin\big(k(x - \alpha)\big) + C$.
    • Jika memilih titik puncak maksimum $y = y_{\text{maks}}$ di $x = \alpha$, paling praktis gunakan $+A \cos\big(k(x - \alpha)\big) + C$.
    • Jika memilih titik lembah minimum $y = y_{\text{min}}$ di $x = \alpha$, gunakan $-A \cos\big(k(x - \alpha)\big) + C$.
  4. Langkah 4 (Uji Titik / Konversi Sudut Berelasi):
    Jika pilihan ganda meminta fungsi $\sin$ padahal kita menyusunnya dalam $\cos$, gunakan identitas konversi: $$\cos \theta = \sin(\theta + 90^\circ) \quad \text{atau} \quad -\cos \theta = \sin(\theta - 90^\circ)$$

4. Nilai Maksimum & Minimum Bentuk $y = a \cos x + b \sin x + c$

Dalam soal SNBT dan seleksi mandiri, fungsi trigonometri sering disajikan sebagai penjumlahan sinus dan cosinus dengan frekuensi yang sama: $$y = a \cos(kx) + b \sin(kx) + c$$ Bentuk $a \cos(kx) + b \sin(kx)$ dapat digabungkan menjadi gelombang tunggal $R \cos(kx - \alpha)$ dengan amplitudo gabungan $R = \sqrt{a^2 + b^2}$. Oleh karena itu, nilai ekstremnya dapat dihitung langsung tanpa perlu mencari sudut $\alpha$: $$y_{\text{maks}} = \sqrt{a^2 + b^2} + c \quad \text{dan} \quad y_{\text{min}} = -\sqrt{a^2 + b^2} + c$$

Contoh Soal & Pembahasan

No. 1
Diketahui fungsi trigonometri $f(x) = -3 \cos\left(2x - \frac{\pi}{3}\right) + 4$. Amplitudo ($A$), periode ($T$), nilai maksimum ($y_{\text{maks}}$), dan pergeseran fase horizontal dari grafik fungsi tersebut berturut-turut adalah ....
  1. $A = -3$, $T = \pi$, $y_{\text{maks}} = 7$, bergeser ke kanan sejauh $\frac{\pi}{3}$
  2. $A = 3$, $T = 2\pi$, $y_{\text{maks}} = 7$, bergeser ke kanan sejauh $\frac{\pi}{6}$
  3. $A = 3$, $T = \pi$, $y_{\text{maks}} = 7$, bergeser ke kanan sejauh $\frac{\pi}{6}$
  4. $A = 3$, $T = \pi$, $y_{\text{maks}} = 1$, bergeser ke kiri sejauh $\frac{\pi}{6}$
  5. $A = 3$, $T = \pi$, $y_{\text{maks}} = 7$, bergeser ke kanan sejauh $\frac{\pi}{3}$
Penyelesaian:

1. Faktorkan koefisien $k = 2$ di dalam tanda kurung terlebih dahulu agar bentuknya menjadi $A \cos\big(k(x - \alpha)\big) + C$: $$f(x) = -3 \cos\left(2\left(x - \frac{\pi}{6}\right)\right) + 4$$

2. Tentukan masing-masing unsur grafiknya:

  • Amplitudo: Selalu bernilai positif, yaitu $|A| = |-3| = 3$.
  • Periode: $T = \frac{2\pi}{|k|} = \frac{2\pi}{2} = \pi$.
  • Nilai Maksimum: $y_{\text{maks}} = |A| + C = 3 + 4 = 7$ (sedangkan $y_{\text{min}} = -3 + 4 = 1$).
  • Pergeseran Fase: Karena di dalam kurung berbentuk $\left(x - \frac{\pi}{6}\right)$, maka grafik bergeser ke kanan sejauh $\frac{\pi}{6}$ (hati-hati: bukan $\frac{\pi}{3}$!).
Jadi, unsurnya adalah $A = 3$, $T = \pi$, $y_{\text{maks}} = 7$, dan bergeser ke kanan sejauh $\frac{\pi}{6}$ (Jawaban C).
No. 2
Suatu grafik fungsi sinus/cosinus mencapai titik puncak maksimum di koordinat $(15^\circ, 5)$ dan mencapai titik lembah minimum terdekatnya di koordinat $(75^\circ, -1)$. Persamaan yang menyatakan grafik fungsi tersebut adalah ....
  1. $y = 3 \cos(3x - 45^\circ) + 2$
  2. $y = 3 \cos(3x + 45^\circ) + 2$
  3. $y = 3 \cos(6x - 90^\circ) + 2$
  4. $y = 2 \cos(3x - 45^\circ) + 3$
  5. $y = 3 \sin(3x - 45^\circ) + 2$
Penyelesaian:

1. Hitung Amplitudo ($A$) dan Pergeseran Vertikal ($C$):
Diketahui $y_{\text{maks}} = 5$ dan $y_{\text{min}} = -1$: $$A = \frac{y_{\text{maks}} - y_{\text{min}}}{2} = \frac{5 - (-1)}{2} = 3$$ $$C = \frac{y_{\text{maks}} + y_{\text{min}}}{2} = \frac{5 + (-1)}{2} = 2$$

2. Hitung Periode ($T$) dan Koefisien $k$:
Jarak horizontal dari puncak ke lembah terdekat adalah setengah periode ($\frac{1}{2}T$): $$\frac{1}{2}T = 75^\circ - 15^\circ = 60^\circ \implies T = 120^\circ$$ Maka nilai $k$ adalah: $$k = \frac{360^\circ}{T} = \frac{360^\circ}{120^\circ} = 3$$

3. Susun Persamaan Fungsi:
Karena grafik mencapai puncak maksimum di $x = \alpha = 15^\circ$, gunakan bentuk cosinus positif: $$y = A \cos\big(k(x - \alpha)\big) + C$$ $$y = 3 \cos\big(3(x - 15^\circ)\big) + 2 = 3 \cos(3x - 45^\circ) + 2$$

Jadi, persamaan grafik fungsi tersebut adalah $y = 3 \cos(3x - 45^\circ) + 2$ (Jawaban A).
No. 3
Jika grafik fungsi $y = a \sin(bx) + c$ dengan $a, b > 0$ memiliki periode $\frac{\pi}{2}$, nilai maksimum $8$, dan nilai minimum $-2$, maka nilai dari $a + 2b + c$ adalah ....
  1. $12$
  2. $14$
  3. $16$
  4. $18$
  5. $20$
Penyelesaian:

1. Karena $a > 0$, kita dapat langsung menghitung $a$ dan $c$ dari nilai maksimum ($8$) dan nilai minimum ($-2$): $$a = \frac{y_{\text{maks}} - y_{\text{min}}}{2} = \frac{8 - (-2)}{2} = \frac{10}{2} = 5$$ $$c = \frac{y_{\text{maks}} + y_{\text{min}}}{2} = \frac{8 + (-2)}{2} = \frac{6}{2} = 3$$

2. Karena $b > 0$ dan periode fungsi sinus adalah $T = \frac{2\pi}{b} = \frac{\pi}{2}$, maka: $$\frac{2\pi}{b} = \frac{\pi}{2} \implies b = 4$$

3. Hitung nilai dari $a + 2b + c$: $$a + 2b + c = 5 + 2(4) + 3 = 5 + 8 + 3 = 16$$

Jadi, nilai dari $a + 2b + c$ adalah $16$ (Jawaban C).
No. 4
Jumlah dari nilai maksimum dan dua kali nilai minimum dari fungsi $f(x) = 8 \cos x - 6 \sin x + 5$ untuk $x \in \mathbb{R}$ adalah ....
  1. $-5$
  2. $0$
  3. $5$
  4. $10$
  5. $15$
Penyelesaian:

1. Fungsi $f(x) = 8 \cos x - 6 \sin x + 5$ berbentuk $a \cos x + b \sin x + c$ dengan $a = 8$, $b = -6$, dan $c = 5$.

2. Hitung amplitudo gabungan $R = \sqrt{a^2 + b^2}$: $$R = \sqrt{8^2 + (-6)^2} = \sqrt{64 + 36} = \sqrt{100} = 10$$

3. Tentukan nilai maksimum dan nilai minimum dari $f(x)$:

  • $y_{\text{maks}} = R + c = 10 + 5 = 15$
  • $y_{\text{min}} = -R + c = -10 + 5 = -5$

4. Hitung nilai dari $y_{\text{maks}} + 2 y_{\text{min}}$: $$y_{\text{maks}} + 2 y_{\text{min}} = 15 + 2(-5) = 15 - 10 = 5$$

Jadi, hasil dari $y_{\text{maks}} + 2 y_{\text{min}}$ adalah $5$ (Jawaban C).
