Tentukan nilai dari \[S = 1 + 2\cdot2 + 3\cdot2^2 + 4\cdot2^3 + \cdots + 2022\cdot2^{2021}\]
  1. \(2^{2022}\)
  2. \(2021\cdot2^{2022} - 1\)
  3. \(2021\cdot2^{2022}\)
  4. \(2021\cdot2^{2022} + 1\)
  5. \(2^{2022} - 1\)
Matematika Zone Id
Pembahasan:
\(\begin{aligned} S&=1+2\cdot2+3\cdot2^2+4\cdot2^3+\cdots+2022\cdot2^{2021}\\ 2S&=1\cdot2+2\cdot2^2+3\cdot2^3+\cdots+2021\cdot2^{2021}+2022\cdot2^{2022}&{\color{red}-}\\\hline -S&=1+2+2^2+2^3+\cdots+2^{2021}-2022\cdot2^{2022}\\[4pt] &=\dfrac{1\left(2^{2022}-1\right)}{2-1}-2022\cdot2^{2022}\\[4pt] &=2^{2022}-1-2022\cdot2^{2022}\\[4pt] &=-2021\cdot2^{2022}-1\\[4pt] S&=\color{blue}\boxed{\boxed{\color{black}2021\cdot2^{2022}+1}} \end{aligned}\)
Jadi, \(S = 2021\cdot2^{2022} + 1\).

Pembahasan:
Tinjau bentuk suku ke-\(k\): \(\begin{aligned} \dfrac{(2k+1)^2+1}{(2k+1)^2-1}&=\dfrac{4k^2+4k+1+1}{4k^2+4k+1-1}\\[4pt] &=\dfrac{4k^2+4k+2}{4k^2+4k}\\[4pt] &=\dfrac{2k^2+2k+1}{2k^2+2k}\\[4pt] &=1+\dfrac1{2k^2+2k}\\[4pt] &=1+\dfrac1{2k(k+1)}\\[4pt] &=1+\dfrac12\left(\dfrac1k-\dfrac1{k+1}\right) \end{aligned}\)

Karena \(99 = 2(49) + 1\), maka deret tersebut dijumlahkan dari \(k = 1\) hingga \(k = 49\):

\(\begin{aligned} \dfrac{3^2+1}{3^2-1}+\dfrac{5^2+1}{5^2-1}+\dots+\dfrac{99^2+1}{99^2-1}&=1+\dfrac12\left(\dfrac11-\dfrac12+\dfrac12-\dfrac13+\dots+\dfrac1{49}-\dfrac1{50}\right)\\[4pt] &=1+\dfrac12\left(1-\dfrac1{50}\right)\\[4pt] &=1+\dfrac12\left(\dfrac{49}{50}\right)\\[4pt] &=1+\dfrac{49}{100}\\[4pt] &=\color{blue}\boxed{\boxed{\color{black}\dfrac{149}{100}}} \end{aligned}\)
Jadi, nilai deret tersebut adalah \(\dfrac{149}{100}\).

Bilangan-bilangan bulat positif \(a_k\), \(k = 1, 2, \dots, 8\) memenuhi persamaan \(\displaystyle\sum_{k=1}^8(k\times a_k)^2=204\). Hasil dari \(\displaystyle\sum_{k=1}^8 a_k\) adalah ....
  1. 6
  2. 7
  3. 8
  4. 10
  5. 12
Matematika Zone Id
Pembahasan:
Perhatikan jumlah kuadrat 8 bilangan asli pertama: \(\begin{aligned} \sum_{k=1}^8 k^2&=\dfrac{8(8+1)(2\cdot8+1)}6\\[4pt] &=\dfrac{8\cdot9\cdot17}6\\[4pt] &=204 \end{aligned}\)

Karena \(a_k\) adalah bilangan bulat positif (\(a_k \ge 1\)) dan \(\sum_{k=1}^8 k^2 = 204\), maka agar: \[\sum_{k=1}^8(k\times a_k)^2 = 204\] haruslah \(a_k = 1\) untuk setiap \(1 \le k \le 8\).

Sehingga: \(\begin{aligned} \sum_{k=1}^8 a_k&=1\cdot8\\[4pt] &=\color{blue}\boxed{\boxed{\color{black}8}} \end{aligned}\)
Jadi, \(\displaystyle\sum_{k=1}^8 a_k = 8\).

Tentukan bentuk umum barisan yang didefinisikan oleh x0 = 3, x1 = 4, dan \[x_{n+1} = x_{n-1}^2 - n x_n\] untuk semua \(n \in \mathbb{N}\).
101 Problems in Algebra
Pembahasan:
Kita dapat membuktikan dengan induksi matematika bahwa \(x_n = n + 3\).

Langkah Dasar:
Untuk \(n = 0\): \(x_0 = 0 + 3 = 3\) (benar).
Untuk \(n = 1\): \(x_1 = 1 + 3 = 4\) (benar).

Langkah Induksi:
Asumsikan rumus benar untuk \(n = k - 1\) dan \(n = k\), yaitu: \(x_{k-1} = k + 2\) dan \(x_k = k + 3\).
Maka untuk \(n = k + 1\): \(\begin{aligned} x_{k+1} &= x_{k-1}^2 - k x_k\\[4pt] &= (k+2)^2 - k(k+3)\\[4pt] &= (k^2+4k+4) - (k^2+3k)\\[4pt] &= k + 4\\[4pt] &= (k+1) + 3 \end{aligned}\)
Terbukti benar untuk setiap \(n \in \mathbb{N}\).
Jadi, bentuk umum barisan tersebut adalah xn = n + 3.

Pembahasan:
Substitusikan \(n = 1\):

  • Pilihan D: Untuk \(n = 1\) (ganjil), \(U_1 = 1\) (sesuai)
Hanya opsi C yang tidak menghasilkan barisan yang dimaksud.
Jadi, rumus yang tidak sesuai adalah \(U_n = \sin(n-1)\pi\).

Perhatikan gambar pola bulatan berikut:
Banyaknya bulatan hitam pada gambar kesepuluh nantinya adalah ....
OSK SMP 2003
Pembahasan:
Banyak bulatan hitam pada gambar ke-\(n\) memiliki pola: \[U_n = 4 + (n - 1)^2\] Maka banyak bulatan hitam pada gambar ke-10 adalah: \(\begin{aligned} U_{10}&=4 + (10 - 1)^2\\ &=4 + 9^2\\ &=4 + 81\\ &=\color{blue}\boxed{\boxed{\color{black}85}} \end{aligned}\)
Jadi, banyaknya bulatan hitam pada gambar kesepuluh nantinya adalah 85.
