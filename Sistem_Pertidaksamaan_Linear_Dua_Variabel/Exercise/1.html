  3. 6x + 5y ≤ 30; x − y ≤ −1; x ≤ 3; y ≥ 0

  5. 5x + 6y ≥ 30; −x + y ≥ −1; x ≤ 3; y ≥ 0
USP SMK Kab. Tangerang 2023
ALTERNATIF PENYELESAIAN

Persamaan Garis I : melalui (0,5) dan (6,0)

5x + 6y ⋯ 30
Koefisien y positif. Dari garis, DP berada di atas, sehingga tandanya adalah ≥.
5x + 6y ≥ 30

Persamaan Garis II: melalui (0,−1) dan (1,0)

−x + y ⋯ −1
Koefisien y positif. Dari garis, DP berada di atas, sehingga tandanya adalah ≥.
−x + y ≥ −1

Persamaan Garis III: Garis vertikal memotong sumbu x di (3,0)

x ⋯ 3
Dari garis, DP berada di kiri, sehingga tandanya adalah ≤.
x ≤ 3

Berada di atas sumbu x

DP seluruhnya berada di atas sumbu x, sehingga y ≥ 0
Jadi, sistem pertidaksamaan linier yang memenuhi daerah penyelesaian pada sketsa grafik di atas adalah 5x + 6y ≥ 30; −x + y ≥ −1; x ≤ 3; y ≥ 0.
