Persamaan grafik fungsi kuadrat yang memiliki koordinat titik balik \(P(-2, 4)\) dan melalui titik \(A(-3, 1)\) adalah ....

  1. \(y = -3(x + 2)^2 + 4\)
  2. \(y = -2(x + 2)^2 + 4\)
  3. \(y = (x + 2)^2 + 4\)
  4. \(y = 2(x + 2)^2 + 4\)
  5. \(y = 3(x + 2)^2 + 4\)
Matematika Zone Indonesia
Pembahasan:
Titik balik (-2, 4)
\(\begin{aligned} y&=a\left(x-x_p\right)^2+y_p\\ y&=a\left(x-(-2)\right)^2+4\\ y&=a\left(x+2\right)^2+4 \end{aligned}\)

Jadi, persamaan grafik fungsi kuadratnya adalah \(y = -3(x + 2)^2 + 4\).

Grafik fungsi kuadrat y = f (x) mempunyai titik puncak (-2, 11) dan grafik memotong sumbu x di titik (-5, 0) dan (a, 0), maka nilai 8a + 2 =

  1. 6
  2. 7
  3. 8
  4. 9
  5. 10
Matematika Zone Indonesia
Pembahasan:
\(\begin{aligned} -5+a&=2(-2)\\ -5+a&=-4\\ a&=-4+5\\ &=1 \end{aligned}\)

Jadi, 8a + 2 = 10.

Koordinat titik puncak grafik f (x) = ax2 + bx + c adalah (1, 1). Jika f (0) = 3, maka nilai a + b + c adalah

  1. 4
  2. 3
  3. 2
  4. 1
  5. 0
Matematika Zone Indonesia
Pembahasan:
\(\begin{aligned} f(1)&=1\\ a(1)^2+b(1)+c&=1\\ a+b+c&=\boxed{\boxed{1}} \end{aligned}\)
Jadi, a + b + c = 1.
JAWAB: D

Titik (a, b) terletak pada grafik y = bx2 + (1 - b2)x - 56. Jika a - b = 7, maka nilai ab adalah

  1. 7
  2. 5
  3. 1
  4. -1
  5. -5
Grup Whatsapp
Pembahasan:
\(\begin{aligned} b&=b(a)^2+\left(1-b^2\right)a-56\\ b&=a^2b+a-ab^2-56\\ 56&=a-b+a^2b-ab^2\\ &=a-b+ab(a-b)\\ &=(a-b)(ab+1)\\ &=7(ab+1)\\ 8&=ab+1\\ ab&=\color{blue}\boxed{\boxed{\color{black}7}} \end{aligned}\)
Jadi, ab = 7.
JAWAB: A

Jika fungsi kuadrat y = f (x) mencapai minimum di titik (1,-4) dan f (4) = 5, maka f (x) =

  1. x2 + 2x + 3
  2. x2 - 2x + 3
  3. x2 - 2x - 3
  4. -x2 + 2x + 3
  5. -x2 + 2x - 3
Matematika Zone Indonesia
Pembahasan:
mencapai minimum berarti x2 positif. Dari semua pilihan jawaban, yang x2 nya positif, a = 1.
\(\begin{aligned} y&=(x-x_p)^2-y_p\\ &=(x-1)^2-4\\ &=x^2-2x+1-4\\ &=\boxed{\boxed{x^2-2x-3}} \end{aligned}\)
Jadi, x2 - 2x - 3.
JAWAB: C

Koordinat titik puncak grafik fungsi y = 4x2 + 12x + 6 adalah ....

  1. \(\left(1\dfrac12,3\right)\)
  2. \(\left(1\dfrac12,-3\right)\)
  3. \(\left(-1\dfrac12,3\right)\)
  4. \(\left(-1\dfrac12,-3\right)\)
Matematika Zone Indonesia
Pembahasan:
a = 4, b = 12, c = 6

\(\begin{aligned} x_p&=\dfrac{-b}{2a}\\ &=\dfrac{-12}{2(4)}\\ &=-\dfrac32\\ &=-1\dfrac12 \end{aligned}\)
Jadi, titik puncaknya adalah \(\left(-1\dfrac12,3\right)\).
JAWAB: D

Diberikan sebuah grafik sebagai berikut. Maka persamaan yang dapat dibentuk dari grafik tersebut adalah.....

  1. y = x2 - x + 6
  2. y = x2 + x + 6
  3. y = x2 - x - 6
  4. y = x2 - 2x - 6
  5. y = x2 + 2x - 6
USP 2024 SMK Kab. Tangerang
Pembahasan:
Titik puncak: (1, -7)
\(\begin{aligned} y&=a\left(x-x_p\right)^2+y_p\\ &=a\left(x-1\right)^2-7 \end{aligned}\)

Melalui (0, -6)
\(\begin{aligned} -6&=a(0-1)^2-7\\ -6&=a-7\\ a&=1 \end{aligned}\)

Jadi, persamaan yang dapat dibentuk dari grafik tersebut adalah y = x2 - 2x - 6.
JAWAB: D

Persamaan sumbu simetri parabola y = 8 - 2x - x2 adalah

Matematika Zone Indonesia
Pembahasan:
a = -1, b = -2, c = 8

\(\begin{aligned} x&=\dfrac{-b}{2a}\\ &=\dfrac{-(-2)}{2(-1)}\\ &=\dfrac2{-2}\\ &=-1 \end{aligned}\)
Jadi, persamaan sumbu simetri parabola y = 8 - 2x - x2 adalah x= -1.

Jika nilai ekstrem fungsi y = x2 + nx + (11 + n) adalah 3, maka harga n = ....

  1. 4
  2. 8
  3. 4 atau -8
  4. 4 atau 8
  5. -4 atau 8
Big Book Matematika SMA
Pembahasan:
\(\begin{aligned} \dfrac{D}{-4a}&=3\\[4pt] \dfrac{b^2-4ac}{-4a}&=3\\[4pt] \dfrac{n^2-4(1)(11+n)}{-4(1)}&=3\\[4pt] n^2-44-4n&=-12\\ n^2-4n-32&=0\\ (n+4)(n-8)&=0 \end{aligned}\)
\(n = -4\) atau \(n = 8\).
Jadi, harga n = -4 atau 8.

Persamaan grafik fungsi kuadrat pada gambar di bawah ini adalah ....

  1. 3y = x2 - 8x + 13
  2. 3y = x2 - 8x + 15
  3. 3y = x2 - 8x + 17
  4. y = 2x2 - 16x + 31
  5. 3y = x2 - 8x + 19
USP SMK Kab. Tangerang 2023
Pembahasan:
Titik puncaknya adalah (4, -1)
y = a(x - 4)2 - 1

Melalui titik (1, 2)
\(\begin{aligned} 2&=a(1-4)^2-1\\ 2+1&=a(-3)^2\\ 3&=9a\\ a&=\dfrac39\\ a&=\boxed{\dfrac13} \end{aligned}\)

\(\begin{aligned} y&=\dfrac13(x-4)^2-1&{\color{red}\times3}\\ 3y&=(x-4)^2-3\\ &=x^2-8x+16-3\\ &=x^2-8x+13 \end{aligned}\)
Jadi, pPersamaan grafik fungsi kuadrat pada gambar di atas adalah 3y = x2 - 8x + 13.
JAWAB: A
