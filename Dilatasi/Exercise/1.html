Bayangan lingkaran \((x - 2)^2 + (y - 1)^2 = 4\) yang didilatasi dengan pusat \(O(0, 0)\) dan faktor skala \(2\) adalah ....

  1. \((2x - 2)^2 + (2y - 1)^2 = 4\)
  2. \((2x - 2)^2 + (2y - 1)^2 = 8\)
  3. \(\left(\dfrac{1}{2}x - 2\right)^2 + \left(\dfrac{1}{2}y - 1\right)^2 = 4\)
  4. \(\left(\dfrac{1}{2}x - 2\right)^2 + \left(\dfrac{1}{2}y - 1\right)^2 = -8\)
SKMP September 2002
Pembahasan:

Persamaan transformasi dilatasi terhadap pusat \(O(0, 0)\) dengan faktor skala \(k = 2\) adalah:

\[ \begin{aligned} \begin{pmatrix}x'\\y'\end{pmatrix} &= 2\begin{pmatrix}x\\y\end{pmatrix} \\[8pt] \begin{pmatrix}x\\y\end{pmatrix} &= \dfrac{1}{2}\begin{pmatrix}x'\\y'\end{pmatrix} = \begin{pmatrix}\dfrac{1}{2}x'\\[8pt]\dfrac{1}{2}y'\end{pmatrix} \end{aligned} \]

Diperoleh:

\[ x = \dfrac{1}{2}x' \quad \text{dan} \quad y = \dfrac{1}{2}y' \]

Substitusikan nilai \(x\) dan \(y\) ke dalam persamaan lingkaran awal:

\[ \begin{aligned} (x - 2)^2 + (y - 1)^2 &= 4 \\[8pt] \left(\dfrac{1}{2}x' - 2\right)^2 + \left(\dfrac{1}{2}y' - 1\right)^2 &= 4 \end{aligned} \]

Dengan mengganti kembali variabel \(x'\) dan \(y'\) menjadi \(x\) dan \(y\), diperoleh persamaan bayangan:

\[ \left(\dfrac{1}{2}x - 2\right)^2 + \left(\dfrac{1}{2}y - 1\right)^2 = 4 \]
Jadi, bayangan lingkaran tersebut adalah \(\left(\dfrac{1}{2}x - 2\right)^2 + \left(\dfrac{1}{2}y - 1\right)^2 = 4\).

Pembahasan:

Rumus dilatasi titik \((x, y)\) terhadap pusat \((a, b)\) dengan faktor skala \(k\) adalah:

\[ \begin{pmatrix}x'\\y'\end{pmatrix} = k\begin{pmatrix}x - a\\y - b\end{pmatrix} + \begin{pmatrix}a\\b\end{pmatrix} \]

Diketahui titik \(G(x, y) = (0, 3)\), titik pusat \(B(a, b) = (1, 2)\), dan faktor skala \(k = 4\):

\[ \begin{aligned} \begin{pmatrix}x'\\y'\end{pmatrix} &= 4\begin{pmatrix}0 - 1\\3 - 2\end{pmatrix} + \begin{pmatrix}1\\2\end{pmatrix} \\[8pt] &= 4\begin{pmatrix}-1\\1\end{pmatrix} + \begin{pmatrix}1\\2\end{pmatrix} \\[8pt] &= \begin{pmatrix}-4\\4\end{pmatrix} + \begin{pmatrix}1\\2\end{pmatrix} \\[8pt] &= \begin{pmatrix}-3\\6\end{pmatrix} \end{aligned} \]
Jadi, koordinat bayangan titik \(G\) adalah \(G'(-3, 6)\).

Pembahasan:

Hubungan dilatasi dengan pusat \(O(0, 0)\) dan faktor skala \(k = 3\):

\[ \begin{pmatrix}x'\\y'\end{pmatrix} = 3\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}3x\\3y\end{pmatrix} \]

Maka diperoleh:

\[ \begin{aligned} x' &= 3x \implies x = \dfrac{x'}{3} \\[6pt] y' &= 3y \implies y = \dfrac{y'}{3} \end{aligned} \]

Substitusikan \(x\) dan \(y\) ke persamaan garis semula:

\[ \begin{aligned} 6x + 9y - 30 &= 0 \\[6pt] 6\left(\dfrac{x'}{3}\right) + 9\left(\dfrac{y'}{3}\right) - 30 &= 0 \\[6pt] 2x' + 3y' - 30 &= 0 \end{aligned} \]
Jadi, persamaan garis bayangannya adalah \(2x + 3y - 30 = 0\).

Pembahasan:

Hubungan dilatasi terhadap pusat \(O(0, 0)\) dengan faktor skala \(k = 2\):

\[ \begin{pmatrix}x'\\y'\end{pmatrix} = 2\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}2x\\2y\end{pmatrix} \]

Maka diperoleh:

\[ x = \dfrac{x'}{2} \quad \text{dan} \quad y = \dfrac{y'}{2} \]

Substitusikan ke persamaan garis awal:

\[ \begin{aligned} x + y - 6 &= 0 \\[6pt] \dfrac{x'}{2} + \dfrac{y'}{2} - 6 &= 0 \end{aligned} \]

Kalikan kedua ruas dengan \(2\):

\[ x' + y' - 12 = 0 \]
Jadi, persamaan garis bayangannya adalah \(x + y - 12 = 0\).

Latihan Pra UKK Semester Genap Kelas XI
Pembahasan:

Menggunakan rumus dilatasi titik \((x, y)\) terhadap pusat \((a, b)\) dengan faktor skala \(k\):

\[ \begin{pmatrix}x'\\y'\end{pmatrix} = k\begin{pmatrix}x - a\\y - b\end{pmatrix} + \begin{pmatrix}a\\b\end{pmatrix} \]

Diketahui titik \(G(0, 3)\), titik pusat \(B(1, 2)\), dan \(k = 3\):

\[ \begin{aligned} \begin{pmatrix}x'\\y'\end{pmatrix} &= 3\begin{pmatrix}0 - 1\\3 - 2\end{pmatrix} + \begin{pmatrix}1\\2\end{pmatrix} \\[8pt] &= 3\begin{pmatrix}-1\\1\end{pmatrix} + \begin{pmatrix}1\\2\end{pmatrix} \\[8pt] &= \begin{pmatrix}-3\\3\end{pmatrix} + \begin{pmatrix}1\\2\end{pmatrix} \\[8pt] &= \begin{pmatrix}-2\\5\end{pmatrix} \end{aligned} \]
Jadi, koordinat bayangan titik \(G\) adalah \(G'(-2, 5)\).
