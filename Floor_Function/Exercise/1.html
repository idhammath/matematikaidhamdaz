Berikut adalah soal tingkat ... materi Floor Function

Jika \(\lfloor x \rfloor\) menyatakan fungsi bilangan bulat terbesar (floor function) yang kurang dari atau sama dengan \(x\), maka nilai dari ekspresi berikut:

\[ \lfloor 3{,}7 \rfloor + \lfloor -2{,}3 \rfloor + \lfloor \sqrt{50} \rfloor - \lfloor -\pi \rfloor \]

adalah ....

  1. 7
  2. 9
  3. 11
  4. 13
  5. 15
Latihan Dasar
Pembahasan:

Definisi: Fungsi tangga bawah (floor function) \(\lfloor x \rfloor\) didefinisikan sebagai bilangan bulat terbesar \(k \in \mathbb{Z}\) sedemikian sehingga:

\[ k \le x < k + 1 \]

Mari kita evaluasi masing-masing suku:

  • Evaluasi \(\lfloor 3{,}7 \rfloor\):
    Karena \(3 \le 3{,}7 < 4\), maka: \[\lfloor 3{,}7 \rfloor = 3\]
  • Evaluasi \(\lfloor -2{,}3 \rfloor\):
    Pada bilangan negatif, perhatikan garis bilangan di mana bilangan bulat terbesar di sebelah kiri \(-2{,}3\) adalah \(-3\): \[-3 \le -2{,}3 < -2 \implies \lfloor -2{,}3 \rfloor = -3\]
  • Evaluasi \(\lfloor \sqrt{50} \rfloor\):
    Kita ketahui bahwa \(7^2 = 49 < 50 < 64 = 8^2\), sehingga \(7 < \sqrt{50} < 8\): \[7 \le \sqrt{50} < 8 \implies \lfloor \sqrt{50} \rfloor = 7\]
  • Evaluasi \(\lfloor -\pi \rfloor\):
    Karena nilai \(\pi \approx 3{,}14159\dots\), maka \(-\pi \approx -3{,}14159\dots\): \[-4 \le -\pi < -3 \implies \lfloor -\pi \rfloor = -4\]

Substitusikan seluruh nilai ke dalam ekspresi:

\[ \begin{aligned} \lfloor 3{,}7 \rfloor + \lfloor -2{,}3 \rfloor + \lfloor \sqrt{50} \rfloor - \lfloor -\pi \rfloor &= 3 + (-3) + 7 - (-4) \\ &= 0 + 7 + 4 \\ &= 11 \end{aligned} \]
Jadi, nilai dari ekspresi tersebut adalah 11.
