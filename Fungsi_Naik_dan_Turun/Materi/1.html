Ringkasan dan penjelasan lengkap materi Fungsi Naik Dan Fungsi Turun

1. Pengertian Kemonotonan Fungsi (Naik dan Turun)

Secara visual pada bidang koordinat Kartesius, grafik suatu fungsi $y = f(x)$ yang dibaca dari kiri ke kanan (nilai $x$ semakin membesar) dapat bergerak menanjak ke atas, menurun ke bawah, atau mendatar. Sifat perilaku grafik fungsi pada suatu selang (interval) ini disebut sebagai kemonotonan fungsi.

Misalkan fungsi $f$ terdefinisi pada suatu interval $I$. Ambil sembarang dua bilangan $x_1, x_2 \in I$ dengan $x_1 < x_2$, maka berlaku definisi formal berikut:

  • Fungsi Naik Murni (Strictly Increasing):
    Fungsi $f$ dikatakan naik pada interval $I$ jika untuk setiap $x_1 < x_2$ berlaku: $$f(x_1) < f(x_2)$$ Artinya, semakin besar nilai $x$, maka nilai fungsi $f(x)$ juga semakin besar (grafik bergerak menanjak dari kiri ke kanan).
  • Fungsi Turun Murni (Strictly Decreasing):
    Fungsi $f$ dikatakan turun pada interval $I$ jika untuk setiap $x_1 < x_2$ berlaku: $$f(x_1) > f(x_2)$$ Artinya, semakin besar nilai $x$, maka nilai fungsi $f(x)$ justru semakin kecil (grafik bergerak menurun dari kiri ke kanan).
  • Fungsi Tidak Pernah Turun & Tidak Pernah Naik:
    - Fungsi dikatakan tidak pernah turun (monoton naik) jika untuk $x_1 < x_2$ berlaku $f(x_1) \le f(x_2)$.
    - Fungsi dikatakan tidak pernah naik (monoton turun) jika untuk $x_1 < x_2$ berlaku $f(x_1) \ge f(x_2)$.

2. Uji Turunan Pertama untuk Fungsi Naik dan Turun

Dalam kalkulus diferensial, turunan pertama $f'(x)$ menyatakan gradien (kemiringan) garis singgung kurva $y = f(x)$ di titik berabsis $x$. Jika garis singgung miring ke kanan atas ($m > 0$), kurva sedang naik. Sebaliknya, jika garis singgung miring ke kanan bawah ($m < 0$), kurva sedang turun.

Misalkan fungsi $f(x)$ kontinu dan dapat diturunkan (diferensiabel) pada setiap titik di dalam interval $I$, maka berlaku teorema kemonotonan berikut:

Kondisi Turunan Pertama Status Grafik Fungsi $f(x)$ Arah Garis Singgung Kurva
$$f'(x) > 0$$ Fungsi Naik pada interval tersebut Miring ke kanan atas (gradien positif, $m > 0$)
$$f'(x) < 0$$ Fungsi Turun pada interval tersebut Miring ke kanan bawah (gradien negatif, $m < 0$)
$$f'(x) = 0$$ Titik Stasioner (fungsi tidak naik dan tidak turun sesaat) Mendatar / sejajar sumbu-$X$ (gradien nol, $m = 0$)
$$f'(x) \ge 0$$ Fungsi Tidak Pernah Turun Gradien positif atau nol ($m \ge 0$)
$$f'(x) \le 0$$ Fungsi Tidak Pernah Naik Gradien negatif atau nol ($m \le 0$)

3. Langkah-Langkah Menentukan Interval Fungsi Naik dan Turun

Untuk mencari batas-batas interval nilai $x$ di mana suatu fungsi $f(x)$ naik atau turun, ikuti prosedur sistematis berikut:

  1. Tentukan Domain: Perhatikan daerah asal fungsi $f(x)$ terlebih dahulu (terutama jika memuat pecahan atau akar).
  2. Cari Turunan Pertama: Tentukan rumus turunan pertama $f'(x)$.
  3. Cari Pembuat Nol / Titik Kritis: Selesaikan persamaan stasioner $f'(x) = 0$ (serta titik di mana $f'(x)$ tidak terdefinisi) untuk mendapatkan titik-titik batas pada garis bilangan.
  4. Uji Tanda pada Garis Bilangan: Plot titik-titik stasioner pada garis bilangan, lalu uji tanda positif ($+$) atau negatif ($-$) dari nilai $f'(x)$ pada masing-masing daerah interval:
    • Daerah bertanda positif ($+$) merupakan interval fungsi naik.
    • Daerah bertanda negatif ($-$) merupakan interval fungsi turun.

4. Syarat Fungsi Selalu Naik atau Selalu Turun pada $\mathbb{R}$

Dalam soal-soal seleksi seperti SNBT dan ujian mandiri, sering ditanyakan syarat parameter agar suatu fungsi polinomial berderajat tiga (kubik) $f(x) = ax^3 + bx^2 + cx + d$ (dengan $a \neq 0$) selalu naik atau selalu turun untuk semua bilangan real $x \in \mathbb{R}$.

Perhatikan bahwa turunan pertama dari fungsi kubik $f(x) = ax^3 + bx^2 + cx + d$ adalah fungsi kuadrat: $$f'(x) = 3ax^2 + 2bx + c = Ax^2 + Bx + C$$ dengan $A = 3a$, $B = 2b$, dan $C = c$. Agar $f(x)$ selalu naik atau selalu turun pada seluruh $x \in \mathbb{R}$, kita gunakan konsep definit pada fungsi kuadrat $f'(x)$ (dengan diskriminan $D_{f'} = B^2 - 4AC = (2b)^2 - 4(3a)(c)$):

Kondisi pada Seluruh $x \in \mathbb{R}$ Syarat Turunan $f'(x)$ Syarat Koefisien & Diskriminan $f'(x)$
Selalu Naik / Tidak Pernah Turun $$f'(x) \ge 0$$ $$a > 0 \quad \text{dan} \quad D_{f'} \le 0$$
Selalu Turun / Tidak Pernah Naik $$f'(x) \le 0$$ $$a < 0 \quad \text{dan} \quad D_{f'} \le 0$$
💡 Catatan Penting: Mengapa syarat diskriminan pada fungsi kubik yang selalu naik/turun boleh menggunakan $D_{f'} \le 0$ (tidak hanya $D_{f'} < 0$)? Karena ketika $D_{f'} = 0$, nilai $f'(x) = 0$ hanya terjadi di satu titik belok horizontal tunggal (misalnya pada $f(x) = x^3$ di titik $x = 0$), sehingga secara keseluruhan fungsi tetap naik murni untuk setiap $x_1 < x_2$. Namun, jika soal secara eksplisit meminta "grafik tidak memiliki titik stasioner", gunakan syarat tegas $D_{f'} < 0$.

5. Contoh Soal dan Pembahasan

Pelajari contoh-contoh soal berikut untuk memahami penerapan uji turunan pertama pada fungsi polinomial, fungsi trigonometri, serta penentuan batas parameter fungsi yang selalu naik/turun. Klik tombol Lihat Penyelesaian untuk membuka langkah pembahasannya.

Contoh 1
Diketahui fungsi polinomial derajat tiga $f(x) = x^3 - 3x^2 - 9x + 12$. Tentukan:
  1. Interval nilai $x$ agar fungsi $f(x)$ naik.
  2. Interval nilai $x$ agar fungsi $f(x)$ turun.
Penyelesaian:

Langkah pertama, kita tentukan turunan pertama $f'(x)$ dari fungsi $f(x) = x^3 - 3x^2 - 9x + 12$: $$f'(x) = 3x^2 - 6x - 9$$

Cari pembuat nol (titik stasioner) dengan menyelesaikan $f'(x) = 0$: $$3x^2 - 6x - 9 = 0 \quad (\text{bagi kedua ruas dengan } 3)$$ $$x^2 - 2x - 3 = 0$$ $$(x + 1)(x - 3) = 0$$ Diperoleh titik batas stasioner $x = -1$ atau $x = 3$.

Uji tanda $f'(x) = 3(x + 1)(x - 3)$ pada tiga interval yang terbentuk di garis bilangan:

  • Untuk $x < -1$ (ambil $x = -2$): $f'(-2) = 3(-1)(-5) = +15 > 0$ (Positif / Naik)
  • Untuk $-1 < x < 3$ (ambil $x = 0$): $f'(0) = 3(1)(-3) = -9 < 0$ (Negatif / Turun)
  • Untuk $x > 3$ (ambil $x = 4$): $f'(4) = 3(5)(1) = +15 > 0$ (Positif / Naik)

Jadi, fungsi $f(x)$ naik pada interval $x < -1$ atau $x > 3$, dan fungsi $f(x)$ turun pada interval $-1 < x < 3$.
Contoh 2
Tentukan batas-batas nilai parameter $p$ agar fungsi $f(x) = -\frac{1}{3}x^3 + px^2 - px + 5$ tidak pernah naik untuk setiap bilangan real $x \in \mathbb{R}$!
Penyelesaian:

Agar fungsi $f(x)$ tidak pernah naik untuk setiap $x \in \mathbb{R}$, maka turunan pertamanya harus selalu bernilai non-positif: $$f'(x) \le 0 \quad \text{untuk semua } x \in \mathbb{R}$$

Kita cari turunan pertama dari $f(x) = -\frac{1}{3}x^3 + px^2 - px + 5$: $$f'(x) = -x^2 + 2px - p$$ Dari bentuk kuadrat $f'(x) = Ax^2 + Bx + C$, diperoleh koefisien $A = -1$, $B = 2p$, dan $C = -p$.

Karena koefisien $A = -1 < 0$ sudah memenuhi syarat terbuka ke bawah, maka agar $f'(x) \le 0$ untuk semua $x \in \mathbb{R}$, diskriminan dari $f'(x)$ harus memenuhi $D_{f'} \le 0$: $$B^2 - 4AC \le 0$$ $$(2p)^2 - 4(-1)(-p) \le 0$$ $$4p^2 - 4p \le 0$$ $$4p(p - 1) \le 0$$

Pembuat nol pertidaksamaan kuadrat tersebut adalah $p = 0$ dan $p = 1$. Karena tanda pertidaksamaan adalah $\le 0$ dengan koefisien $p^2$ positif, maka penyelesaiannya berada di antara kedua akar.

Jadi, batas nilai $p$ agar fungsi tersebut tidak pernah naik untuk setiap $x \in \mathbb{R}$ adalah $0 \le p \le 1$.
Contoh 3
Diketahui fungsi trigonometri $f(x) = \sin(2x) - x$ pada interval tertutup $0 \le x \le \pi$. Tentukan pada interval mana fungsi $f(x)$ tersebut turun!
Penyelesaian:

Ingat bahwa turunan dari $\sin(ax)$ adalah $a\cos(ax)$. Maka turunan pertama dari fungsi $f(x) = \sin(2x) - x$ adalah: $$f'(x) = 2\cos(2x) - 1$$

Cari titik stasioner dengan menyamakan $f'(x) = 0$ pada domain $0 \le x \le \pi$ ($0 \le 2x \le 2\pi$): $$2\cos(2x) - 1 = 0 \implies \cos(2x) = \frac{1}{2}$$ Nilai sudut $2x$ di kuadran I dan IV yang memiliki nilai cosinus $\frac{1}{2}$ adalah: $$2x = \frac{\pi}{3} \implies x = \frac{\pi}{6}$$ $$2x = \frac{5\pi}{3} \implies x = \frac{5\pi}{6}$$

Selanjutnya, uji tanda $f'(x) = 2\cos(2x) - 1$ pada ketiga sub-interval di dalam $[0, \pi]$:

  • Pada $0 < x < \frac{\pi}{6}$ (uji $x = 0$): $f'(0) = 2\cos(0) - 1 = 1 > 0$ (Naik)
  • Pada $\frac{\pi}{6} < x < \frac{5\pi}{6}$ (uji $x = \frac{\pi}{2}$): $f'\left(\frac{\pi}{2}\right) = 2\cos(\pi) - 1 = 2(-1) - 1 = -3 < 0$ (Turun)
  • Pada $\frac{5\pi}{6} < x < \pi$ (uji $x = \pi$): $f'(\pi) = 2\cos(2\pi) - 1 = 1 > 0$ (Naik)

Jadi, pada domain $0 \le x \le \pi$, fungsi $f(x) = \sin(2x) - x$ turun pada interval $\dfrac{\pi}{6} < x < \dfrac{5\pi}{6}$.
