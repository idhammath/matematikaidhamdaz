Berikut adalah soal tingkat ... materi Fungsi Naik dan Turun

Diberikan fungsi kubik yang memuat parameter real \(m\):

\[ f(x) = \frac{1}{3}x^3 + (m - 1)x^2 + (m + 5)x - 7 \]

Fungsi \(f(x)\) selalu naik (monoton naik) untuk setiap bilangan real \(x \in \mathbb{R}\) jika dan hanya jika nilai \(m\) memenuhi ....

  1. \(m \le -1\) atau \(m \ge 4\)
  2. \(m < -1\) atau \(m > 4\)
  3. \(-1 < m < 4\)
  4. \(-1 \le m \le 4\)
  5. \(-4 \le m \le 1\)
Olimpiade / HOTS
Pembahasan:

Langkah 1: Menentukan turunan pertama fungsi \(f(x)\)

Fungsi kubik awal adalah:

\[ f(x) = \frac{1}{3}x^3 + (m - 1)x^2 + (m + 5)x - 7 \]

Turunan pertama terhadap \(x\):

\[ \begin{aligned} f'(x) &= 3 \cdot \frac{1}{3}x^2 + 2(m - 1)x + (m + 5) \\ &= x^2 + 2(m - 1)x + (m + 5) \end{aligned} \]

Langkah 2: Memahami syarat matematis fungsi selalu naik

Fungsi \(f(x)\) selalu monoton naik untuk setiap \(x \in \mathbb{R}\) jika turunan pertamanya tak-negatif untuk seluruh bilangan real:

\[ f'(x) \ge 0, \quad \forall x \in \mathbb{R} \]

Bentuk \(f'(x) = x^2 + 2(m - 1)x + (m + 5)\) adalah fungsi kuadrat \(Ax^2 + Bx + C\) dengan:

  • Koefisien \(A = 1 > 0\) (parabola membuka ke atas)
  • Koefisien \(B = 2(m - 1)\)
  • Konstanta \(C = m + 5\)

Agar fungsi kuadrat bernilai definit positif atau menyinggung sumbu-\(X\) (selalu \(\ge 0\)), nilai diskriminannya harus kurang dari atau sama dengan nol (\(D \le 0\)).

Langkah 3: Menyelesaikan pertidaksamaan diskriminan

\[ \begin{aligned} D &\le 0 \\ B^2 - 4AC &\le 0 \\ [2(m - 1)]^2 - 4(1)(m + 5) &\le 0 \\ 4(m - 1)^2 - 4(m + 5) &\le 0 \end{aligned} \]

Bagi kedua ruas dengan \(4\):

\[ \begin{aligned} (m - 1)^2 - (m + 5) &\le 0 \\ (m^2 - 2m + 1) - m - 5 &\le 0 \\ m^2 - 3m - 4 &\le 0 \end{aligned} \]

Faktorkan pertidaksamaan kuadrat tersebut:

\[ (m - 4)(m + 1) \le 0 \]

Pembuat nol adalah \(m = -1\) dan \(m = 4\). Karena koefisien \(m^2 > 0\) dan tanda pertidaksamaan adalah \(\le 0\), himpunan penyelesaiannya adalah interval tertutup di antara kedua pembuat nol:

\[ -1 \le m \le 4 \]
Jadi, fungsi \(f(x)\) selalu naik untuk setiap bilangan real \(x\) jika dan hanya jika \(-1 \le m \le 4\).
