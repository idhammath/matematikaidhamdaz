Diketahui polinomial berderajat 3 dengan koefisien \(x^3\) adalah 1. Jika \(f(1) = 1\), \(f(2) = 4\), \(f(3) = 9\), maka nilai \(f(4)\) adalah ....
Grup Matematika Idhamdaz
Pembahasan:
Perhatikan bahwa \(f(k) = k^2\) untuk \(k \in \{1, 2, 3\}\).
Karena \(f(x)\) berderajat 3 dengan koefisien \(x^3\) bernilai 1, maka kita dapat mendefinisikan: \[f(x) - x^2 = (x - 1)(x - 2)(x - 3)\] Sehingga: \[f(x) = (x - 1)(x - 2)(x - 3) + x^2\] Untuk menghitung nilai \(f(4)\), substitusikan \(x = 4\): \[\begin{aligned} f(4) &= (4 - 1)(4 - 2)(4 - 3) + 4^2\\ &= (3)(2)(1) + 16\\ &= 6 + 16 = 22 \end{aligned}\]
Jadi, nilai \(f(4)\) adalah 22.
Misal \(a\) dan \(b\) adalah bilangan real dengan \(b > 0\). Jika persamaan \(x^4 + ax^2 + b = 0\) mempunyai tepat 2 solusi real, nilai minimum \(a + 2b\) adalah .... , dan nilai maksimum dari \(\lceil a - b \rceil\) adalah ....
Grup Matematika Idhamdaz
Pembahasan:
Misalkan \(y = x^2 \ge 0\). Persamaan menjadi: \[y^2 + ay + b = 0\] Karena \(b > 0\), hasil kali akar-akar \(y_1 y_2 = b > 0\), yang berarti kedua akar \(y_1\) dan \(y_2\) memiliki tanda yang sama.
Agar persamaan \(x^4 + ax^2 + b = 0\) mempunyai tepat 2 solusi real, persamaan kuadrat dalam \(y\) harus memiliki akar kembar positif.

Syarat akar kembar: \[D = a^2 - 4b = 0 \iff b = \dfrac{a^2}{4}\] Dan agar akarnya positif: \(y = -\dfrac{a}{2} > 0 \implies a < 0\).

1. Mencari nilai minimum \(a + 2b\): \[\begin{aligned} a + 2b &= a + 2\left(\dfrac{a^2}{4}\right) = \dfrac{a^2}{2} + a\\ &= \dfrac{1}{2}(a^2 + 2a + 1) - \dfrac{1}{2}\\ &= \dfrac{1}{2}(a + 1)^2 - \dfrac{1}{2} \end{aligned}\] Nilai minimum tercapai saat \(a = -1\) (memenuhi \(a < 0\)), yaitu: \[(a + 2b)_{\min} = -\dfrac{1}{2}\] 2. Mencari nilai maksimum \(\lceil a - b \rceil\): \[\begin{aligned} a - b &= a - \dfrac{a^2}{4} = -\dfrac{1}{4}(a^2 - 4a + 4) + 1\\ &= -\dfrac{1}{4}(a - 2)^2 + 1 \end{aligned}\] Untuk interval \(a < 0\), nilai supremum mendekati 1.
Jadi, nilai minimum \(a + 2b\) adalah \(-\dfrac{1}{2}\), dan nilai maksimum dari \(\lceil a - b \rceil\) adalah 1.
Diberikan suku banyak dengan koefisien bilangan bulat \(P(x)\). Jika \[P(r_1) = P(r_2) = 220\] dengan \(r_1\) dan \(r_2\) merupakan akar-akar dari persamaan kuadrat \(x^2 + x - 25 = 0\), maka sisa pembagian \(P(1)\) oleh 23 adalah ....
Latihan Olimpiade
Pembahasan:
Karena \(r_1\) dan \(r_2\) adalah akar-akar dari \(x^2 + x - 25 = 0\), maka: \[P(x) = Q(x)(x^2 + x - 25) + 220\] Substitusikan \(x = 1\): \[\begin{aligned} P(1) &= Q(1)(1^2 + 1 - 25) + 220\\ &= -23 \cdot Q(1) + 220 \end{aligned}\] Sisa pembagian \(P(1)\) oleh 23: \[220 = 9 \times 23 + 13 \implies 220 \equiv 13 \pmod{23}\]
Jadi, sisa pembagian \(P(1)\) oleh 23 adalah 13.
Jika hasil kali dua akar persamaan \(x^4 - 18x^3 + kx^2 + 200x - 1984 = 0\) adalah \(-32\), maka nilai \(k = \dots.\)
Grup WhatsApp
Pembahasan:
Misalkan akar-akarnya adalah \(x_1, x_2, x_3, x_4\) dengan \(x_1 x_2 = -32\).

Berdasarkan Teorema Vieta:
  • \(x_1 + x_2 + x_3 + x_4 = 18\)
  • \(x_1 x_2 x_3 x_4 = -1984 \implies -32(x_3 x_4) = -1984 \implies x_3 x_4 = 62\)
  • \(x_1 x_2(x_3 + x_4) + x_3 x_4(x_1 + x_2) = -200\)
Substitusikan nilai ke persamaan ketiga: \[\begin{aligned} -32(x_3 + x_4) + 62(x_1 + x_2) &= -200\\ -16(x_3 + x_4) + 31(18 - (x_3 + x_4)) &= -100\\ -47(x_3 + x_4) &= -658\\ x_3 + x_4 &= 14 \end{aligned}\] Sehingga \(x_1 + x_2 = 18 - 14 = 4\).
Nilai koefisien \(k\): \[\begin{aligned} k &= x_1 x_2 + (x_1 + x_2)(x_3 + x_4) + x_3 x_4\\ &= -32 + (4)(14) + 62 = 86 \end{aligned}\]
Jadi, nilai \(k = 86\).
Diberikan polinomial: \[P(x) = (a + b)x^2 + bx - a - b\] dan \[Q(x) = cx^2 + (c + a)x - a - b - 2c\] Jika \(P(-2) = -2023\), tentukan nilai dari \(Q(-2)\).
KTOM September 2023
Pembahasan:
Hitung \(P(-2)\): \[\begin{aligned} P(-2) &= 4(a + b) - 2b - a - b\\ &= 3a + b = -2023 \end{aligned}\] Hitung \(Q(-2)\): \[\begin{aligned} Q(-2) &= 4c - 2(c + a) - a - b - 2c\\ &= -3a - b = -(3a + b)\\ &= -(-2023) = 2023 \end{aligned}\]
Jadi, \(Q(-2) = 2023\).
Misalkan: \[S = (x - 2)^4 + 8(x - 2)^3 + 24(x - 2)^2 + 32(x - 2) + 16\] Apakah \(S\) jika dituliskan dalam sesedikit mungkin suku penjumlahan?
OSP SMA 2002
Pembahasan:
Bentuk ini merupakan ekspansi Binomial Newton dari \(((x - 2) + 2)^4\): \[\begin{aligned} S &= \binom{4}{0}(x-2)^4 + \binom{4}{1}(x-2)^3(2) + \binom{4}{2}(x-2)^2(2^2) + \binom{4}{3}(x-2)(2^3) + \binom{4}{4}2^4\\ &= ((x - 2) + 2)^4\\ &= x^4 \end{aligned}\]
Jadi, \(S\) jika dituliskan dalam sesedikit mungkin suku penjumlahan adalah \(x^4\).
Polinomial kuartik (derajat 4) \(P(x)\) memenuhi \(P(1) = 0\) dan mencapai nilai maksimum 3 pada \(x = 2\) dan \(x = 3\). Hitung nilai dari \(P(5)\).
  1. \(-24\)
  2. \(-11\)
  3. \(-2\)
  4. 4
  5. 9
Kompetisi Sains Sigma Siswa SMA 2023
Pembahasan:
Bentuk umum polinomial yang menyinggung nilai maksimum 3 pada \(x = 2\) dan \(x = 3\): \[P(x) = a(x - 2)^2(x - 3)^2 + 3\] Dari \(P(1) = 0\): \[a(1 - 2)^2(1 - 3)^2 + 3 = 0 \implies 4a + 3 = 0 \implies a = -\dfrac{3}{4}\] Substitusikan \(x = 5\): \[\begin{aligned} P(5) &= -\dfrac{3}{4}(5 - 2)^2(5 - 3)^2 + 3\\ &= -\dfrac{3}{4}(9)(4) + 3\\ &= -27 + 3 = -24 \end{aligned}\]
Jadi, nilai \(P(5) = -24\).

Apabila hasil dari perkalian semua solusi real yang memenuhi: \[\prod_{k=1}^{2022}\left(x^2-73x+k\right)=0\] dapat dinyatakan dalam \(n!\) dengan \(n\) bilangan asli, maka nilai \(n\) adalah ....
Latihan OSK 2024 SMA
Pembahasan:
Agar persamaan \(x^2 - 73x + k = 0\) memiliki akar real: \[D = 73^2 - 4k \ge 0 \implies 4k \le 5329 \implies k \le 1332{,}25\] Maka \(k \in \{1, 2, \dots, 1332\}\).
Hasil kali semua solusi real: \[\prod_{k=1}^{1332} k = 1332!\] Diperoleh \(n = 1332\).
Jadi, nilai \(n\) adalah 1332.
Bilangan asli \(n\) dikatakan menarik jika terdapat suku banyak (polinom) dengan koefisien bulat \(P(x)\) sehingga \(P(7) = 2021\) dan \(P(n) = 2045\). Banyaknya bilangan prima menarik adalah ....
Latihan OSK 2024 SMA
Pembahasan:
Berdasarkan sifat keterbagian polinomial berkoefisien bulat: \[n - 7 \mid P(n) - P(7) \implies n - 7 \mid 2045 - 2021 = 24\] Faktor bulat dari 24 menghasilkan nilai asli \(n\): \[n \in \{1, 3, 4, 5, 6, 8, 9, 10, 11, 13, 15, 19, 31\}\] Nilai prima dari himpunan tersebut adalah: \[3, 5, 11, 13, 19, 31\] Terdapat 6 bilangan prima menarik.
Jadi, banyaknya bilangan prima menarik adalah 6.
Diberikan polinomial \(p(x) = x^3 + 3x^2 + 4x - 11\). Jika \(p(x)\) mempunyai akar-akar \(a, b,\) dan \(c\), dan polinomial \(q(x) = x^3 + rx^2 + sx + t\) mempunyai akar-akar \((a + b), (b + c),\) dan \((a + c)\), maka nilai dari \(t\) adalah ....
Evaluasi GMOM Februari 2024 tingkat SMA
Pembahasan:
Dari Teorema Vieta pada \(p(x)\):
  • \(a + b + c = -3\)
  • \(ab + bc + ca = 4\)
  • \(abc = 11\)
Karena \(a + b = -3 - c\), \(b + c = -3 - a\), dan \(a + c = -3 - b\): \[\begin{aligned} -t &= (a + b)(b + c)(a + c) = (-3 - c)(-3 - a)(-3 - b)\\ t &= (3 + a)(3 + b)(3 + c)\\ &= 3^3 + 3^2(a + b + c) + 3(ab + bc + ca) + abc\\ &= 27 + 9(-3) + 3(4) + 11\\ &= 23 \end{aligned}\]
Jadi, nilai dari \(t\) adalah 23.
