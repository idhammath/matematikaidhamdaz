Diberikan $f(x) = \sin^2 x$. Jika $f'(x)$ menyatakan turunan pertama dari $f(x)$, maka $\displaystyle\lim_{h\to\infty}h\left\{f'\left(x+\dfrac{1}{h}\right)-f'(x)\right\}=$ ....

  1. $\sin 2x$
  2. $-\cos 2x$
  3. $2\cos 2x$
  4. $2\sin x$
  5. $-2\cos x$
Sumber soal
Pembahasan:
$$\begin{aligned} f'(x)&=2\sin x\cos x\\ &=\sin 2x \end{aligned}$$

Misal $\dfrac{1}{h}=k$, maka untuk $h\to\infty$ berlaku $k\to 0$.

$$\begin{aligned} \lim_{h\to\infty}h\left\{f'\left(x+\dfrac{1}{h}\right)-f'(x)\right\}&=\lim_{k\to0}\dfrac{\sin2\left(x+k\right)-\sin2x}{k}\\[3.7pt] &=\lim_{k\to0}\dfrac{\sin(2x+2k)-\sin2x}{k}\\[3.7pt] &=\lim_{k\to0}\dfrac{\sin2x\cos2k+\cos2x\sin2k-\sin2x}{k}\\[3.7pt] &=\lim_{k\to0}\dfrac{\sin2x(\cos2k-1)+\cos2x\sin2k}{k}\\[3.7pt] &=\sin2x\lim_{k\to0}\dfrac{\cos2k-1}{k}+\cos2x\lim_{k\to0}\dfrac{\sin2k}{k}\\[3.7pt] &=\sin2x(0)+\cos2x(2)\\ &=\boxed{\boxed{2\cos2x}} \end{aligned}$$
Jadi, $\displaystyle\lim_{h\to\infty}h\left\{f'\left(x+\dfrac{1}{h}\right)-f'(x)\right\}=2\cos2x$. (JAWAB: C)

Fungsi $g(x) = x^3 + 3x - 2$ mempunyai invers $g^{-1}(x) = h(x)$, dan $g(1) = 2$. Nilai $h'(2) =$ ....

  1. $\dfrac{1}{3}$
  2. $\dfrac{1}{4}$
  3. $\dfrac{1}{5}$
  4. $\dfrac{1}{6}$
  5. $\dfrac{1}{7}$
Pembahasan:
$$\begin{aligned} g(x)&=x^3+3x-2\\ g^{-1}\left(x^3+3x-2\right)&=x\\ h\left(x^3+3x-2\right)&=x\\ \left(3x^2+3\right)\ h'\left(x^3+3x-2\right)&=1 \end{aligned}$$

Untuk $x = 1$,

$$\begin{aligned} \left(3(1)^2+3\right)\ h'\left((1)^3+3(1)-2\right)&=1\\ \left(3+3\right)\ h'\left(1+3-2\right)&=1\\ 6\ h'(2)&=1\\ h'(2)&=\boxed{\boxed{\dfrac{1}{6}}} \end{aligned}$$
Jadi, $h'(2)=\dfrac{1}{6}$. (JAWAB: D)

Misalkan $f(x) = |x|$ menghasilkan $f'(x)=\dfrac{|x|}{x}$ untuk $x \neq 0$. Jika $g(x) = |x|^2 + x|x|$, dengan $x \neq 0$, maka $g'(x) =$ ....

  1. $2x + 2|x|$
  2. $4x$
  3. $4|x|$
  4. $0$
  5. $-4x$
Pembahasan:
$$\begin{aligned} g(x)&=|x|^2+x|x|\\ g'(x)&=2|x|\dfrac{|x|}{x}+1\cdot|x|+x\dfrac{|x|}{x}\\[3.7pt] &=2\dfrac{|x|^2}{x}+|x|+|x|\\[3.7pt] &=2\dfrac{x^2}{x}+2|x|\\ &=\boxed{\boxed{2x+2|x|}} \end{aligned}$$
Jadi, $g'(x) = 2x + 2|x|$. (JAWAB: A)

Jika $f(x) = 2x^3 \cdot g(x)$, $g(1) = -2$, $g'(1) = 3$. Maka $f'(1) =$ ....

  1. $-6$
  2. $6$
  3. $0$
  4. $12$
  5. $-12$
Pembahasan:
$$\begin{aligned} f(x)&=2x^3\cdot g(x)\\ f'(x)&=6x^2\cdot g(x)+2x^3\cdot g'(x)\\ f'(1)&=6(1)^2\cdot g(1)+2(1)^3\cdot g'(1)\\ &=6\cdot(-2)+2\cdot 3\\ &=-12+6\\ &=\boxed{\boxed{-6}} \end{aligned}$$
Jadi, $f'(1) = -6$. (JAWAB: A)

Jika $f(x)=\sqrt{3x}\cdot g(x)$, $g(3) = 4$, $g'(3) = 2$, maka $f'(3) =$ ....

  1. $4$
  2. $6$
  3. $8$
  4. $2$
  5. $1$
Pembahasan:
$$\begin{aligned} f(x)&=\sqrt{3x}\cdot g(x)\\ f'(x)&=\dfrac{3}{2\sqrt{3x}}\cdot g(x)+\sqrt{3x}\cdot g'(x)\\ f'(3)&=\dfrac{3}{2\sqrt{3(3)}}\cdot g(3)+\sqrt{3(3)}\cdot g'(3)\\ &=\dfrac{3}{2(3)}\cdot (4)+3\cdot (2)\\ &=2+6\\ &=\boxed{\boxed{8}} \end{aligned}$$
Jadi, $f'(3) = 8$. (JAWAB: C)

Jika $f(x) = \cos x$ dan $g(x) = \csc x$, maka $\dfrac{d\left(g\circ f\right)(x)}{dx}=$ ....

  1. $-\sin x \sec(\cos x)$
  2. $\sin x \sec(\sin x)$
  3. $\sin x \csc(\cos x) \cot(\cos x)$
  4. $\sin x \csc(\sin x)$
  5. $-\sin x \sec(\sin x)$
Pembahasan:
$$\begin{aligned} f(x)&=\cos x\\ f'(x)&=-\sin x \end{aligned} \qquad \begin{aligned} g(x)&=\csc x\\ g'(x)&=-\csc x\cot x \end{aligned}$$ $$\begin{aligned} \dfrac{d\left(g\circ f\right)(x)}{dx}&=g'\left(f(x)\right)\cdot f'(x)\\ &=-\csc\left(f(x)\right)\cot\left(f(x)\right)(-\sin x)\\ &=\boxed{\boxed{\sin x\csc\left(\cos x\right)\cot\left(\cos x\right)}} \end{aligned}$$
Jadi, $\dfrac{d\left(g\circ f\right)(x)}{dx}=\sin x\csc\left(\cos x\right)\cot\left(\cos x\right)$. (JAWAB: C)

Diketahui $f$ dan $g$ memenuhi $f(x) \cdot g(x) = x^2 - 3x$ untuk setiap bilangan real $x$. Jika $g(1) = -2$, $f'(1) = f(1)$ dan $g'(1) = f(1)$, maka $g'(1) =$ ....

  1. $-2$
  2. $-1$
  3. $0$
  4. $1$
  5. $2$
SKMP Agustus 2020
Pembahasan:
$$\begin{aligned} f(x)\cdot g(x)&=x^2-3x\\ f(1)\cdot g(1)&=1^2-3(1)\\ f(1)\cdot(-2)&=1-3\\ -2f(1)&=-2\\ f(1)&=1 \end{aligned}$$

Sehingga $f'(1) = g'(1) = f(1) = 1$.

$$\begin{aligned} f(x)\cdot g(x)&=x^2-3x\\ \dfrac{d}{dx}\left(f(x)\cdot g(x)\right)&=\dfrac{d}{dx}\left(x^2-3x\right)\\ f'(x)\cdot g(x)+f(x)\cdot g'(x)&=2x-3\\ f'(1)\cdot g(1)+f(1)\cdot g'(1)&=2(1)-3\\ 1\cdot(-2)+1\cdot g'(1)&=2-3\\ -2+g'(1)&=-1\\ g'(1)&=\boxed{\boxed{1}} \end{aligned}$$
Jadi, $g'(1) = 1$. (JAWAB: D)
