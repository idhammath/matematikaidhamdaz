Berikut adalah soal tingkat ... materi Integral Trigonometri Tak Tentu

Hasil dari integral tak tentu: \[\int \frac{3\sin x + 4\cos x}{2\sin x + \cos x} \, dx\] adalah ....

  1. \(2x + \ln|2\sin x + \cos x| + C\)
  2. \(2x - \ln|2\sin x + \cos x| + C\)
  3. \(x + 2\ln|2\sin x + \cos x| + C\)
  4. \(3x + \ln|2\sin x + \cos x| + C\)
  5. \(x - \ln|2\sin x + \cos x| + C\)
HOTS / Ujian Masuk PTN Mandiri
Pembahasan:

Langkah 1: Memahami Metode Kombinasi Linier

Untuk menyelesaikan integral berbentuk: \[\int \frac{a\sin x + b\cos x}{c\sin x + d\cos x} \, dx\] kita nyatakan pembilang sebagai kombinasi linier dari penyebut dan turunan penyebut: \[\text{Pembilang} = A \cdot (\text{Penyebut}) + B \cdot (\text{Turunan Penyebut})\]

Langkah 2: Menentukan Turunan Penyebut

Penyebut dari integran adalah: \[D(x) = 2\sin x + \cos x\] Turunannya adalah: \[D'(x) = \frac{d}{dx}(2\sin x + \cos x) = 2\cos x - \sin x\]

Langkah 3: Menentukan Nilai Konstanta \(A\) dan \(B\)

Susun persamaan kombinasi linier: \[3\sin x + 4\cos x = A(2\sin x + \cos x) + B(2\cos x - \sin x)\] Kelompokkan suku-suku sejenis: \[3\sin x + 4\cos x = (2A - B)\sin x + (A + 2B)\cos x\] Samakan koefisien suku yang bersesuaian pada kedua ruas:

  • Koefisien \(\sin x\): \(2A - B = 3 \implies B = 2A - 3\) ...(Persamaan 1)
  • Koefisien \(\cos x\): \(A + 2B = 4\) ...(Persamaan 2)
Substitusikan Persamaan 1 ke Persamaan 2: \[A + 2(2A - 3) = 4\] \[A + 4A - 6 = 4\] \[5A = 10 \implies A = 2\] Maka nilai \(B\): \[B = 2(2) - 3 = 4 - 3 = 1\]

Langkah 4: Memecah dan Mengevaluasi Integral

Tulis ulang pecahan integran menggunakan nilai \(A = 2\) dan \(B = 1\): \[\frac{3\sin x + 4\cos x}{2\sin x + \cos x} = \frac{2(2\sin x + \cos x) + 1(2\cos x - \sin x)}{2\sin x + \cos x}\] \[= 2 + \frac{2\cos x - \sin x}{2\sin x + \cos x}\] Sekarang integralkan masing-masing suku: \[\int \frac{3\sin x + 4\cos x}{2\sin x + \cos x} \, dx = \int 2 \, dx + \int \frac{2\cos x - \sin x}{2\sin x + \cos x} \, dx\] Pada integral kedua, pembilang adalah turunan eksak dari penyebut (\(du = (2\cos x - \sin x) \, dx\)): \[= 2x + \ln|2\sin x + \cos x| + C\]

Jadi, hasil dari integral tak tentu tersebut adalah \(2x + \ln|2\sin x + \cos x| + C\) (Pilihan A).
