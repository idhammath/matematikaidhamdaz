Berikut adalah soal tingkat ... materi Grafik Fungsi Trigonometri

Persamaan grafik fungsi pada gambar berikut adalah ....

  1. \(y = 2\sin x + 1\)
  2. \(y = 2\sin x - 1\)
  3. \(y = 2\cos x + 1\)
  4. \(y = 2\cos x - 1\)
  5. \(y = \cos 2x + 1\)
Matematika Zone Indonesia
Pembahasan:

Berdasarkan grafik fungsi trigonometri pada gambar:

  • Nilai maksimum grafik adalah \(y_{\text{maks}} = 3\) yang dicapai pada absis \(x = 0\) dan \(x = 2\pi\).
  • Nilai minimum grafik adalah \(y_{\text{min}} = -1\) yang dicapai pada absis \(x = \pi\).

1. Menentukan Amplitudo (\(a\)):

\[ a = \dfrac{y_{\text{maks}} - y_{\text{min}}}{2} = \dfrac{3 - (-1)}{2} = \dfrac{4}{2} = 2 \]

2. Menentukan Pergeseran Vertikal (\(c\)):

\[ c = \dfrac{y_{\text{maks}} + y_{\text{min}}}{2} = \dfrac{3 + (-1)}{2} = \dfrac{2}{2} = 1 \]

3. Menentukan Periode (\(T\)) dan Frekuensi Gelombang (\(b\)):

Satu siklus gelombang penuh terbentuk dari interval \(x = 0\) sampai \(x = 2\pi\), sehingga periodenya adalah: \[ T = 2\pi - 0 = 2\pi \] Nilai \(b\) dirumuskan sebagai: \[ b = \dfrac{2\pi}{T} = \dfrac{2\pi}{2\pi} = 1 \]

4. Menentukan Persamaan Fungsi:

Karena saat \(x = 0\) nilai kurva berada di titik puncaknya (maksimum), kurva ini mengikuti pola dasar fungsi kosinus \(y = a\cos(b(x - x_1)) + c\) tanpa pergeseran fase horizontal (\(x_1 = 0\)):

\[\begin{aligned} y &= a\cos(b(x - x_1)) + c \\ &= 2\cos(1(x - 0)) + 1 \\ &= 2\cos x + 1 \end{aligned}\]
Jadi, persamaan grafik fungsi pada gambar di atas adalah \(y = 2\cos x + 1\).
