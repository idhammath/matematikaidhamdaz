Berikut adalah soal tingkat ... materi Basis Bilangan

Suatu bilangan tiga digit \(abc\) dalam basis \(7\) memiliki nilai yang sama dengan bilangan tiga digit \(cba\) dalam basis \(9\), dengan \(a \ne 0\) dan \(c \ne 0\). Nilai dari \(a + b + c\) adalah ....
  1. 6
  2. 7
  3. 8
  4. 9
  5. 10
SNBT / UTBK
Pembahasan:
Diberikan kesamaan bilangan dalam basis berbeda: \[abc_{(7)} = cba_{(9)}\] Langkah 1: Menguraikan bilangan ke dalam bentuk polinomial desimal (basis 10)

\[\begin{aligned} abc_{(7)} &= a \cdot 7^2 + b \cdot 7^1 + c \cdot 7^0 = 49a + 7b + c \\ cba_{(9)} &= c \cdot 9^2 + b \cdot 9^1 + a \cdot 9^0 = 81c + 9b + a \end{aligned}\] Karena nilainya sama, samakan kedua bentuk tersebut: \[\begin{aligned} 49a + 7b + c &= 81c + 9b + a \\ 49a - a - 81c + c &= 9b - 7b \\ 48a - 80c &= 2b \end{aligned}\] Bagi kedua ruas dengan 2: \[24a - 40c = b \implies b = 8(3a - 5c)\]

Langkah 2: Menganalisis batasan nilai digit

Perhatikan batasan digit pada masing-masing basis:

  • Pada basis 7, digit yang diperbolehkan adalah \(\{0, 1, 2, 3, 4, 5, 6\}\). Maka \(0 \le a, b, c \le 6\).
  • Karena \(a \ne 0\) dan \(c \ne 0\), maka \(a, c \in \{1, 2, 3, 4, 5, 6\}\).
  • Nilai \(b\) adalah bilangan bulat non-negatif yang memenuhi \(0 \le b \le 6\).
Dari persamaan \(b = 8(3a - 5c)\):
  • Jika \(3a - 5c \ge 1\), maka \(b \ge 8(1) = 8\) (tidak memenuhi karena \(b \le 6\)).
  • Jika \(3a - 5c \le -1\), maka \(b \le 8(-1) = -8\) (tidak memenuhi karena \(b \ge 0\)).
Oleh karena itu, satu-satunya kemungkinan adalah: \[3a - 5c = 0 \implies 3a = 5c\]

Langkah 3: Menentukan nilai \(a, b,\) dan \(c\)

Karena \(3\) dan \(5\) saling prima (faktor persekutuan terbesar adalah 1), maka \(a\) harus merupakan kelipatan dari 5, dan \(c\) merupakan kelipatan dari 3.
Mengingat \(1 \le a \le 6\) dan \(1 \le c \le 6\), maka satu-satunya pasangan nilai bulat yang memenuhi adalah: \[a = 5 \quad \text{dan} \quad c = 3\] Substitusikan kembali untuk memperoleh \(b\): \[b = 8(3(5) - 5(3)) = 8(15 - 15) = 0\]

Pemeriksaan Nilai:

\[503_{(7)} = 5(49) + 0(7) + 3 = 245 + 3 = 248\] \[305_{(9)} = 3(81) + 0(9) + 5 = 243 + 5 = 248\] (Keduanya bernilai tepat 248).

Langkah 4: Menghitung nilai \(a + b + c\)

\[a + b + c = 5 + 0 + 3 = 8\]

Jadi, nilai dari \(a + b + c\) adalah 8.
