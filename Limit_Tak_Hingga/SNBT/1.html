Tentukan nilai dari: \[\lim_{x\to\infty}\left(\sqrt{4x+2}-\sqrt{4x}\right)\sqrt{x+1}\]

Ganesha Operation
Pembahasan:

Kalikan faktor \(\sqrt{x+1}\) ke dalam tanda kurung secara distributif:

\[ \begin{aligned} \lim_{x\to\infty}\left(\sqrt{4x+2}-\sqrt{4x}\right)\sqrt{x+1} &= \lim_{x\to\infty}\left(\sqrt{(4x+2)(x+1)}-\sqrt{4x(x+1)}\right)\\[3.7pt] &= \lim_{x\to\infty}\left(\sqrt{4x^2+6x+2}-\sqrt{4x^2+4x}\right) \end{aligned} \] Gunakan rumus cepat selisih bentuk akar kuadrat \(\dfrac{b-q}{2\sqrt{a}}\): \[ \dfrac{6-4}{2\sqrt{4}} = \dfrac{2}{2(2)} = \dfrac{2}{4} = \dfrac{1}{2} \]
Jadi, \(\displaystyle\lim_{x\to\infty}\left(\sqrt{4x+2}-\sqrt{4x}\right)\sqrt{x+1}=\dfrac{1}{2}\).

\[\lim_{x\to\infty}\left(\sqrt{x^2+3x-5}+\sqrt{x^2-x+2}-\sqrt{4x^2+8x-5}\right)=\dots\]

  1. \(\dfrac{3}{2}\)
  2. \(1\)
  3. \(\dfrac{1}{2}\)
  4. \(0\)
  5. \(-1\)
Pembahasan:

Faktorkan angka 4 dari suku akar ketiga \(\sqrt{4x^2+8x-5}\):

\[ \sqrt{4x^2+8x-5} = \sqrt{4\left(x^2+2x-\dfrac{5}{4}\right)} = 2\sqrt{x^2+2x-\dfrac{5}{4}} \] Pecah suku tersebut menjadi dua bagian yang sama untuk dipasangkan dengan masing-masing akar kuadrat pertama dan kedua: \[ \begin{aligned} &\lim_{x\to\infty}\left[\left(\sqrt{x^2+3x-5}-\sqrt{x^2+2x-\dfrac{5}{4}}\right) + \left(\sqrt{x^2-x+2}-\sqrt{x^2+2x-\dfrac{5}{4}}\right)\right]\\[3.7pt] &= \dfrac{3-2}{2\sqrt{1}} + \dfrac{-1-2}{2\sqrt{1}}\\[3.7pt] &= \dfrac{1}{2} + \left(-\dfrac{3}{2}\right) = -\dfrac{2}{2} = -1 \end{aligned} \]
Jadi, hasilnya adalah \(-1\).

Tentukan nilai dari: \[\lim_{x\to\infty}\left(\sqrt{25x^2-100x}-\sqrt{4x^2-5x}-3x-2\right)\]

Matematika Zone Id
Pembahasan:

Pecah suku \(-3x-2\) menjadi \(-5x + (2x-2)\) agar koefisien kuadrat dari bentuk akarnya bersesuaian (\(\sqrt{25x^2}=5x\) dan \(\sqrt{4x^2}=2x\)):

\[ \begin{aligned} &\lim_{x\to\infty}\left[\left(\sqrt{25x^2-100x}-5x\right) + \left((2x-2)-\sqrt{4x^2-5x}\right)\right]\\[3.7pt] &= \lim_{x\to\infty}\left[\left(\sqrt{25x^2-100x}-\sqrt{25x^2}\right) + \left(\sqrt{(2x-2)^2}-\sqrt{4x^2-5x}\right)\right]\\[3.7pt] &= \lim_{x\to\infty}\left[\left(\sqrt{25x^2-100x}-\sqrt{25x^2+0x}\right) + \left(\sqrt{4x^2-8x+4}-\sqrt{4x^2-5x}\right)\right] \end{aligned} \] Gunakan rumus cepat \(\dfrac{b-q}{2\sqrt{a}}\) pada masing-masing kelompok: \[ \begin{aligned} &= \dfrac{-100-0}{2\sqrt{25}} + \dfrac{-8-(-5)}{2\sqrt{4}}\\[3.7pt] &= \dfrac{-100}{10} + \dfrac{-3}{4}\\[3.7pt] &= -10 - \dfrac{3}{4} = -\dfrac{43}{4} \end{aligned} \]
Jadi, hasilnya adalah \(-\dfrac{43}{4}\).

Tentukan nilai dari: \[\lim_{x\to\infty}\left(\sqrt{9x^2+2}+\sqrt{4x^2-3x+7}-5x\right)\]

Matematika Zone Id
Pembahasan:

Uraikan \(-5x = -3x - 2x = -\sqrt{9x^2} - \sqrt{4x^2}\):

\[ \begin{aligned} &\lim_{x\to\infty}\left[\left(\sqrt{9x^2+2}-\sqrt{9x^2}\right) + \left(\sqrt{4x^2-3x+7}-\sqrt{4x^2}\right)\right]\\[3.7pt] &= \dfrac{0-0}{2\sqrt{9}} + \dfrac{-3-0}{2\sqrt{4}}\\[3.7pt] &= 0 + \left(-\dfrac{3}{4}\right) = -\dfrac{3}{4} \end{aligned} \]
Jadi, hasilnya adalah \(-\dfrac{3}{4}\).

Jika diketahui dua fungsi \(f(x)\) dan \(g(x)\) dengan \[f(x)=\sqrt{x^2+5x}-\sqrt{x^2-2x+1} \quad \text{dan} \quad g(x)=x-\sqrt{x^2+2x}\] maka nilai dari \(\displaystyle\lim_{x\to\infty}\dfrac{f(x)}{g(x)}=\dots\)

  1. \(\dfrac{7}{2}\)
  2. \(\dfrac{3}{2}\)
  3. \(0\)
  4. \(-\dfrac{3}{2}\)
  5. \(-\dfrac{7}{2}\)
Pembahasan:

1. Hitung nilai limit untuk pembilang \(f(x)\):

\[ \begin{aligned} \lim_{x\to\infty}f(x) &= \lim_{x\to\infty}\left(\sqrt{x^2+5x}-\sqrt{x^2-2x+1}\right)\\[3.7pt] &= \dfrac{5-(-2)}{2\sqrt{1}} = \dfrac{7}{2} \end{aligned} \]

2. Hitung nilai limit untuk penyebut \(g(x)\):

\[ \begin{aligned} \lim_{x\to\infty}g(x) &= \lim_{x\to\infty}\left(\sqrt{x^2}-\sqrt{x^2+2x}\right)\\[3.7pt] &= \dfrac{0-2}{2\sqrt{1}} = \dfrac{-2}{2} = -1 \end{aligned} \]

3. Hitung limit hasil bagi:

\[ \lim_{x\to\infty}\dfrac{f(x)}{g(x)} = \dfrac{\displaystyle\lim_{x\to\infty}f(x)}{\displaystyle\lim_{x\to\infty}g(x)} = \dfrac{\dfrac{7}{2}}{-1} = -\dfrac{7}{2} \]
Jadi, \(\displaystyle\lim_{x\to\infty}\dfrac{f(x)}{g(x)}=-\dfrac{7}{2}\).
