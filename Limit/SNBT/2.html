Jika diketahui: \[\lim_{x\to2}\dfrac{x^n-2^n}{x^{\frac{n}{3}}-2^{\frac{n}{3}}}=3\sqrt[3]{16}\] tentukan nilai dari \(n\)!

Grup Telegram
Pembahasan:

Cara 1: Pemfaktoran Aljabar

Gunakan rumus selisih kubik \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\) dengan memisalkan \(a = x^{\frac{n}{3}}\) dan \(b = 2^{\frac{n}{3}}\):

\[ \begin{aligned} \lim_{x\to2}\dfrac{x^n-2^n}{x^{\frac{n}{3}}-2^{\frac{n}{3}}} &= \lim_{x\to2}\dfrac{\left(x^{\frac{n}{3}}\right)^3-\left(2^{\frac{n}{3}}\right)^3}{x^{\frac{n}{3}}-2^{\frac{n}{3}}}\\[3.7pt] &= \lim_{x\to2}\dfrac{\left(x^{\frac{n}{3}}-2^{\frac{n}{3}}\right)\left(x^{\frac{2n}{3}}+x^{\frac{n}{3}}2^{\frac{n}{3}}+2^{\frac{2n}{3}}\right)}{x^{\frac{n}{3}}-2^{\frac{n}{3}}}\\[3.7pt] &= \lim_{x\to2}\left(x^{\frac{2n}{3}}+x^{\frac{n}{3}}2^{\frac{n}{3}}+2^{\frac{2n}{3}}\right)\\[3.7pt] &= 2^{\frac{2n}{3}} + 2^{\frac{2n}{3}} + 2^{\frac{2n}{3}}\\[3.7pt] &= 3\cdot 2^{\frac{2n}{3}} \end{aligned} \] Diketahui nilainya sama dengan \(3\sqrt[3]{16} = 3\cdot 16^{\frac{1}{3}} = 3\cdot\left(2^4\right)^{\frac{1}{3}} = 3\cdot 2^{\frac{4}{3}}\): \[ \begin{aligned} 3\cdot 2^{\frac{2n}{3}} &= 3\cdot 2^{\frac{4}{3}}\\[3.7pt] \dfrac{2n}{3} &= \dfrac{4}{3}\\[3.7pt] 2n &= 4 \implies n = 2 \end{aligned} \]

Cara 2: Aturan L'Hôpital

\[ \begin{aligned} \lim_{x\to2}\dfrac{nx^{n-1}}{\dfrac{n}{3}x^{\frac{n}{3}-1}} &= 3\sqrt[3]{16}\\[3.7pt] \lim_{x\to2}\left(3x^{(n-1)-(\frac{n}{3}-1)}\right) &= 3\sqrt[3]{16}\\[3.7pt] 3(2)^{\frac{2n}{3}} &= 3\cdot 2^{\frac{4}{3}} \implies n = 2 \end{aligned} \]
Jadi, nilai \(n = 2\).

Diketahui \(f(x)=\sqrt{x+3}\). Nilai dari \[\lim_{h\to0}\dfrac{f\left(3+2h^2\right)-f\left(3-3h^2\right)}{h^2}\] adalah ....

  2. \(5\sqrt{6}\)
  3. \(\dfrac{5}{12}\sqrt{6}\)
  4. \(\dfrac{5}{2}\sqrt{6}\)
  5. \(5\)

Pembahasan:

Cara 1: Mengalikan dengan Sekawan

\[ \begin{aligned} \lim_{h\to0}\dfrac{f\left(3+2h^2\right)-f\left(3-3h^2\right)}{h^2}&=\lim_{h\to0}\dfrac{\sqrt{3+2h^2+3}-\sqrt{3-3h^2+3}}{h^2}\\[3.7pt] &=\lim_{h\to0}\dfrac{\sqrt{6+2h^2}-\sqrt{6-3h^2}}{h^2}\cdot\dfrac{\sqrt{6+2h^2}+\sqrt{6-3h^2}}{\sqrt{6+2h^2}+\sqrt{6-3h^2}}\\[3.7pt] &=\lim_{h\to0}\dfrac{(6+2h^2)-(6-3h^2)}{h^2\left(\sqrt{6+2h^2}+\sqrt{6-3h^2}\right)}\\[3.7pt] &=\lim_{h\to0}\dfrac{5h^2}{h^2\left(\sqrt{6+2h^2}+\sqrt{6-3h^2}\right)}\\[3.7pt] &=\dfrac{5}{\sqrt{6}+\sqrt{6}} = \dfrac{5}{2\sqrt{6}}\cdot\dfrac{\sqrt{6}}{\sqrt{6}} = \dfrac{5}{12}\sqrt{6} \end{aligned} \]

Cara 2: Definisi Turunan / L'Hôpital

Turunan dari \(f(x) = \sqrt{x+3}\) adalah \(f'(x) = \dfrac{1}{2\sqrt{x+3}}\):

\[ \begin{aligned} \lim_{h\to0}\dfrac{f\left(3+2h^2\right)-f\left(3-3h^2\right)}{h^2} &= \lim_{h\to0}\dfrac{4h\cdot f'(3+2h^2) - (-6h)\cdot f'(3-3h^2)}{2h}\\[3.7pt] &= 2f'(3) + 3f'(3) = 5f'(3)\\[3.7pt] &= 5\cdot\dfrac{1}{2\sqrt{3+3}} = \dfrac{5}{2\sqrt{6}} = \dfrac{5}{12}\sqrt{6} \end{aligned} \]
Jadi, hasilnya adalah \(\dfrac{5}{12}\sqrt{6}\).

Diketahui \(f(x) = ax + b\) dengan \(f^{-1}(11) = 2\) dan \(f^{-1}(8) = 1\), dengan \(f^{-1}\) menyatakan fungsi invers dari \(f\). Nilai dari \[\lim_{h\to0}\dfrac{(3+h)f(3)-3f(3+h)}{h}=\dots\]

  1. \(4\)
  2. \(5\)
  3. \(6\)
  4. \(7\)
  5. \(8\)
Ganesha Operation
Pembahasan:

1. Dari sifat fungsi invers:

\[ \begin{aligned} f^{-1}(11) = 2 &\iff f(2) = 11 \implies 2a + b = 11\\[3.7pt] f^{-1}(8) = 1 &\iff f(1) = 8 \implies a + b = 8 \end{aligned} \] Eliminasi kedua persamaan: \[ a = 11 - 8 = 3 \implies b = 8 - 3 = 5 \] Sehingga \(f(x) = 3x + 5\), dan nilai \(f(3) = 3(3) + 5 = 14\).

2. Substitusikan ke bentuk limit:

\[ \begin{aligned} \lim_{h\to0}\dfrac{(3+h)f(3)-3f(3+h)}{h} &= \lim_{h\to0}\dfrac{(3+h)(14) - 3\left[3(3+h)+5\right]}{h}\\[3.7pt] &= \lim_{h\to0}\dfrac{(42+14h) - 3(14+3h)}{h}\\[3.7pt] &= \lim_{h\to0}\dfrac{42+14h - 42 - 9h}{h}\\[3.7pt] &= \lim_{h\to0}\dfrac{5h}{h} = 5 \end{aligned} \]
Jadi, hasilnya adalah \(5\).

Jika nilai \[\lim_{x\to1}\dfrac{\sqrt{ax+b}-3}{x-1}=\dfrac{2}{3}\] maka nilai \(8a + 2b\) adalah ....

  1. \(42\)
  2. \(44\)
  3. \(46\)
  4. \(48\)
  5. \(50\)
SKMP Juli 2020
Pembahasan:

1. Karena penyebut \(\lim_{x\to1}(x-1)=0\) dan nilai limit ada (\(\frac{2}{3}\)), maka pembilang harus bernilai nol di \(x = 1\):

\[ \sqrt{a(1)+b} - 3 = 0 \implies \sqrt{a+b} = 3 \implies a + b = 9 \quad \dots\text{(Persamaan 1)} \]

2. Gunakan aturan L'Hôpital pada limit:

\[ \begin{aligned} \lim_{x\to1}\dfrac{\dfrac{a}{2\sqrt{ax+b}}}{1} &= \dfrac{2}{3}\\[3.7pt] \dfrac{a}{2\sqrt{a+b}} &= \dfrac{2}{3}\\[3.7pt] \dfrac{a}{2(3)} &= \dfrac{2}{3} \implies \dfrac{a}{6} = \dfrac{2}{3} \implies a = 4 \end{aligned} \] Substitusi ke Persamaan 1: \[ 4 + b = 9 \implies b = 5 \]

3. Hitung nilai \(8a + 2b\):

\[ 8a + 2b = 8(4) + 2(5) = 32 + 10 = 42 \]
Jadi, nilai \(8a + 2b = 42\).

Jika diketahui \(\displaystyle\lim_{x\to2}\dfrac{\sqrt{ax^4+b}-1}{x-2}=3\), maka nilai dari \[\lim_{x\to2}\dfrac{2\sqrt{ax^4+b}-x}{x^2+2x-8}=\dots\]

  1. \(1\)
  2. \(2\)
  3. \(\dfrac{1}{6}\)
  4. \(\dfrac{5}{6}\)
  5. \(\dfrac{1}{2}\)
SKMP Februari 2021
Pembahasan:

Misalkan \(f(x) = \sqrt{ax^4+b}\). Dari informasi pertama:

\[ \lim_{x\to2}\dfrac{f(x)-1}{x-2}=3 \implies f(2) = 1 \quad \text{dan} \quad f'(2) = 3 \]

Sekarang selesaikan limit yang ditanyakan dengan aturan L'Hôpital (karena saat \(x = 2\), pembilang bernilai \(2(1) - 2 = 0\) dan penyebut \(2^2+2(2)-8 = 0\)):

\[ \begin{aligned} \lim_{x\to2}\dfrac{2f(x)-x}{x^2+2x-8} &= \lim_{x\to2}\dfrac{2f'(x)-1}{2x+2}\\[3.7pt] &= \dfrac{2f'(2)-1}{2(2)+2}\\[3.7pt] &= \dfrac{2(3)-1}{4+2}\\[3.7pt] &= \dfrac{6-1}{6} = \dfrac{5}{6} \end{aligned} \]
Jadi, hasilnya adalah \(\dfrac{5}{6}\).

Jika \(p\) dan \(q\) merupakan bilangan real sehingga \[\lim_{x\to\frac{1}{3}}\dfrac{\sqrt{9x^4+3}-\sqrt{\dfrac{p}{x^2}+q}}{3x-1}=L\] maka nilai dari \[\lim_{x\to3}\dfrac{\sqrt{3x^4+9}-\sqrt{px^6+qx^4}}{x^2-9}=\dots\]

  1. \(-\dfrac{3}{2}L\)
  2. \(-\dfrac{L}{2}\)
  3. \(\dfrac{L}{2}\)
  4. \(\dfrac{3}{2}L\)
  5. \(\dfrac{5}{2}L\)
Grup WhatsApp
Pembahasan:

Lakukan substitusi variabel \(u = \dfrac{1}{x}\). Saat \(x \to 3\), maka \(u \to \dfrac{1}{3}\).

Faktorkan bentuk aljabar pada limit kedua:

\[ \begin{aligned} \sqrt{3x^4+9} - \sqrt{px^6+qx^4} &= \sqrt{x^4\left(3+\dfrac{9}{x^4}\right)} - \sqrt{x^4(px^2+q)}\\[3.7pt] &= x^2\left(\sqrt{3+\dfrac{9}{x^4}} - \sqrt{px^2+q}\right) \end{aligned} \] Faktorkan penyebut: \[ x^2 - 9 = (x+3)(x-3) = -x(x+3)\left(\dfrac{3}{x}-1\right) \] Sehingga: \[ \begin{aligned} \lim_{x\to3}\dfrac{\sqrt{3x^4+9}-\sqrt{px^6+qx^4}}{x^2-9} &= \lim_{x\to3}\left[\dfrac{x}{-(x+3)}\cdot\dfrac{\sqrt{3+\dfrac{9}{x^4}}-\sqrt{px^2+q}}{\dfrac{3}{x}-1}\right]\\[3.7pt] &= \left(\lim_{x\to3}\dfrac{x}{-(x+3)}\right)\cdot\left(\lim_{u\to\frac{1}{3}}\dfrac{\sqrt{9u^4+3}-\sqrt{\dfrac{p}{u^2}+q}}{3u-1}\right)\\[3.7pt] &= \dfrac{3}{-(3+3)}\cdot L\\[3.7pt] &= \dfrac{3}{-6}\cdot L = -\dfrac{L}{2} \end{aligned} \]
Jadi, hasilnya adalah \(-\dfrac{L}{2}\).
