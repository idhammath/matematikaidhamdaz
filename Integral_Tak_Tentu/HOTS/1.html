Berikut adalah soal tingkat ... materi Integral Tak Tentu

Hasil dari integral tak tentu: \[\int \frac{x^2 - 1}{x^4 + 3x^2 + 1} \, dx\] adalah ....

  1. \(\arctan\left(\dfrac{x^2 + 1}{x}\right) + C\)
  2. \(\arctan\left(\dfrac{x^2 - 1}{x}\right) + C\)
  3. \(\dfrac{1}{2} \ln\left|\dfrac{x^2 - x + 1}{x^2 + x + 1}\right| + C\)
  4. \(\dfrac{1}{\sqrt{3}} \arctan\left(\dfrac{x^2 + 1}{\sqrt{3}x}\right) + C\)
  5. \(\ln\left|x^4 + 3x^2 + 1\right| + C\)
HOTS / Ujian Masuk PTN Mandiri
Pembahasan:

Langkah 1: Mengamati Struktur Integran dan Membagi dengan \(x^2\)

Integral berbentuk: \[I = \int \frac{x^2 - 1}{x^4 + 3x^2 + 1} \, dx\] Karena derajat pembilang dan penyebut bersifat simetris kuadratik, kita bagi pembilang dan penyebut dengan \(x^2\) (untuk \(x \neq 0\)): \[I = \int \frac{\dfrac{x^2 - 1}{x^2}}{\dfrac{x^4 + 3x^2 + 1}{x^2}} \, dx\] \[I = \int \frac{1 - \dfrac{1}{x^2}}{x^2 + 3 + \dfrac{1}{x^2}} \, dx\]

Langkah 2: Menghubungkan Pembilang dengan Diferensial Bentuk Simetris

Perhatikan bahwa pembilang \(1 - \dfrac{1}{x^2}\) adalah turunan eksak dari bentuk \(\left(x + \dfrac{1}{x}\right)\): \[\frac{d}{dx}\left(x + \frac{1}{x}\right) = 1 - \frac{1}{x^2} \implies d\left(x + \frac{1}{x}\right) = \left(1 - \frac{1}{x^2}\right) dx\]

Langkah 3: Memanipulasi Penyebut ke Bentuk Kuadrat Sempurna

Nyatakan bagian penyebut dalam suku \(\left(x + \dfrac{1}{x}\right)\): \[\left(x + \frac{1}{x}\right)^2 = x^2 + 2 + \frac{1}{x^2}\] Sehingga: \[x^2 + 3 + \frac{1}{x^2} = \left(x^2 + 2 + \frac{1}{x^2}\right) + 1 = \left(x + \frac{1}{x}\right)^2 + 1\] Maka integral dapat ditulis ulang menjadi: \[I = \int \frac{\left(1 - \dfrac{1}{x^2}\right) dx}{\left(x + \dfrac{1}{x}\right)^2 + 1}\]

Langkah 4: Melakukan Substitusi Variabel

Misalkan: \[u = x + \frac{1}{x} \implies du = \left(1 - \frac{1}{x^2}\right) dx\] Integral berubah menjadi integral dasar fungsi invers tangen (arkus tangen): \[I = \int \frac{du}{u^2 + 1} = \arctan(u) + C\]

Langkah 5: Mengembalikan ke Variabel Asli \(x\)

Substitusikan kembali \(u = x + \dfrac{1}{x} = \dfrac{x^2 + 1}{x}\): \[I = \arctan\left(x + \frac{1}{x}\right) + C = \arctan\left(\frac{x^2 + 1}{x}\right) + C\]

Verifikasi dengan Diferensiasi Balik:
Misalkan \(y = \arctan\left(\frac{x^2+1}{x}\right)\). Sesuai aturan rantai: \[\frac{dy}{dx} = \frac{1}{1 + \left(\frac{x^2+1}{x}\right)^2} \cdot \frac{d}{dx}\left(x + \frac{1}{x}\right)\] \[= \frac{1}{1 + \frac{x^4 + 2x^2 + 1}{x^2}} \cdot \left(1 - \frac{1}{x^2}\right)\] \[= \frac{x^2}{x^4 + 3x^2 + 1} \cdot \frac{x^2 - 1}{x^2} = \frac{x^2 - 1}{x^4 + 3x^2 + 1}\] Hasil turunan tepat kembali ke fungsi awal di dalam integral.

Jadi, hasil dari integral tak tentu tersebut adalah \(\arctan\left(\dfrac{x^2 + 1}{x}\right) + C\) (Pilihan A).
