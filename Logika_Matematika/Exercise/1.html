Grup Matematika Zone Indonesia
ALTERNATIF PENYELESAIAN
\begin{aligned} \sim(p\vee q)\vee(\sim p\wedge q)&\equiv(\sim p\wedge \sim q)\vee(\sim p\wedge q)\qquad&{\color{red}\text{De Morgan's Law 1}}\\ &\equiv \sim p\wedge(\sim q\vee q)\qquad&{\color{red}\text{The Second Distributive Law}}\\ \end{aligned}
Jadi, ~(p ∨ q) ∨ (~p ∧ q) ≡ ~p ∧ (~q ∨ q).

  1. Jika piknik dilaksanakan, maka cuaca hari minggu ini pastilah cerah
  2. Jika cuaca hari minggu tidak cerah, maka piknik tidak akan dilaksanakan
  1. Jika piknik tidak dilaksanakan, maka cuaca minggu tidaklah cerah
  2. Jika cuaca hari minggu tidak cerah, maka piknik akan dilaksanakan
SUMBER
ALTERNATIF PENYELESAIAN
Premis dalam bentuk implikasi, kesimpulan biasanya dalam bentuk kontraposisi. Pernyataan di atas ekuivalen dengan "Jika cuacanya tidak cerah, maka piknik pada hari minggu tidak akan dilaksanakan".

p = cuacanya tidak cerah
~p = cuacanya cerah
q = piknik pada hari minggu tidak akan dilaksanakan
~q = piknik pada hari minggu akan dilaksanakan

p ⟶ q ≡ ~q ⟶ ~p
Pertanyaan premis ekuivalen dengan "Jika piknik pada hari minggu akan dilaksanakan, maka cuacanya cerah"
Jadi, kita dapat menyimpulkan bahwa Jika piknik dilaksanakan, maka cuaca hari minggu ini pastilah cerah.
