Ringkasan dan penjelasan komprehensif materi Ketaksamaan Cauchy-Schwarz (Aljabar & Olimpiade Matematika)

1. Pengantar dan Pernyataan Teorema

Ketaksamaan Cauchy-Schwarz (sering disingkat CS Inequality atau Cauchy-Bunyakovsky-Schwarz) adalah salah satu ketaksamaan paling penting dan mendasar dalam seluruh cabang matematika—mulai dari aljabar dasar, geometri vektor, analisis riil, hingga mekanika kuantum.

Ketaksamaan ini menyatakan bahwa untuk sembarang bilangan riil $a_1, a_2, \dots, a_n$ dan $b_1, b_2, \dots, b_n$, berlaku:

$$(a_1 b_1 + a_2 b_2 + \dots + a_n b_n)^2 \le (a_1^2 + a_2^2 + \dots + a_n^2)(b_1^2 + b_2^2 + \dots + b_n^2)$$

Atau dalam notasi sigma ($\Sigma$):

$$\left( \sum_{i=1}^n a_i b_i \right)^2 \le \left( \sum_{i=1}^n a_i^2 \right) \left( \sum_{i=1}^n b_i^2 \right)$$
Syarat Kesamaan (Equality Case): Kesamaan terjadi jika dan hanya jika kedua deretan bilangan tersebut berbanding lurus (proporsional), yaitu: $$\frac{a_1}{b_1} = \frac{a_2}{b_2} = \dots = \frac{a_n}{b_n} = k \quad (k \in \mathbb{R})$$ (dengan asumsi penyebut tidak bernilai nol, atau salah satu vektor adalah kelipatan skalar dari yang lain).

2. Interpretasi Geometris & Vektor

Dalam aljabar linier dan geometri analitik, misalkan $\vec{u} = (a_1, a_2, \dots, a_n)$ dan $\vec{v} = (b_1, b_2, \dots, b_n)$ adalah dua vektor di ruang Euklides $\mathbb{R}^n$. Perkalian titik (dot product) dan panjang vektor (norma) didefinisikan sebagai:

$$\vec{u} \cdot \vec{v} = \sum_{i=1}^n a_i b_i, \quad \Vert{}\vec{u}\Vert{} = \sqrt{\sum_{i=1}^n a_i^2}, \quad \Vert{}\vec{v}\Vert{} = \sqrt{\sum_{i=1}^n b_i^2}$$

Berdasarkan hubungan geometri perkalian titik dengan sudut apit $\theta$ di antara kedua vektor:

$$\vec{u} \cdot \vec{v} = \Vert{}\vec{u}\Vert{} \Vert{}\vec{v}\Vert{} \cos \theta$$ Karena nilai $\vert{}\cos \theta\vert{} \le 1$ untuk setiap sudut riil $\theta$, maka kuadrat dari kedua ruas menghasilkan: $$\vert{}\vec{u} \cdot \vec{v}\vert{} \le \Vert{}\vec{u}\Vert{} \Vert{}\vec{v}\Vert{} \implies (\vec{u} \cdot \vec{v})^2 \le \Vert{}\vec{u}\Vert{}^2 \Vert{}\vec{v}\Vert{}^2$$

Kesamaan terjadi ketika $\vert{}\cos \theta\vert{} = 1 \iff \theta = 0^\circ \text{ atau } 180^\circ$, yang berarti vektor $\vec{u}$ dan $\vec{v}$ kolinear (sejajar atau berimpit).

Gambar 1: Interpretasi vektor Ketaksamaan Cauchy-Schwarz melalui proyeksi ortogonal $\vec{u}$ terhadap $\vec{v}$. Nilai $\Vert{}\vec{u}\Vert{} \cos\theta \le \Vert{}\vec{u}\Vert{}$.

3. Bukti Aljabar Menggunakan Polinomial Kuadratik

Salah satu metode pembuktian paling elegan untuk dimensi sembarang adalah dengan mengonstruksi sebuah fungsi polinomial kuadratik riil satu variabel $f(t)$ yang dijamin non-negatif:

Misalkan $t \in \mathbb{R}$. Tinjau jumlahan kuadrat berikut:

$$f(t) = \sum_{i=1}^n (a_i t - b_i)^2$$

Karena setiap suku $(a_i t - b_i)^2 \ge 0$, maka jelas bahwa $f(t) \ge 0$ untuk seluruh nilai $t \in \mathbb{R}$. Jabarkan persamaan di atas:

$$\begin{aligned} f(t) &= \sum_{i=1}^n (a_i^2 t^2 - 2 a_i b_i t + b_i^2) \\ &= \left( \sum_{i=1}^n a_i^2 \right) t^2 - 2 \left( \sum_{i=1}^n a_i b_i \right) t + \left( \sum_{i=1}^n b_i^2 \right) \end{aligned}$$

Bentuk ini adalah fungsi kuadrat $f(t) = A t^2 + B t + C$ dengan:

$$A = \sum_{i=1}^n a_i^2, \quad B = -2 \sum_{i=1}^n a_i b_i, \quad C = \sum_{i=1}^n b_i^2$$

Karena kurva parabola $f(t)$ selalu berada di atas atau menyinggung sumbu-$t$ ($f(t) \ge 0$), maka persamaan kuadrat $f(t) = 0$ maksimal hanya memiliki paling banyak satu akar riil (akarnya kembar atau imajiner). Dengan demikian, nilai Diskriminan ($D$) tidak boleh positif:

$$D = B^2 - 4AC \le 0$$ $$\left(-2 \sum_{i=1}^n a_i b_i\right)^2 - 4 \left( \sum_{i=1}^n a_i^2 \right) \left( \sum_{i=1}^n b_i^2 \right) \le 0$$ $$4 \left( \sum_{i=1}^n a_i b_i \right)^2 \le 4 \left( \sum_{i=1}^n a_i^2 \right) \left( \sum_{i=1}^n b_i^2 \right)$$ $$\left( \sum_{i=1}^n a_i b_i \right)^2 \le \left( \sum_{i=1}^n a_i^2 \right) \left( \sum_{i=1}^n b_i^2 \right) \quad \blacksquare$$

Gambar 2: Karakteristik kurva $f(t) \ge 0$ dengan diskriminan $D \le 0$ yang mendasari bukti Cauchy-Schwarz.

4. Bentuk Khusus: Titu's Lemma (Bentuk Engel)

Dalam kompetisi olimpiade matematika (OSN/IMO), bentuk pecahan dari Cauchy-Schwarz sangat populer dan dikenal luas sebagai Titu's Lemma, Ketaksamaan Engel, atau Sedrakyan's Inequality.

Untuk setiap bilangan riil $x_1, x_2, \dots, x_n$ dan bilangan riil positif $y_1, y_2, \dots, y_n > 0$, berlaku:

$$\frac{x_1^2}{y_1} + \frac{x_2^2}{y_2} + \dots + \frac{x_n^2}{y_n} \ge \frac{(x_1 + x_2 + \dots + x_n)^2}{y_1 + y_2 + \dots + y_n}$$

Atau:

$$\sum_{i=1}^n \frac{x_i^2}{y_i} \ge \frac{\left( \sum_{i=1}^n x_i \right)^2}{\sum_{i=1}^n y_i}$$

Bukti Singkat Titu's Lemma:

Terapkan Cauchy-Schwarz bentuk standar pada dua barisan $a_i = \dfrac{x_i}{\sqrt{y_i}}$ dan $b_i = \sqrt{y_i}$:

$$\left( \sum_{i=1}^n a_i b_i \right)^2 \le \left( \sum_{i=1}^n a_i^2 \right) \left( \sum_{i=1}^n b_i^2 \right)$$ $$\left( \sum_{i=1}^n \frac{x_i}{\sqrt{y_i}} \cdot \sqrt{y_i} \right)^2 \le \left( \sum_{i=1}^n \frac{x_i^2}{y_i} \right) \left( \sum_{i=1}^n y_i \right)$$ $$\left( \sum_{i=1}^n x_i \right)^2 \le \left( \sum_{i=1}^n \frac{x_i^2}{y_i} \right) \left( \sum_{i=1}^n y_i \right)$$

Dengan membagi kedua ruas dengan $\sum y_i > 0$, teorema langsung terbukti.

5. Contoh Soal dan Pembahasan

Contoh 1
Jika $x, y \in \mathbb{R}$ memenuhi persamaan $x^2 + y^2 = 5$, tentukan nilai maksimum dan minimum yang mungkin dari bentuk $3x + 4y$!
Penyelesaian:

Gunakan Ketaksamaan Cauchy-Schwarz untuk 2 variabel dengan pasangan bilangan $(a_1, a_2) = (3, 4)$ dan $(b_1, b_2) = (x, y)$:

$$(a_1 b_1 + a_2 b_2)^2 \le (a_1^2 + a_2^2)(b_1^2 + b_2^2)$$ $$(3x + 4y)^2 \le (3^2 + 4^2)(x^2 + y^2)$$

Substitusikan nilai yang diketahui:

$$(3x + 4y)^2 \le (9 + 16)(5)$$ $$(3x + 4y)^2 \le 25 \times 5 = 125$$

Akarkan kedua ruas:

$$-\sqrt{125} \le 3x + 4y \le \sqrt{125}$$ $$-5\sqrt{5} \le 3x + 4y \le 5\sqrt{5}$$

Syarat kesamaan maksimum tercapai saat $\dfrac{x}{3} = \dfrac{y}{4} = k > 0 \implies x = \dfrac{3}{\sqrt{5}}, y = \dfrac{4}{\sqrt{5}}$.

Jadi, nilai maksimum dari $3x + 4y$ adalah $5\sqrt{5}$ dan nilai minimum-nya adalah $-5\sqrt{5}$.
Contoh 2
Diberikan tiga bilangan riil positif $a, b, c > 0$ sedemikian sehingga $a + b + c = 1$. Buktikan bahwa: $$\frac{1}{a} + \frac{1}{b} + \frac{1}{c} \ge 9$$
Penyelesaian:

Metode 1: Menggunakan Cauchy-Schwarz Standar

Pilih barisan $u = (\sqrt{a}, \sqrt{b}, \sqrt{c})$ dan $v = \left(\dfrac{1}{\sqrt{a}}, \dfrac{1}{\sqrt{b}}, \dfrac{1}{\sqrt{c}}\right)$:

$$(u \cdot v)^2 \le \Vert{}u\Vert{}^2 \Vert{}v\Vert{}^2$$ $$\left(\sqrt{a} \cdot \frac{1}{\sqrt{a}} + \sqrt{b} \cdot \frac{1}{\sqrt{b}} + \sqrt{c} \cdot \frac{1}{\sqrt{c}}\right)^2 \le (a + b + c) \left(\frac{1}{a} + \frac{1}{b} + \frac{1}{c}\right)$$ $$(1 + 1 + 1)^2 \le 1 \cdot \left(\frac{1}{a} + \frac{1}{b} + \frac{1}{c}\right)$$ $$3^2 \le \frac{1}{a} + \frac{1}{b} + \frac{1}{c} \implies \frac{1}{a} + \frac{1}{b} + \frac{1}{c} \ge 9$$

Metode 2: Menggunakan Titu's Lemma

$$\frac{1^2}{a} + \frac{1^2}{b} + \frac{1^2}{c} \ge \frac{(1 + 1 + 1)^2}{a + b + c} = \frac{3^2}{1} = 9$$

Kesamaan tercapai jika $a = b = c = \dfrac{1}{3}$.

Terbukti bahwa $\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c} \ge 9$ dengan nilai minimum tepat $9$.
Contoh 3
Untuk setiap bilangan riil positif $a, b, c > 0$, buktikan ketaksamaan Nesbitt berikut: $$\frac{a}{b + c} + \frac{b}{c + a} + \frac{c}{a + b} \ge \frac{3}{2}$$
Penyelesaian:

Ubah bentuk pembilang menjadi bentuk kuadrat agar Titu's Lemma dapat langsung diaplikasikan:

$$S = \frac{a^2}{a(b + c)} + \frac{b^2}{b(c + a)} + \frac{c^2}{c(a + b)}$$

Berdasarkan Titu's Lemma:

$$S \ge \frac{(a + b + c)^2}{a(b + c) + b(c + a) + c(a + b)} = \frac{(a + b + c)^2}{2(ab + bc + ca)}$$

Ingat identitas aljabar dasar:

$$(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$$

Karena selalu berlaku $a^2 + b^2 + c^2 \ge ab + bc + ca$, maka:

$$(a + b + c)^2 \ge (ab + bc + ca) + 2(ab + bc + ca) = 3(ab + bc + ca)$$

Akibatnya:

$$S \ge \frac{3(ab + bc + ca)}{2(ab + bc + ca)} = \frac{3}{2}$$
Terbukti bahwa $\dfrac{a}{b + c} + \dfrac{b}{c + a} + \dfrac{c}{a + b} \ge \dfrac{3}{2}$, dengan kesamaan terjadi saat $a = b = c$.
