Nilai dari \((2013 - 2015 + 2018 - 2019) + (2015 - 2010 + 2019 - 2018)\) adalah ...
  1. 8
  2. 6
  3. 5
  4. 3
  5. 2
Pateron
Pembahasan:

Kelompokkan suku-suku yang saling menghilangkan:

\[ \begin{aligned} &(2013 - 2015 + 2018 - 2019) + (2015 - 2010 + 2019 - 2018) \\ &= (2013 - 2010) + (-2015 + 2015) + (2018 - 2018) + (-2019 + 2019) \\ &= 3 + 0 + 0 + 0 = \boxed{\boxed{3}} \end{aligned} \]
Jadi, nilai dari ekspresi tersebut adalah 3.
