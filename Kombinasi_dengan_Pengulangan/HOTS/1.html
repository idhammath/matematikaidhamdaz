Berikut adalah soal tingkat ... materi Kombinasi dengan Pengulangan

Diberikan bilangan asli \(a, b, c, d\) di mana \(a + b + c + d = 10\). Jika \(a < 3\) dan \(c > 3\), maka banyak pasangan \((a, b, c, d)\) yang mungkin adalah ....

Komunitas Pendidik Matematika
Pembahasan:

Karena \(a, b, c, d\) adalah bilangan asli (\(\ge 1\)) dengan batasan \(a < 3\) dan \(c > 3\), maka:

  • \(a \in \{1, 2\}\)
  • \(b \ge 1\)
  • \(c \ge 4\)
  • \(d \ge 1\)

Kita lakukan substitusi variabel non-negatif (\(a', b', c', d' \ge 0\)): \[ a = a' + 1 \quad (\text{dengan } a' \in \{0, 1\}) \] \[ b = b' + 1, \quad c = c' + 4, \quad d = d' + 1 \] Substitusikan ke dalam persamaan: \[ \begin{aligned} (a' + 1) + (b' + 1) + (c' + 4) + (d' + 1) &= 10 \\[4pt] a' + b' + c' + d' + 7 &= 10 \\[4pt] a' + b' + c' + d' &= 3 \end{aligned} \]

Karena \(a' < 2\), kita bagi menjadi dua kasus:

1. Kasus \(a' = 0\):
Persamaan menjadi \(b' + c' + d' = 3\). Banyaknya solusi bilangan bulat non-negatif dihitung menggunakan kombinasi dengan pengulangan: \[ \binom{3 + 3 - 1}{3} = \binom{5}{3} = \frac{5 \times 4}{2 \times 1} = 10 \]

2. Kasus \(a' = 1\):
Persamaan menjadi \(b' + c' + d' = 2\). Banyaknya solusi bilangan bulat non-negatif: \[ \binom{2 + 3 - 1}{2} = \binom{4}{2} = \frac{4 \times 3}{2 \times 1} = 6 \]

Total banyaknya pasangan yang mungkin adalah: \[ 10 + 6 = 16 \]

Jadi, banyak pasangan \((a, b, c, d)\) yang mungkin adalah \(16\).

Diberikan bilangan asli \(a, b, c, d\) di mana \(2a + 2b + 2c + d = 15\). Maka banyak pasangan \((a, b, c, d)\) yang mungkin adalah ....

Komunitas Pendidik Matematika
Pembahasan:

Perhatikan persamaan: \[ 2(a + b + c) + d = 15 \] Karena \(2(a + b + c)\) bernilai genap dan \(15\) bernilai ganjil, maka \(d\) harus merupakan bilangan ganjil.

Karena \(a, b, c, d\) adalah bilangan asli (\(\ge 1\)), kita dapat memisalkan: \[ a = a' + 1, \quad b = b' + 1, \quad c = c' + 1 \quad (a', b', c' \ge 0) \] Karena \(d\) bilangan asli ganjil, kita dapat memisalkan: \[ d = 2d' + 1 \quad (d' \ge 0) \]

Substitusikan ke persamaan awal: \[ \begin{aligned} 2(a' + 1) + 2(b' + 1) + 2(c' + 1) + (2d' + 1) &= 15 \\[4pt] (2a' + 2) + (2b' + 2) + (2c' + 2) + (2d' + 1) &= 15 \\[4pt] 2a' + 2b' + 2c' + 2d' + 7 &= 15 \\[4pt] 2(a' + b' + c' + d') &= 8 \\[4pt] a' + b' + c' + d' &= 4 \end{aligned} \]

Banyaknya solusi bilangan bulat non-negatif \((a', b', c', d')\) diperoleh dengan rumus kombinasi dengan pengulangan: \[ \binom{n + k - 1}{k} = \binom{4 + 4 - 1}{4} = \binom{7}{4} = \frac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35 \]

Jadi, banyak pasangan \((a, b, c, d)\) yang mungkin adalah \(35\).

Bilangan OSK adalah bilangan 4 angka yang tidak dimulai dengan angka 0 dan hasil penjumlahan semua digitnya adalah 8. Sebagai contoh, 2024 merupakan bilangan OSK. Banyaknya bilangan OSK adalah ....

OSK SMA 2024
Pembahasan:

Misalkan bilangan 4 angka tersebut adalah \(\overline{abcd}\).

  • Digit pertama tidak boleh nol: \(a \in \{1, 2, \dots, 9\}\) (\(a \ge 1\))
  • Digit lainnya: \(b, c, d \in \{0, 1, \dots, 9\}\) (\(b, c, d \ge 0\))
  • Jumlah seluruh digit adalah 8: \(a + b + c + d = 8\)

Perhatikan bahwa karena jumlah keempat digit hanya \(8\), tidak ada digit yang dapat bernilai lebih dari \(8\), sehingga batasan digit \(\le 9\) otomatis terpenuhi untuk semua variabel.

Karena \(a \ge 1\), kita substitusikan \(a = a' + 1\) dengan \(a' \ge 0\): \[ \begin{aligned} (a' + 1) + b + c + d &= 8 \\[4pt] a' + b + c + d &= 7 \end{aligned} \]

Banyaknya bilangan OSK sama dengan banyaknya solusi bulat non-negatif dari persamaan \(a' + b + c + d = 7\): \[ \begin{aligned} \binom{7 + 4 - 1}{7} &= \binom{10}{7} = \binom{10}{3} \\[6pt] &= \frac{10 \times 9 \times 8}{3 \times 2 \times 1} \\[6pt] &= 10 \times 3 \times 4 = 120 \end{aligned} \]

Jadi, banyaknya bilangan OSK yang memenuhi adalah \(120\).

Tentukan banyaknya tripel bilangan asli \((a, b, c)\), di mana ketiganya tidak habis dibagi 3, sedemikian sehingga: \[ a + b + c = 60 \]

Grup WhatsApp
Pembahasan:

Diketahui \(a, b, c\) adalah bilangan asli yang tidak habis dibagi 3, yang berarti \(a, b, c \not\equiv 0 \pmod 3\). Oleh karena itu, masing-masing nilai \(a, b, c\) hanya mungkin kongruen dengan \(1\) atau \(2\) modulo 3.

Karena \(a + b + c = 60 \equiv 0 \pmod 3\), jumlah dari sisa pembagian ketiganya harus kelipatan 3:

  • Jika ketiganya bersisa \(1\): \(1 + 1 + 1 = 3 \equiv 0 \pmod 3\) (memenuhi)
  • Jika ketiganya bersisa \(2\): \(2 + 2 + 2 = 6 \equiv 0 \pmod 3\) (memenuhi)
  • Kombinasi campuran seperti \((1, 1, 2) \to 4 \equiv 1\) atau \((1, 2, 2) \to 5 \equiv 2\) tidak menghasilkan kelipatan 3.

Maka terdapat dua kasus yang perlu dihitung:

Kasus 1: \(a, b, c \equiv 1 \pmod 3\)
Karena \(a, b, c \ge 1\), kita nyatakan dalam bentuk: \[ a = 3k + 1, \quad b = 3l + 1, \quad c = 3m + 1 \quad (k, l, m \ge 0) \] Substitusikan ke persamaan: \[ \begin{aligned} (3k + 1) + (3l + 1) + (3m + 1) &= 60 \\[4pt] 3(k + l + m) + 3 &= 60 \\[4pt] 3(k + l + m) &= 57 \\[4pt] k + l + m &= 19 \end{aligned} \] Banyak tripel bulat non-negatif \((k, l, m)\) adalah: \[ \binom{19 + 3 - 1}{19} = \binom{21}{2} = \frac{21 \times 20}{2} = 210 \]

Kasus 2: \(a, b, c \equiv 2 \pmod 3\)
Karena \(a, b, c \ge 1\), kita nyatakan dalam bentuk: \[ a = 3k + 2, \quad b = 3l + 2, \quad c = 3m + 2 \quad (k, l, m \ge 0) \] Substitusikan ke persamaan: \[ \begin{aligned} (3k + 2) + (3l + 2) + (3m + 2) &= 60 \\[4pt] 3(k + l + m) + 6 &= 60 \\[4pt] 3(k + l + m) &= 54 \\[4pt] k + l + m &= 18 \end{aligned} \] Banyak tripel bulat non-negatif \((k, l, m)\) adalah: \[ \binom{18 + 3 - 1}{18} = \binom{20}{2} = \frac{20 \times 19}{2} = 190 \]

Total banyaknya tripel yang mungkin adalah: \[ 210 + 190 = 400 \]

Jadi, banyaknya tripel bilangan asli \((a, b, c)\) yang memenuhi adalah \(400\).
