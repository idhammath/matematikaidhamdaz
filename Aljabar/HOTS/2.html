Diketahui x,y ∈ ℝ, x > 2016 dan x > 2017. Jika \(2016\sqrt{(x+2016)(x-2016)}+2017\sqrt{(x+2017)(x-2017)}=\dfrac12\left(x^2+y^2\right)\)
maka nilai xy =
  1. 4066272
  2. 4068289
  3. 5750577,011
  4. 5756281,95
  5. 8132544
Grup Telegram
Pembahasan:
Misal \(a=\sqrt{(x+2016)(x-2016)}\)

\(\begin{aligned} a^2&=x^2-2016^2\\ x^2&=a^2+2016^2 \end{aligned}\)

Misal \(b=\sqrt{(y+2017)(y-2017)}\)

\(\begin{aligned} b^2&=y^2-2017^2\\ y^2&=b^2+2017^2 \end{aligned}\)

\(\begin{aligned} 2016a+2017b&=\dfrac12\left(a^2+2016^2+b^2+2017^2\right)\\ 2\cdot2016a+2\cdot2017b&=a^2+2016^2+b^2+2017^2\\ a^2-2\cdot2016a+2016^2+b^2-2\cdot2017b+2017^2&=0\\ (a-2016)^2+(b-2017)^2&=0 \end{aligned}\)
didapat a= 2016 dan b= 2017

\(\begin{aligned} x^2&=2016^2+2016^2\\ &=2\cdot2016^2\\ x&=2016\sqrt2 \end{aligned}\)

\(\begin{aligned} y^2&=2017^2+2017^2\\ &=2\cdot2017^2\\ x&=2017\sqrt2 \end{aligned}\)

\(\begin{aligned} xy&=2016\sqrt2\cdot2017\sqrt2\\ &=\boxed{\boxed{8132544}} \end{aligned}\)
Jadi, xy = 8132544.

Jika \(n-\dfrac1n=x\), maka berapakah \(n^2+\dfrac1{n^2}\) jika dinyatakan dalam x?
  1. x2 + 1
  2. x + 1
  3. x3 + 1
  4. x2 + 2
  5. \(\sqrt{x}+\sqrt1\)
Grup Telegram
Pembahasan:
\(\begin{aligned} n-\dfrac1n&=x\\ \left(n-\dfrac1n\right)^2&=x^2\\ n^2-2(n)\left(\dfrac1n\right)+\left(\dfrac1n\right)^2&=x^2\\ n^2-2+\dfrac1{n^2}&=x^2\\ n^2+\dfrac1{n^2}&=\boxed{\boxed{x^2+2}} \end{aligned}\)
Jadi, \(n^2+\dfrac1{n^2}=x^2+2\).

Nilai dari \(\dfrac{(1945+2011)^2+(2011-1945)^2}{1945^2+2011^2}\) adalah ....
Diktat Pembinaan Olimpiade
Pembahasan:
Misal a = 1945 dan b = 2011

\(\begin{aligned} \dfrac{(1945+2011)^2+(2011-1945)^2}{1945^2+2011^2}&=\dfrac{(a+b)^2+(b-a)^2}{a^2+b^2}\\ &=\dfrac{a^2+2ab+b^2+b^2-2ab+a^2}{a^2+b^2}\\ &=\dfrac{2\left(a^2+b^2\right)}{a^2+b^2}\\ &=\boxed{\boxed{2}} \end{aligned}\)

Bilangan-bilangan real a, b, dan c memenuhi sistem persamaan a + b = 8 dan ab = c2 + 16. Hasil dari a + b + c = ....
  1. 4
  2. 5
  3. 6
  4. 7
  5. 8
Matematika Zone Id
Pembahasan:
\(\begin{aligned} ab&\leq\dfrac{(a+b)^2}4\\ &\leq\dfrac{8^2}4\\ &\leq16 \end{aligned}\)

\(\begin{aligned} c^2+16&\geq16\\ ab&\geq16\\ \end{aligned}\)
Didapat ab = 16 dan c = 0

a + b + c = 8 + 0 = 8
Jadi, a + b + c = 8.

Telegram
Pembahasan:
$$\begin{aligned} \left(x+\dfrac1x\right)^2&=4^2\\ x^2+2+\dfrac1{x^2}&=16\\ x^2+\dfrac1{x^2}&=14 \end{aligned}$$ $$\begin{aligned} \left(x^2+\dfrac1{x^2}\right)\left(x+\dfrac1x\right)&=(14)(4)\\ x^3+x+\dfrac1x+\dfrac1{x^3}&=56\\ x^3+4+\dfrac1{x^3}&=56\\ x^3+\dfrac1{x^3}&=\boxed{\boxed{52}} \end{aligned}$$

Jika e, b, c adalah bilangan real yang memenuhi |a − b| = 1, |b − c| = 1, |c − a| = 2 dan a × b × c = 60. Nilai dari \(\dfrac{a}{bc}+\dfrac{b}{ac}+\dfrac{c}{ab}-\dfrac1a-\dfrac1b-\dfrac1c=...\)
Grup Telegram
Pembahasan:
\(\begin{aligned} \dfrac{a}{bc}+\dfrac{b}{ac}+\dfrac{c}{ab}-\dfrac1a-\dfrac1b-\dfrac1c&=\dfrac{a^2+b^2+c^2-ab-bc-ac}{abc}\\[8pt] &=\dfrac{2a^2+2b^2+2c^2-2ab-2bc-2ac}{2abc}\\[8pt] &=\dfrac{(a-b)^2+(b-c)^2+(c-a)^2}{2\cdot60}\\[8pt] &=\dfrac{1^2+1^2+2^2}{120}\\[8pt] &=\dfrac{1+1+4}{120}\\[8pt] &=\dfrac6{120}\\ &=\boxed{\boxed{\dfrac1{20}}} \end{aligned}\)
Jadi, \(\dfrac{a}{bc}+\dfrac{b}{ac}+\dfrac{c}{ab}-\dfrac1a-\dfrac1b-\dfrac1c=\dfrac1{20}.\)
