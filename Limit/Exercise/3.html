Buktikan limit fungsi multivariabel berikut menggunakan definisi presisi limit \((\varepsilon - \delta)\): \[\lim_{(x,y)\to(3,2)}(3x-4y)=1\]

Grup Telegram
Pembahasan:

Akan ditunjukkan bahwa untuk setiap \(\varepsilon > 0\), terdapat \(\delta > 0\) sedemikian rupa sehingga jika \[0 < \sqrt{(x-3)^2+(y-2)^2} < \delta\] maka \[|(3x-4y)-1| < \varepsilon\]

Perhatikan bahwa jika \(\sqrt{(x-3)^2+(y-2)^2} < \delta\), maka berlaku: \[|x-3| \le \sqrt{(x-3)^2+(y-2)^2} < \delta \quad \text{dan} \quad |y-2| \le \sqrt{(x-3)^2+(y-2)^2} < \delta\]

Uraikan bentuk nilai mutlak yang ingin dibatasi:

\[ \begin{aligned} |(3x-4y)-1| &= |3(x-3) - 4(y-2)|\\[3.7pt] &\le |3(x-3)| + |4(y-2)|\\[3.7pt] &= 3|x-3| + 4|y-2|\\[3.7pt] &< 3\delta + 4\delta = 7\delta \end{aligned} \]

Pilihlah \(\delta = \dfrac{\varepsilon}{7}\). Maka: \[|(3x-4y)-1| < 7\left(\dfrac{\varepsilon}{7}\right) = \varepsilon\]

Jadi, terbukti secara definisi bahwa \(\displaystyle\lim_{(x,y)\to(3,2)}(3x-4y)=1\).

Diketahui \(f(x) = x^2 - 1\). Tentukan nilai dari: \[\lim_{p\to0}\dfrac{f(2+p)-f(2)}{p}\]

Grup Telegram
Pembahasan:

Substitusikan \(f(2+p) = (2+p)^2 - 1\) dan \(f(2) = 2^2 - 1 = 3\):

\[ \begin{aligned} \lim_{p\to0}\dfrac{f(2+p)-f(2)}{p}&=\lim_{p\to0}\dfrac{\left[(2+p)^2-1\right]-\left(2^2-1\right)}{p}\\[3.7pt] &=\lim_{p\to0}\dfrac{4+4p+p^2-1-3}{p}\\[3.7pt] &=\lim_{p\to0}\dfrac{4p+p^2}{p}\\[3.7pt] &=\lim_{p\to0}(4+p)\\[3.7pt] &=4+0 = 4 \end{aligned} \]

Catatan: Bentuk limit ini setara dengan definisi turunan \(f'(2)\). Karena \(f'(x)=2x\), maka \(f'(2)=2(2)=4\).

Jadi, \(\displaystyle\lim_{p\to0}\dfrac{f(2+p)-f(2)}{p}=4\).

\[\lim_{x\to0}\dfrac{x}{\sqrt{5-x}-\sqrt{5}}=\dots\]

Grup Telegram
Pembahasan:

Kalikan dengan sekawan dari penyebut:

\[ \begin{aligned} \lim_{x\to0}\dfrac{x}{\sqrt{5-x}-\sqrt{5}}&=\lim_{x\to0}\dfrac{x}{\sqrt{5-x}-\sqrt{5}}\cdot\dfrac{\sqrt{5-x}+\sqrt{5}}{\sqrt{5-x}+\sqrt{5}}\\[3.7pt] &=\lim_{x\to0}\dfrac{x\left(\sqrt{5-x}+\sqrt{5}\right)}{(5-x)-5}\\[3.7pt] &=\lim_{x\to0}\dfrac{x\left(\sqrt{5-x}+\sqrt{5}\right)}{-x}\\[3.7pt] &=\lim_{x\to0}\left(-\left(\sqrt{5-x}+\sqrt{5}\right)\right)\\[3.7pt] &=-\left(\sqrt{5-0}+\sqrt{5}\right) = -2\sqrt{5} \end{aligned} \]
Jadi, \(\displaystyle\lim_{x\to0}\dfrac{x}{\sqrt{5-x}-\sqrt{5}}=-2\sqrt{5}\).

\[\lim_{x\to0}\dfrac{x^3+2x^2}{x^4-x^3+5x^2}=\dots\]

Grup Telegram
Pembahasan:

Faktorkan \(x^2\) dari pembilang dan penyebut:

\[ \begin{aligned} \lim_{x\to0}\dfrac{x^3+2x^2}{x^4-x^3+5x^2}&=\lim_{x\to0}\dfrac{x^2(x+2)}{x^2\left(x^2-x+5\right)}\\[3.7pt] &=\lim_{x\to0}\dfrac{x+2}{x^2-x+5}\\[3.7pt] &=\dfrac{0+2}{0^2-0+5} = \dfrac{2}{5} \end{aligned} \]
Jadi, \(\displaystyle\lim_{x\to0}\dfrac{x^3+2x^2}{x^4-x^3+5x^2}=\dfrac{2}{5}\).

\[\lim_{x\to-3}\dfrac{2x+1}{x^2-3x+4}=\dots\]

Grup Telegram
Pembahasan:

Gunakan teknik substitusi langsung karena penyebut terdefinisi dan tidak bernilai nol:

\[ \begin{aligned} \lim_{x\to-3}\dfrac{2x+1}{x^2-3x+4}&=\dfrac{2(-3)+1}{(-3)^2-3(-3)+4}\\[3.7pt] &=\dfrac{-6+1}{9+9+4}\\[3.7pt] &=\dfrac{-5}{22} = -\dfrac{5}{22} \end{aligned} \]
Jadi, \(\displaystyle\lim_{x\to-3}\dfrac{2x+1}{x^2-3x+4}=-\dfrac{5}{22}\).

\[\lim_{x\to0}\dfrac{x^2+3x-1}{x^3+5x}=\dots\]

Grup Telegram
Pembahasan:

Periksa nilai limit dari pembilang dan penyebut:

\[ \lim_{x\to0}(x^2+3x-1) = -1 \quad \text{dan} \quad \lim_{x\to0}(x^3+5x) = \lim_{x\to0}x(x^2+5) = 0 \]

Karena pembilang bernilai bukan nol (\(-1\)) dan penyebut mendekati \(0\), maka limitnya tidak terdefinisi secara bilangan real (asintot tegak / menuju tak hingga \(\infty\)):

\[ \lim_{x\to0}\dfrac{x^2+3x-1}{x^3+5x} \to \infty \]
Jadi, nilainya menuju \(\infty\) (tidak berhingga).

Diberikan fungsi \(f(x) = \dfrac{x^2-x-2}{x-2}\). Tentukan nilai \(\displaystyle\lim_{x\to2}\dfrac{x^2-x-2}{x-2}\) dengan menggunakan tabel pendekatan nilai berikut:

Nilai \(x\) Nilai \(y = f(x)\)
\(1{,}95\)...
\(1{,}98\)...
\(1{,}99\)...
\(2{,}01\)...
\(2{,}05\)...
\(2{,}10\)...
Grup Telegram
Pembahasan:

Karena \(\dfrac{x^2-x-2}{x-2} = \dfrac{(x-2)(x+1)}{x-2} = x+1\) untuk setiap \(x \ne 2\), maka nilai fungsi mendekati:

Nilai \(x\) Nilai \(y = x + 1\)
\(1{,}95\)\(2{,}95\)
\(1{,}98\)\(2{,}98\)
\(1{,}99\)\(2{,}99\)
\(2{,}01\)\(3{,}01\)
\(2{,}05\)\(3{,}05\)
\(2{,}10\)\(3{,}10\)

Dari tabel terlihat bahwa saat \(x\) mendekati \(2\) baik dari kiri maupun kanan, nilai \(y\) mendekati \(3\).

Jadi, \(\displaystyle\lim_{x\to2}\dfrac{x^2-x-2}{x-2}=3\).

\[\lim_{x\to3}\left(x^2+2x+10\right)=\dots\]

Pembahasan:

Karena fungsi polinom kontinu di setiap titik, substitusikan langsung nilai \(x = 3\):

\[ \begin{aligned} \lim_{x\to3}\left(x^2+2x+10\right)&=3^2+2(3)+10\\[3.7pt] &=9+6+10 = 25 \end{aligned} \]
Jadi, \(\displaystyle\lim_{x\to3}\left(x^2+2x+10\right)=25\).

Pembahasan:

Jadi, \(\displaystyle\lim_{x\to2}(3x+2)=8\).

Tentukan status nilai limit fungsi berikut saat disubstitusi langsung, apakah terdefinisi, tidak terdefinisi, atau bentuk tak tentu \(\dfrac{0}{0}\):

  1. \(\displaystyle\lim_{x\to3}\dfrac{x^2-1}{x+1}\)
  2. \(\displaystyle\lim_{x\to2}\dfrac{2x^2+1}{2x-4}\)
  3. \(\displaystyle\lim_{x\to4}\dfrac{x^2-16}{x-4}\)
Latihan Pra UKK Semester Genap Kelas XI
Pembahasan:
  1. Substitusi langsung \(x = 3\): \[ \lim_{x\to3}\dfrac{x^2-1}{x+1} = \dfrac{3^2-1}{3+1} = \dfrac{8}{4} = 2 \] Penyebut tidak sama dengan nol, sehingga nilainya terdefinisi.
  2. Substitusi langsung \(x = 2\): \[ \lim_{x\to2}\dfrac{2x^2+1}{2x-4} = \dfrac{2(2)^2+1}{2(2)-4} = \dfrac{9}{0} \] Pembagian dengan nol menghasilkan bilangan yang tidak terdefinisi (menuju \(\pm\infty\)).
  3. Substitusi langsung \(x = 4\): \[ \lim_{x\to4}\dfrac{x^2-16}{x-4} = \dfrac{4^2-16}{4-4} = \dfrac{0}{0} \] Merupakan bentuk tak tentu \(\dfrac{0}{0}\) (dapat diselesaikan dengan pemfaktoran menjadi \(\lim_{x\to4}(x+4) = 8\)).
Jadi statusnya:
  1. Terdefinisi (bernilai 2)
  2. Tidak terdefinisi (\(\frac{9}{0}\))
  3. Bentuk tak tentu \(\dfrac{0}{0}\)
