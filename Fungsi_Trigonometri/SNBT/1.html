Berikut adalah soal tingkat ... materi Fungsi Trigonometri

Grafik fungsi trigonometri \(f(x) = a\cos(kx) + c\) dengan \(a > 0\) dan \(k > 0\) memiliki nilai maksimum \(5\), nilai minimum \(-1\), serta periode gelombang sebesar \(\pi\). Nilai dari \(f\left(\dfrac{\pi}{6}\right)\) adalah ....

  1. \(2\)
  2. \(2{,}5\)
  3. \(3{,}5\)
  4. \(4\)
  5. \(5\)
SNBT / UTBK
Pembahasan:

Langkah 1: Menentukan nilai amplitudo (\(a\)) dan pergeseran vertikal (\(c\))

Berdasarkan sifat umum grafik fungsi cosinus \(f(x) = a\cos(kx) + c\) dengan \(a > 0\):

  • Nilai maksimum: \(y_{\text{maks}} = a + c = 5\)
  • Nilai minimum: \(y_{\text{min}} = -a + c = -1\)

Amplitudo gelombang (\(a\)) dapat dihitung dengan setengah dari selisih nilai ekstrem:

\[ a = \frac{y_{\text{maks}} - y_{\text{min}}}{2} = \frac{5 - (-1)}{2} = \frac{6}{2} = 3 \]

Garis tengah / pergeseran vertikal (\(c\)) adalah rata-rata nilai ekstrem:

\[ c = \frac{y_{\text{maks}} + y_{\text{min}}}{2} = \frac{5 + (-1)}{2} = \frac{4}{2} = 2 \]

Langkah 2: Menentukan nilai frekuensi gelombang (\(k\))

Periode gelombang fungsi cosinus dirumuskan sebagai:

\[ T = \frac{2\pi}{k} \]

Diketahui periode \(T = \pi\), maka:

\[ \pi = \frac{2\pi}{k} \implies k = 2 \]

Langkah 3: Menyusun rumus fungsi \(f(x)\) dan evaluasi nilai

Dengan demikian, rumus lengkap fungsi trigonometri tersebut adalah:

\[ f(x) = 3\cos(2x) + 2 \]

Substitusikan nilai \(x = \dfrac{\pi}{6}\):

\[ \begin{aligned} f\left(\frac{\pi}{6}\right) &= 3\cos\left(2 \cdot \frac{\pi}{6}\right) + 2 \\ &= 3\cos\left(\frac{\pi}{3}\right) + 2 \\ &= 3\left(\frac{1}{2}\right) + 2 \\ &= 1{,}5 + 2 \\ &= 3{,}5 \end{aligned} \]
Jadi, nilai dari \(f\left(\dfrac{\pi}{6}\right)\) adalah \(3{,}5\).
