Ringkasan dan penjelasan lengkap materi Floor Function

1. Pengertian Floor Function, Ceiling Function & Bagian Pecahan

Dalam matematika diskrit dan teori bilangan, Floor Function (fungsi lantai atau fungsi bilangan bulat terbesar / greatest integer function) dari suatu bilangan real $x$, dilambangkan dengan $\lfloor x \rfloor$ atau $[x]$, didefinisikan sebagai bilangan bulat terbesar yang kurang dari atau sama dengan $x$: $$\lfloor x \rfloor = \max \{n \in \mathbb{Z} \mid n \le x\}$$ Selain fungsi lantai, terdapat dua fungsi pendamping yang selalu berkaitan erat dengannya:

  • Ceiling Function (Fungsi Atap $\lceil x \rceil$): Bilangan bulat terkecil yang lebih dari atau sama dengan $x$: $$\lceil x \rceil = \min \{n \in \mathbb{Z} \mid n \ge x\}$$
  • Fractional Part (Bagian Pecahan $\{x\}$): Selisih antara bilangan real $x$ dengan nilai fungsi lantainya: $$\{x\} = x - \lfloor x \rfloor \iff x = \lfloor x \rfloor + \{x\} \quad \text{dengan } 0 \le \{x\} < 1$$

Hati-Hati pada Bilangan Negatif!
Secara geometris pada garis bilangan real, nilai $\lfloor x \rfloor$ selalu diperoleh dengan melangkah ke sebelah kiri menuju bilangan bulat terdekat (bukan sekadar membuang angka di belakang koma!):

  • Untuk $x = 2{,}7 \implies \lfloor 2{,}7 \rfloor = 2$ dan $\{2{,}7\} = 2{,}7 - 2 = 0{,}7$.
  • Untuk $x = -2{,}3 \implies$ bilangan bulat di sebelah kiri $-2{,}3$ adalah $-3$ (bukan $-2$!). Maka $\lfloor -2{,}3 \rfloor = -3$ dan bagian pecahannya tetap positif: $\{-2{,}3\} = -2{,}3 - (-3) = 0{,}7$.

2. Grafik Fungsi Tangga $f(x) = \lfloor x \rfloor$

Grafik fungsi $y = \lfloor x \rfloor$ berbentuk deretan ruas garis horizontal yang menyerupai anak tangga, sehingga sering disebut Fungsi Tangga (Step Function):

  • Pada setiap interval setengah terbuka $[n, n+1)$, nilai fungsi konstan sama dengan $n$.
  • Di ujung kiri setiap ruas ($x = n$), terdapat bulatan penuh ($\bullet$) karena $\lfloor n \rfloor = n$.
  • Di ujung kanan setiap ruas ($x = n+1$), terdapat bulatan kosong ($\circ$) karena saat mencapai $n+1$, nilai fungsi meloncat naik ke $n+1$.
  • Fungsi ini diskontinu (terputus) di setiap titik bilangan bulat $x \in \mathbb{Z}$.

3. Pertidaksamaan Dasar & Sifat-Sifat Aljabar Floor Function

Kunci utama untuk menyelesaikan persamaan atau pertidaksamaan yang memuat $\lfloor x \rfloor$ adalah mengubahnya menjadi pertidaksamaan aljabar biasa menggunakan definisi fundamental berikut:

💡 Ekuivalensi Utama & Batas Apit Floor Function (Wajib Hafal!):
1. $\lfloor x \rfloor = n \iff n \le x < n + 1 \quad (\text{untuk } n \in \mathbb{Z})$
2. $x - 1 < \lfloor x \rfloor \le x < \lfloor x \rfloor + 1$
3. $0 \le x - \lfloor x \rfloor < 1$

Selain itu, untuk sembarang $x, y \in \mathbb{R}$ dan bilangan bulat $m, n \in \mathbb{Z}$, berlaku sifat-sifat berikut:

  1. Sifat Mengeluarkan Bilangan Bulat: Bilangan bulat di dalam tanda floor dapat langsung dikeluarkan atau dimasukkan: $$\lfloor x + m \rfloor = \lfloor x \rfloor + m$$
  2. Sifat Penjumlahan Dua Variabel (Sub-aditif):
    Secara umum $\lfloor x + y \rfloor \neq \lfloor x \rfloor + \lfloor y \rfloor$. Karena $0 \le \{x\} + \{y\} < 2$, maka nilai $\lfloor x + y \rfloor$ hanya memiliki dua kemungkinan: $$\lfloor x \rfloor + \lfloor y \rfloor \le \lfloor x + y \rfloor \le \lfloor x \rfloor + \lfloor y \rfloor + 1$$
  3. Sifat Negasi (Lawan Bilangan): $$\lfloor x \rfloor + \lfloor -x \rfloor = \begin{cases} 0, & \text{jika } x \in \mathbb{Z} \\ -1, & \text{jika } x \notin \mathbb{Z} \end{cases}$$ serta berlaku hubungan $\lceil x \rceil = -\lfloor -x \rfloor$.
  4. Sifat Pembagian Berjenjang (Nested Division): Untuk setiap bilangan asli $n \in \mathbb{N}$ dan $x \in \mathbb{R}$: $$\left\lfloor \frac{\lfloor x \rfloor}{n} \right\rfloor = \left\lfloor \frac{x}{n} \right\rfloor$$
  5. Pertidaksamaan dengan Bilangan Bulat $n \in \mathbb{Z}$:
    • $\lfloor x \rfloor < n \iff x < n$    dan    $\lfloor x \rfloor \le n \iff x < n + 1$
    • $\lfloor x \rfloor \ge n \iff x \ge n$    dan    $\lfloor x \rfloor > n \iff x \ge n + 1$

4. Aplikasi Teori Bilangan & Identitas Hermite

a. Hubungan dengan Pembagian Bersisa (Algoritma Euclid)
Jika bilangan bulat $a$ dibagi oleh bilangan asli $b$, maka hasil bagi bulatnya adalah $q = \left\lfloor \frac{a}{b} \right\rfloor$ dan sisa pembagiannya ($r = a \bmod b$) dapat ditulis secara eksak sebagai: $$r = a - b \left\lfloor \frac{a}{b} \right\rfloor$$

b. Menghitung Banyaknya Kelipatan pada Suatu Rentang
Banyaknya bilangan bulat positif dari $1$ sampai $N$ yang habis dibagi oleh $k$ adalah: $$\text{Banyak kelipatan } k \text{ pada } [1, N] = \left\lfloor \frac{N}{k} \right\rfloor$$

c. Identitas Hermite (Sering Keluar di Olimpiade / HOTS)
Untuk setiap bilangan real $x \in \mathbb{R}$ dan bilangan asli $n \in \mathbb{N}$, berlaku identitas: $$\lfloor x \rfloor + \left\lfloor x + \frac{1}{n} \right\rfloor + \left\lfloor x + \frac{2}{n} \right\rfloor + \dots + \left\lfloor x + \frac{n - 1}{n} \right\rfloor = \lfloor nx \rfloor$$ Khusus untuk $n = 2$, diperoleh bentuk yang sangat populer: $$\lfloor x \rfloor + \left\lfloor x + \frac{1}{2} \right\rfloor = \lfloor 2x \rfloor$$

d. Strategi Menyelesaikan Persamaan yang Memuat $x$ dan $\lfloor x \rfloor$:

  • Metode 1 (Substitusi $x = n + r$): Misalkan $\lfloor x \rfloor = n \in \mathbb{Z}$ dan $\{x\} = r \in [0, 1)$, lalu substitusikan $x = n + r$ ke persamaan dan gunakan syarat $0 \le r < 1$ untuk membatasi nilai bilangan bulat $n$.
  • Metode 2 (Jepit Pertidaksamaan): Gunakan sifat $x - 1 < \lfloor x \rfloor \le x$ untuk menemukan rentang kemungkinan bilangan bulat $n = \lfloor x \rfloor$.

Contoh Soal & Pembahasan

No. 1
Nilai dari $\left\lfloor 3{,}7 \right\rfloor + \left\lfloor -3{,}7 \right\rfloor + \left\lceil -2{,}1 \right\rceil + \{-1{,}4\}$ adalah ....
  1. $-2{,}6$
  2. $-2{,}4$
  3. $-1{,}4$
  4. $-0{,}4$
  5. $0{,}6$
Penyelesaian:

Kita hitung nilai dari masing-masing suku secara cermat (perhatikan tanda negatif):

  • $\lfloor 3{,}7 \rfloor = 3$ (bilangan bulat terbesar $\le 3{,}7$).
  • $\lfloor -3{,}7 \rfloor = -4$ (bilangan bulat terbesar $\le -3{,}7$; ingat $-4 < -3{,}7 < -3$).
  • $\lceil -2{,}1 \rceil = -2$ (bilangan bulat terkecil $\ge -2{,}1$).
  • $\{-1{,}4\} = -1{,}4 - \lfloor -1{,}4 \rfloor = -1{,}4 - (-2) = 0{,}6$.

Jumlahkan keempat hasil tersebut: $$3 + (-4) + (-2) + 0{,}6 = -3 + 0{,}6 = -2{,}4$$

Jadi, hasil dari operasi tersebut adalah $-2{,}4$ (Jawaban B).
No. 2
Himpunan semua bilangan real $x$ yang memenuhi persamaan $\lfloor 2x - 1 \rfloor = 5$ adalah ....
  1. $2 \le x < 3$
  2. $3 \le x < \frac{7}{2}$
  3. $3 < x \le \frac{7}{2}$
  4. $\frac{5}{2} \le x < 3$
  5. $2 \le x < \frac{7}{2}$
Penyelesaian:

1. Gunakan ekuivalensi dasar fungsi lantai $\lfloor u \rfloor = n \iff n \le u < n + 1$: $$\lfloor 2x - 1 \rfloor = 5 \iff 5 \le 2x - 1 < 5 + 1$$ $$5 \le 2x - 1 < 6$$

2. Tambahkan $1$ pada ketiga ruas pertidaksamaan: $$6 \le 2x < 7$$

3. Bagi ketiga ruas dengan $2$: $$3 \le x < \frac{7}{2}$$

Jadi, himpunan penyelesaiannya adalah $3 \le x < \frac{7}{2}$ (Jawaban B).
No. 3
Jumlah semua bilangan real $x$ yang memenuhi persamaan $2\lfloor x \rfloor = x + 3\{x\}$ adalah ....
  1. $3{,}75$
  2. $4{,}25$
  3. $6{,}25$
  4. $7{,}50$
  5. $8{,}75$
Penyelesaian:

1. Misalkan $\lfloor x \rfloor = n$ (dengan $n \in \mathbb{Z}$) dan $\{x\} = r$ (dengan $0 \le r < 1$). Maka bilangan real $x$ dapat ditulis sebagai $x = n + r$.

2. Substitusikan $\lfloor x \rfloor = n$, $\{x\} = r$, dan $x = n + r$ ke dalam persamaan soal: $$2n = (n + r) + 3r$$ $$2n - n = 4r \implies n = 4r \iff r = \frac{n}{4}$$

3. Karena bagian pecahan wajib memenuhi syarat $0 \le r < 1$, maka: $$0 \le \frac{n}{4} < 1 \iff 0 \le n < 4$$ Karena $n$ adalah bilangan bulat, nilai $n$ yang memenuhi adalah $n \in \{0, 1, 2, 3\}$.

4. Cari nilai $x = n + r = n + \frac{n}{4} = \frac{5}{4}n$ untuk masing-masing nilai $n$:

  • $n = 0 \implies x_1 = 0$
  • $n = 1 \implies x_2 = \frac{5}{4} = 1{,}25$
  • $n = 2 \implies x_3 = \frac{10}{4} = 2{,}50$
  • $n = 3 \implies x_4 = \frac{15}{4} = 3{,}75$

Jumlah seluruh solusi real $x$ adalah $0 + 1{,}25 + 2{,}50 + 3{,}75 = 7{,}50$.

Jadi, jumlah semua bilangan real $x$ yang memenuhi persamaan tersebut adalah $7{,}50$ (Jawaban D).
No. 4
Nilai dari penjumlahan deret $S = \lfloor \sqrt{1} \rfloor + \lfloor \sqrt{2} \rfloor + \lfloor \sqrt{3} \rfloor + \lfloor \sqrt{4} \rfloor + \dots + \lfloor \sqrt{50} \rfloor$ adalah ....
  1. $196$
  2. $203$
  3. $210$
  4. $217$
  5. $224$
Penyelesaian:

1. Perhatikan bahwa nilai $\lfloor \sqrt{k} \rfloor$ bernilai konstan sama dengan bilangan bulat $m$ ketika: $$m \le \sqrt{k} < m + 1 \iff m^2 \le k < (m + 1)^2 \iff m^2 \le k \le (m + 1)^2 - 1$$ Banyaknya bilangan asli $k$ pada rentang tersebut adalah: $$\big[(m + 1)^2 - 1\big] - m^2 + 1 = (m^2 + 2m + 1) - m^2 = 2m + 1 \text{ suku}$$

2. Kelompokkan suku-suku dari $k = 1$ sampai $k = 50$ berdasarkan batas bilangan kuadrat sempurna ($1, 4, 9, 16, 25, 36, 49$):

  • Untuk $k = 1$ s.d. $3$ ($3$ suku): $\lfloor \sqrt{k} \rfloor = 1 \implies \text{Jumlah} = 3 \times 1 = 3$
  • Untuk $k = 4$ s.d. $8$ ($5$ suku): $\lfloor \sqrt{k} \rfloor = 2 \implies \text{Jumlah} = 5 \times 2 = 10$
  • Untuk $k = 9$ s.d. $15$ ($7$ suku): $\lfloor \sqrt{k} \rfloor = 3 \implies \text{Jumlah} = 7 \times 3 = 21$
  • Untuk $k = 16$ s.d. $24$ ($9$ suku): $\lfloor \sqrt{k} \rfloor = 4 \implies \text{Jumlah} = 9 \times 4 = 36$
  • Untuk $k = 25$ s.d. $35$ ($11$ suku): $\lfloor \sqrt{k} \rfloor = 5 \implies \text{Jumlah} = 11 \times 5 = 55$
  • Untuk $k = 36$ s.d. $48$ ($13$ suku): $\lfloor \sqrt{k} \rfloor = 6 \implies \text{Jumlah} = 13 \times 6 = 78$
  • Untuk $k = 49$ dan $50$ ($2$ suku terakhir): $\lfloor \sqrt{k} \rfloor = 7 \implies \text{Jumlah} = 2 \times 7 = 14$

3. Jumlahkan seluruh kelompok tersebut: $$S = 3 + 10 + 21 + 36 + 55 + 78 + 14 = 217$$

Jadi, nilai dari penjumlahan deret tersebut adalah $217$ (Jawaban D).
