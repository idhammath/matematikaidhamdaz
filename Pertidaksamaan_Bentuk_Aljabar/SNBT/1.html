Nilai \(p\) yang memenuhi pertidaksamaan \(\dfrac{x^2+px-2}{x^2-x+1}\gt-3\) adalah ....
  1. \(-7 \gt p \gt 1\)
  2. \(-1 \gt p \gt 7\)
  3. \(1 \gt p \gt 7\)
  1. \(p \lt -7\) atau \(p \gt 1\)
  2. \(p \lt -1\) atau \(p \gt 7\)
Grup WhatsApp
Pembahasan:
\(\begin{aligned} \dfrac{x^2+px-2}{x^2-x+1}&\gt-3\\[4pt] \dfrac{x^2+px-2}{x^2-x+1}+3&\gt0\\[4pt] \dfrac{x^2+px-2+3(x^2-x+1)}{x^2-x+1}&\gt0\\[4pt] \dfrac{x^2+px-2+3x^2-3x+3}{x^2-x+1}&\gt0\\[4pt] \dfrac{4x^2+(p-3)x+1}{x^2-x+1}&\gt0 \end{aligned}\)

Karena penyebut \(x^2 - x + 1\) selalu positif untuk setiap \(x \in \mathbb{R}\) (karena \(a = 1 \gt 0\) dan \(D = (-1)^2 - 4(1)(1) = -3 \lt 0\)), maka pertidaksamaan terpenuhi jika pembilang bernilai positif untuk nilai \(x\) tertentu, yang terjadi ketika: \(\begin{aligned} D&\gt0\\[4pt] b^2-4ac&\gt0\\[4pt] (p-3)^2-4(4)(1)&\gt0\\[4pt] p^2-6p+9-16&\gt0\\[4pt] p^2-6p-7&\gt0\\[4pt] (p+1)(p-7)&\gt0 \end{aligned}\)

Sehingga didapat: \[p \lt -1 \text{ atau } p \gt 7\]
Jadi, \(p \lt -1\) atau \(p \gt 7\).

Jika himpunan penyelesaian pertidaksamaan \(\dfrac3{1+x}\lt2\) dan \(\dfrac3{1-x}\gt2\) adalah \(\{x \mid x \in \mathbb{R},\ p \lt x \lt q\}\), maka \(4p - q =\) ....
  1. 0
  2. 1
  3. 2
  1. 3
  2. 4
Grup WhatsApp
Pembahasan:
Pertidaksamaan Pertama: \(\begin{aligned} \dfrac3{1+x}&\lt2\\[4pt] \dfrac3{x+1}-2&\lt0\\[4pt] \dfrac{3-2(x+1)}{x+1}&\lt0\\[4pt] \dfrac{-2x+1}{x+1}&\lt0\\[4pt] \dfrac{2x-1}{x+1}&\gt0 \end{aligned}\)
Diperoleh: \(x \lt -1\) atau \(x \gt \dfrac12\).

Pertidaksamaan Kedua: \(\begin{aligned} \dfrac3{1-x}&\gt2\\[4pt] \dfrac3{1-x}-2&\gt0\\[4pt] \dfrac{3-2(1-x)}{1-x}&\gt0\\[4pt] \dfrac{2x+1}{1-x}&\gt0\\[4pt] \dfrac{2x+1}{x-1}&\lt0 \end{aligned}\)
Diperoleh: \(-\dfrac12 \lt x \lt 1\).

Irisan kedua penyelesaian: \[\left(x \lt -1 \text{ atau } x \gt \dfrac12\right) \cap \left(-\dfrac12 \lt x \lt 1\right) \implies \dfrac12 \lt x \lt 1\] Maka diperoleh: \[p = \dfrac12, \quad q = 1\] Sehingga: \(\begin{aligned} 4p-q&=4\left(\dfrac12\right)-1\\ &=2-1\\ &=1 \end{aligned}\)
Jadi, \(4p - q = 1\).

Himpunan semua bilangan real \(|x| \gt 1\) yang memenuhi \(\dfrac{x^2-2x-6}{-x+2}\gt x\) adalah \(\{x \in \mathbb{R} \mid x \lt a \text{ atau } b \lt x \lt c\}\). Nilai \(a - b + c =\) ....
  1. -1
  2. -2
  3. -3
  1. 1
  2. 0
Grup WhatsApp
Pembahasan:
Syarat awal: \[|x| \gt 1 \iff x \lt -1 \text{ atau } x \gt 1\] Selesaikan pertidaksamaan: \(\begin{aligned} \dfrac{x^2-2x-6}{-x+2}&\gt x\\[4pt] \dfrac{x^2-2x-6}{-x+2}-x&\gt0\\[4pt] \dfrac{x^2-2x-6-x(-x+2)}{-x+2}&\gt0\\[4pt] \dfrac{x^2-2x-6+x^2-2x}{-x+2}&\gt0\\[4pt] \dfrac{2x^2-4x-6}{-x+2}&\gt0\\[4pt] \dfrac{x^2-2x-3}{-x+2}&\gt0\\[4pt] \dfrac{(x+1)(x-3)}{x-2}&\lt0 \end{aligned}\)
Pembuat nol: \(x = -1\), \(x = 2\), \(x = 3\).
Uji tanda menghasilkan: \[x \lt -1 \text{ atau } 2 \lt x \lt 3\] Irisan dengan \(|x| \gt 1\) (\(x \lt -1\) atau \(x \gt 1\)): \[x \lt -1 \text{ atau } 2 \lt x \lt 3\] Dari bentuk \(\{x \in \mathbb{R} \mid x \lt a \text{ atau } b \lt x \lt c\}\), didapat: \[a = -1, \quad b = 2, \quad c = 3\] Maka: \[a - b + c = -1 - 2 + 3 = 0\]
Jadi, \(a - b + c = 0\).
