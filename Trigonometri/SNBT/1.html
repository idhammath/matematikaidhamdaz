Nilai minimum dari fungsi $h(x) = \dfrac{1 - \tan^2 x}{2\sec^2 x}$ untuk $0 \le x \le 2\pi$ adalah ....
  1. $-3$
  2. $-2$
  3. $-1$
  4. $-\dfrac{1}{2}$
  5. $0$
Sumber: Dari Sherly
Pembahasan:
Sederhanakan fungsi trigonometri dengan mengubah ke bentuk sinus dan cosinus: $$\begin{aligned} \frac{1 - \tan^2 x}{2\sec^2 x} &= \frac{1 - \frac{\sin^2 x}{\cos^2 x}}{\frac{2}{\cos^2 x}}\\[4pt] &= \frac{\cos^2 x - \sin^2 x}{2}\\[4pt] &= \frac{1}{2}\cos 2x \end{aligned}$$ Nilai minimum dari $\cos 2x$ adalah $-1$, sehingga nilai minimum fungsinya adalah: $$\text{Minimum} = \frac{1}{2}(-1) = -\frac{1}{2}$$
Jadi, nilai minimum dari fungsi tersebut adalah $-\dfrac{1}{2}$ (D).
Jika $x - y = \dfrac{1}{2}\pi$, maka $\tan x$ adalah ....
  1. $\dfrac{1 + y^2}{y}$
  2. $-\dfrac{1 - y^2}{\tan y}$
  3. $\dfrac{\tan(1 - y)}{(1 + y)^2}$
  4. $\dfrac{\tan y}{(1 + y)^2}$
  5. $-\dfrac{1}{\tan y}$
Sumber: Grup Matematika Idhamdaz
Pembahasan:
Dari persamaan $x - y = \dfrac{1}{2}\pi$, diperoleh: $$x = \dfrac{1}{2}\pi + y$$ Maka nilai $\tan x$: $$\begin{aligned} \tan x &= \tan\left(\frac{1}{2}\pi + y\right)\\ &= -\cot y\\ &= -\frac{1}{\tan y} \end{aligned}$$
Jadi, $\tan x = -\dfrac{1}{\tan y}$ (E).
Jika $\sin x + \cos x = 2p$, maka $\sin^4 x + \cos^4 x = $ ....
  1. $1 - (2p^2 - 1)^2$
  2. $1 + \dfrac{1}{2}\left(2p^2 - 1\right)^2$
  3. $1 - \dfrac{1}{2}\left(2p^2 - 1\right)^2$
  4. $1 + \dfrac{1}{2}\left(4p^2 - 1\right)^2$
  5. $1 - \dfrac{1}{2}\left(4p^2 - 1\right)^2$
Sumber: Ganesha Operation
Pembahasan:
Kuadratkan kedua ruas persamaan $\sin x + \cos x = 2p$: $$\begin{aligned} (\sin x + \cos x)^2 &= (2p)^2\\ \sin^2 x + 2\sin x\cos x + \cos^2 x &= 4p^2\\ 1 + 2\sin x\cos x &= 4p^2\\ \sin x\cos x &= \frac{1}{2}\left(4p^2 - 1\right) \end{aligned}$$ Selanjutnya jabarkan $\sin^4 x + \cos^4 x$: $$\begin{aligned} \sin^4 x + \cos^4 x &= \left(\sin^2 x + \cos^2 x\right)^2 - 2\sin^2 x\cos^2 x\\ &= 1^2 - 2(\sin x\cos x)^2\\ &= 1 - 2\left(\frac{1}{2}\left(4p^2 - 1\right)\right)^2\\ &= 1 - \frac{1}{2}\left(4p^2 - 1\right)^2 \end{aligned}$$
Jadi, $\sin^4 x + \cos^4 x = 1 - \dfrac{1}{2}\left(4p^2 - 1\right)^2$ (E).
Nilai yang ekivalen dengan $\dfrac{\dfrac{\sin^2 x + \cos^2 x}{\tan^2 x + \cot^2 x}}{\dfrac{\sin^2 x - \cos^2 x}{\tan^2 x - \cot^2 x}}$ adalah ....
  1. $\dfrac{2}{2 + \sin^2 2x}$
  2. $\dfrac{2}{1 + 2\cos^2 2x}$
  3. $\dfrac{2\sec^2 x}{\sec^2 x - 1}$
  4. $\dfrac{2\csc^2 x}{\csc^2 x + 1}$
  5. $\dfrac{2\sec^2 x}{\sec^2 x + 1}$
Sumber: Grup Matematika Idhamdaz
Pembahasan:
Sederhanakan pecahan bertingkat menggunakan sifat aljabar dan identitas trigonometri: $$\begin{aligned} \frac{\frac{\sin^2 x + \cos^2 x}{\tan^2 x + \cot^2 x}}{\frac{\sin^2 x - \cos^2 x}{\tan^2 x - \cot^2 x}} &= \frac{\sin^2 x + \cos^2 x}{\tan^2 x + \cot^2 x} \cdot \frac{\tan^2 x - \cot^2 x}{\sin^2 x - \cos^2 x}\\[6pt] &= \frac{1}{\frac{\sin^2 x}{\cos^2 x} + \frac{\cos^2 x}{\sin^2 x}} \cdot \frac{\frac{\sin^2 x}{\cos^2 x} - \frac{\cos^2 x}{\sin^2 x}}{\sin^2 x - \cos^2 x}\\[6pt] &= \frac{1}{\frac{\sin^4 x + \cos^4 x}{\cos^2 x \sin^2 x}} \cdot \frac{\frac{\sin^4 x - \cos^4 x}{\cos^2 x \sin^2 x}}{\sin^2 x - \cos^2 x}\\[6pt] &= \frac{\cancel{\cos^2 x \sin^2 x}}{\sin^4 x + \cos^4 x} \cdot \frac{\left(\sin^2 x - \cos^2 x\right)\left(\sin^2 x + \cos^2 x\right)}{\cancel{\cos^2 x \sin^2 x}\left(\sin^2 x - \cos^2 x\right)}\\[6pt] &= \frac{1}{\left(\sin^2 x + \cos^2 x\right)^2 - 2\sin^2 x\cos^2 x} \cdot 1\\[6pt] &= \frac{1}{1^2 - \frac{1}{2}(2\sin x\cos x)^2} = \frac{1}{1 - \frac{1}{2}\sin^2 2x} = \frac{2}{2 - \sin^2 2x}\\[6pt] &= \frac{2}{1 + \cos^2 2x} = \frac{\frac{2}{\cos^2 x}}{\frac{1}{\cos^2 x} + 1} = \boxed{\frac{2\sec^2 x}{\sec^2 x + 1}} \end{aligned}$$
Jadi bentuk yang ekivalen adalah $\dfrac{2\sec^2 x}{\sec^2 x + 1}$ (E).
Diketahui $\sin\alpha\cos\alpha = \dfrac{8}{25}$. Nilai $\dfrac{1}{\sin\alpha} - \dfrac{1}{\cos\alpha}$ adalah ....
  1. $\dfrac{3}{25}$
  2. $\dfrac{9}{25}$
  3. $\dfrac{5}{8}$
  4. $\dfrac{3}{5}$
  5. $\dfrac{15}{8}$
Sumber: Grup Matematika Idhamdaz
Pembahasan:
Pertama tentukan nilai $(\cos\alpha - \sin\alpha)^2$: $$\begin{aligned} (\cos\alpha - \sin\alpha)^2 &= \cos^2\alpha + \sin^2\alpha - 2\sin\alpha\cos\alpha\\ &= 1 - 2\left(\frac{8}{25}\right)\\[4pt] &= 1 - \frac{16}{25} = \frac{9}{25}\\[4pt] \cos\alpha - \sin\alpha &= \sqrt{\frac{9}{25}} = \frac{3}{5} \end{aligned}$$ Selanjutnya hitung bentuk yang ditanyakan: $$\begin{aligned} \frac{1}{\sin\alpha} - \frac{1}{\cos\alpha} &= \frac{\cos\alpha - \sin\alpha}{\sin\alpha\cos\alpha}\\[6pt] &= \frac{\frac{3}{5}}{\frac{8}{25}}\\[6pt] &= \frac{3}{5} \cdot \frac{25}{8} = \boxed{\frac{15}{8}} \end{aligned}$$
Jadi, nilai $\dfrac{1}{\sin\alpha} - \dfrac{1}{\cos\alpha} = \dfrac{15}{8}$ (E).
