Tentukan lima suku yang pertama dari barisan bilangan berikut:
\(U_n = 5n\)
Grup Matematika Zone Indonesia
Pembahasan:
Untuk \(n = 1\):
\(U_1 = 5(1) = 5\)

Untuk \(n = 2\):
\(U_2 = 5(2) = 10\)

Untuk \(n = 3\):
\(U_3 = 5(3) = 15\)
Untuk \(n = 4\):
\(U_4 = 5(4) = 20\)

Untuk \(n = 5\):
\(U_5 = 5(5) = 25\)
Jadi, lima suku yang pertama dari barisan bilangan \(U_n = 5n\) adalah 5, 10, 15, 20, 25.
