Fungsi Naik dan Turun

Kumpulan soal latihan dan pembahasan mengenai fungsi naik dan fungsi turun dengan penerapan konsep turunan pertama serta analisis garis bilangan interval.

STANDAR

Fungsi \(f(x) = \cos\left(2x + \dfrac{\pi}{2}\right)\) dengan \(0 \le x \le \pi\), naik pada interval ....

Grup Telegram
Pembahasan:
Turunan pertama dari \(f(x)\): \[ f'(x) = -2\sin\left(2x + \dfrac{\pi}{2}\right) \] Fungsi \(f(x)\) naik jika \(f'(x) > 0\): \[\begin{aligned} -2\sin\left(2x + \dfrac{\pi}{2}\right) &> 0 \\[4pt] \sin\left(2x + \dfrac{\pi}{2}\right) &< 0 \end{aligned}\] Menentukan pembuat nol \(f'(x) = 0\) pada interval \(0 \le x \le \pi\): \[\begin{aligned} \sin\left(2x + \dfrac{\pi}{2}\right) &= 0 \\ 2x + \dfrac{\pi}{2} &= \{0, \pi, 2\pi, 3\pi, 4\pi\} \\[4pt] 2x &= \left\{0 - \dfrac{\pi}{2}, \pi - \dfrac{\pi}{2}, 2\pi - \dfrac{\pi}{2}, 3\pi - \dfrac{\pi}{2}, 4\pi - \dfrac{\pi}{2}\right\} \\[4pt] 2x &= \left\{-\dfrac{\pi}{2}, \dfrac{\pi}{2}, \dfrac{3\pi}{2}, \dfrac{5\pi}{2}, \dfrac{7\pi}{2}\right\} \\[4pt] x &= \left\{-\dfrac{\pi}{4}, \dfrac{\pi}{4}, \dfrac{3\pi}{4}, \dfrac{5\pi}{4}, \dfrac{7\pi}{4}\right\} \end{aligned}\] Karena domain yang dibatasi adalah \(0 \le x \le \pi\), maka pembuat nol di dalam interval adalah: \[ x = \dfrac{\pi}{4} \quad \text{dan} \quad x = \dfrac{3\pi}{4} \] Uji tanda turunan pertama pada garis bilangan:
Berdasarkan uji tanda, interval fungsi naik (\(f'(x) > 0\)) adalah: \[ \dfrac{\pi}{4} < x < \dfrac{3\pi}{4} \]
Jadi, \(f(x)\) naik pada interval \(\dfrac{\pi}{4} < x < \dfrac{3\pi}{4}\).

Batasan nilai \(x\) agar fungsi \(f(x) = 4x - x^2\) merupakan fungsi turun adalah ....

  1. \(x < 2\)
  2. \(-2 < x < 2\)
  3. \(x > 2\)
  4. \(x < -2\)
  5. \(x > -2\)
Grup Telegram
Pembahasan:
Syarat fungsi \(f(x)\) turun adalah \(f'(x) < 0\): \[\begin{aligned} f'(x) &< 0 \\ 4 - 2x &< 0 \\ -2x &< -4 \\ x &> 2 \end{aligned}\]
Jadi, batasan nilai \(x\) agar fungsi \(f(x) = 4x - x^2\) merupakan fungsi turun adalah \(x > 2\).
JAWAB: C

Tentukan pada interval \((0, 2\pi)\) di mana fungsi \(f(x) = \cos(x + \pi)\) merupakan fungsi naik atau fungsi turun.

Grup Matematika Zone Indonesia
Pembahasan:
Turunan pertama dari \(f(x)\): \[ f'(x) = -\sin(x + \pi) \] Mencari pembuat nol (titik stasioner) dengan menyelesaikan \(f'(x) = 0\): \[\begin{aligned} -\sin(x + \pi) &= 0 \\ \sin(x + \pi) &= 0 \\ x + \pi &= \{0, \pi, 2\pi, 3\pi\} \\ x &= \{0 - \pi, \pi - \pi, 2\pi - \pi, 3\pi - \pi\} \\ x &= \{-\pi\ \text{(TM)}, 0, \pi, 2\pi\} \end{aligned}\] Uji tanda nilai \(f'(x)\) pada interval \((0, 2\pi)\):
  • Fungsi \(f(x)\) naik saat \(f'(x) > 0\), yaitu pada interval \(0 < x < \pi\).
  • Fungsi \(f(x)\) turun saat \(f'(x) < 0\), yaitu pada interval \(\pi < x < 2\pi\).
Jadi, \(f(x)\) naik pada interval \(0 < x < \pi\) dan turun pada interval \(\pi < x < 2\pi\).
