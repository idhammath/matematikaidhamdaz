Diberikan fungsi f memenuhi persamaan 3f(−x) + f(x − 3) = x + 1 untuk setiap bilangan real x. Nilai 4f(−3) adalah
  1. 10
  2. 11
  3. \dfrac{11}2
  1. 12
  2. \dfrac{13}2

ALTERNATIF PENYELESAIAN

Untuk x = 3,

\begin{aligned} 3f(-3) + f(3-3)& = 3 + 1\\ 3f(-3) + f(0)& = 4&\times3\\ 9f(-3)+3f(0)&=12 \end{aligned}

Untuk x = 0,

\begin{aligned} 3f(-0) + f(0-3)& = 0 + 1\\ 3f(0) + f(-3)& = 1\\ f(-3)+3f(0)&=1 \end{aligned}
\begin{aligned} 9f(-3)+3f(0)&=12\\ f(-3)+3f(0)&=1&-\\\hline 8f(-3)&=11&:2\\ 4f(-3)&=\boxed{\boxed{\dfrac{11}2}} \end{aligned}
Jadi, 4 f(-3)=\dfrac{11}2.
