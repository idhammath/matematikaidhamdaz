Pertama, buat tabel distribusi frekuensi lengkap dengan frekuensi kumulatif (\(F_k\)):

Interval Kelas Frekuensi (\(f\)) \(F_k\)

Total data \(n = 40\), dan panjang kelas \(p = 124 - 120 + 1 = 5\).

1. Menentukan Kuartil Bawah (\(Q_1\)):

Letak \(Q_1\) berada pada data ke-\(\dfrac{1}{4}n = \dfrac{1}{4}(40) = 10\).
Data ke-10 berada pada kelas interval ke-3 (130 − 134).

  • Tepi bawah (\(T_b\)) = \(130 - 0{,}5 = 129{,}5\)
  • Frekuensi kumulatif sebelum kelas \(Q_1\) (\(F_k\)) = \(7\)
  • Frekuensi kelas \(Q_1\) (\(f\)) = \(10\)
  • Panjang kelas (\(p\)) = \(5\)

\[ \begin{aligned} Q_1 &= T_b + \left(\frac{\frac{n}{4} - F_k}{f}\right) p \\[6pt] &= 129{,}5 + \left(\frac{10 - 7}{10}\right) 5 \\[6pt] &= 129{,}5 + \left(\frac{3}{10}\right) 5 \\[6pt] &= 129{,}5 + 1{,}5 = 131 \end{aligned} \]

2. Menentukan Kuartil Tengah / Median (\(Q_2\)):

Letak \(Q_2\) berada pada data ke-\(\dfrac{2}{4}n = \dfrac{1}{2}(40) = 20\).
Data ke-20 berada pada kelas interval ke-4 (135 − 139).

  • Tepi bawah (\(T_b\)) = \(135 - 0{,}5 = 134{,}5\)
  • Frekuensi kumulatif sebelum kelas \(Q_2\) (\(F_k\)) = \(17\)
  • Frekuensi kelas \(Q_2\) (\(f\)) = \(7\)
  • Panjang kelas (\(p\)) = \(5\)

\[ \begin{aligned} Q_2 &= T_b + \left(\frac{\frac{n}{2} - F_k}{f}\right) p \\[6pt] &= 134{,}5 + \left(\frac{20 - 17}{7}\right) 5 \\[6pt] &= 134{,}5 + \left(\frac{3}{7}\right) 5 \\[6pt] &= 134{,}5 + \frac{15}{7} \\[6pt] &\approx 134{,}5 + 2{,}14 = 136{,}64 \end{aligned} \]

3. Menentukan Kuartil Atas (\(Q_3\)):

Letak \(Q_3\) berada pada data ke-\(\dfrac{3}{4}n = \dfrac{3}{4}(40) = 30\).
Data ke-30 berada pada kelas interval ke-5 (140 − 144).

  • Tepi bawah (\(T_b\)) = \(140 - 0{,}5 = 139{,}5\)
  • Frekuensi kumulatif sebelum kelas \(Q_3\) (\(F_k\)) = \(24\)
  • Frekuensi kelas \(Q_3\) (\(f\)) = \(11\)
  • Panjang kelas (\(p\)) = \(5\)

\[ \begin{aligned} Q_3 &= T_b + \left(\frac{\frac{3n}{4} - F_k}{f}\right) p \\[6pt] &= 139{,}5 + \left(\frac{30 - 24}{11}\right) 5 \\[6pt] &= 139{,}5 + \left(\frac{6}{11}\right) 5 \\[6pt] &= 139{,}5 + \frac{30}{11} \\[6pt] &\approx 139{,}5 + 2{,}73 = 142{,}23 \end{aligned} \]

Jadi, diperoleh nilai kuartil sebagai berikut:
  • Kuartil bawah (\(Q_1\)) = \(131\)
  • Kuartil tengah (\(Q_2\)) = \(136{,}64\)
  • Kuartil atas (\(Q_3\)) = \(142{,}23\)

Pembahasan:

Lengkapilah tabel distribusi frekuensi dengan frekuensi kumulatif (\(F_k\)):

Nilai Frekuensi (\(f\)) \(F_k\)
50 − 5922
60 − 6979
70 − 791120
80 − 89424
90 − 99125

Total data \(n = 25\), dan panjang interval kelas \(p = 59 - 50 + 1 = 10\).

1. Menentukan Kuartil Bawah (\(Q_1\)):

Letak \(Q_1\) berada pada data ke-\(\dfrac{1}{4}n = \dfrac{1}{4}(25) = 6{,}25\).
Data ke-6,25 terletak pada kelas ke-2 (60 − 69).

  • \(T_b = 60 - 0{,}5 = 59{,}5\)
  • \(F_k = 2\)
  • \(f = 7\)
  • \(p = 10\)

\[ \begin{aligned} Q_1 &= T_b + \left(\frac{\frac{n}{4} - F_k}{f}\right) p \\[6pt] &= 59{,}5 + \left(\frac{6{,}25 - 2}{7}\right) 10 \\[6pt] &= 59{,}5 + \left(\frac{4{,}25}{7}\right) 10 \\[6pt] &= 59{,}5 + \frac{42{,}5}{7} \\[6pt] &\approx 59{,}5 + 6{,}07 = 65{,}57 \end{aligned} \]

2. Menentukan Kuartil Atas (\(Q_3\)):

Letak \(Q_3\) berada pada data ke-\(\dfrac{3}{4}n = \dfrac{3}{4}(25) = 18{,}75\).
Data ke-18,75 terletak pada kelas ke-3 (70 − 79).

  • \(T_b = 70 - 0{,}5 = 69{,}5\)
  • \(F_k = 9\)
  • \(f = 11\)
  • \(p = 10\)

\[ \begin{aligned} Q_3 &= T_b + \left(\frac{\frac{3n}{4} - F_k}{f}\right) p \\[6pt] &= 69{,}5 + \left(\frac{18{,}75 - 9}{11}\right) 10 \\[6pt] &= 69{,}5 + \left(\frac{9{,}75}{11}\right) 10 \\[6pt] &= 69{,}5 + \frac{97{,}5}{11} \\[6pt] &\approx 69{,}5 + 8{,}86 = 78{,}36 \end{aligned} \]

3. Menentukan Simpangan Kuartil (\(Q_d\)):

Rumus simpangan kuartil: \[ \begin{aligned} Q_d &= \frac{1}{2}(Q_3 - Q_1) \\[6pt] &= \frac{1}{2}(78{,}36 - 65{,}57) \\[6pt] &= \frac{1}{2}(12{,}79) \\[6pt] &= 6{,}395 \end{aligned} \]

Jadi, simpangan kuartil (\(Q_d\)) dari data tersebut adalah \(6{,}395\).
