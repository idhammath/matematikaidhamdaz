Berikut adalah soal tingkat ... materi Bilangan Real

Himpunan semua bilangan real \(x\) yang memenuhi pertidaksamaan: \[\sqrt{x + 3} > x + 1\] adalah ....
  1. \(-3 \le x < 1\)
  2. \(-1 \le x < 1\)
  3. \(-2 < x < 1\)
  4. \(-3 \le x \le 1\)
  5. \(x < 1\)
SNBT / UTBK
Pembahasan:
Diberikan pertidaksamaan irasional: \[\sqrt{x + 3} > x + 1\] 1. Syarat Bilangan Real di Bawah Akar (Domain Definisi)

Nilai di dalam tanda akar harus bernilai non-negatif: \[x + 3 \ge 0 \implies x \ge -3 \quad \text{--- (Syarat 1)}\]

2. Analisis Kasus Berdasarkan Tanda Ruas Kanan (\(x + 1\))

Kasus A: Ruas kanan bernilai negatif (\(x + 1 < 0 \iff x < -1\))
Irisan dengan Syarat 1 adalah interval \([-3, -1)\).
Pada interval ini:

  • Ruas kiri \(\sqrt{x + 3} \ge 0\) (selalu bernilai non-negatif).
  • Ruas kanan \(x + 1 < 0\) (bernilai negatif).
Karena bilangan non-negatif selalu lebih besar daripada bilangan negatif, maka pertidaksamaan selalu bernilai benar untuk seluruh \(x \in [-3, -1)\).
Diperoleh himpunan penyelesaian bagian pertama: \[HP_A = [-3, -1) \iff -3 \le x < -1\]

Kasus B: Ruas kanan bernilai non-negatif (\(x + 1 \ge 0 \iff x \ge -1\))
Karena kedua ruas bernilai non-negatif, kita dapat mengkuadratkan kedua ruas tanpa membalik tanda pertidaksamaan: \[\begin{aligned} (\sqrt{x + 3})^2 &> (x + 1)^2 \\ x + 3 &> x^2 + 2x + 1 \\ 0 &> x^2 + 2x - x + 1 - 3 \\ x^2 + x - 2 &< 0 \\ (x + 2)(x - 1) &< 0 \end{aligned}\] Pembuat nol adalah \(x = -2\) dan \(x = 1\). Karena tanda pertidaksamaan \(<\), maka penyelesaiannya adalah: \[-2 < x < 1\] Iriskan dengan syarat kasus B (\(x \ge -1\)): \[HP_B = [-1, 1) \iff -1 \le x < 1\]

3. Menggabungkan Kedua Kasus (Himpunan Penyelesaian Total)

Gabungkan solusi dari Kasus A dan Kasus B: \[\begin{aligned} HP &= HP_A \cup HP_B \\ &= [-3, -1) \cup [-1, 1) \\ &= [-3, 1) \end{aligned}\] Dalam bentuk notasi pertidaksamaan: \[-3 \le x < 1\]

Jadi, himpunan semua bilangan real yang memenuhi adalah \(-3 \le x < 1\).
