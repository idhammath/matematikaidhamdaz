Berikut adalah soal tingkat ... materi Refleksi (Pencerminan)

Hasil pencerminan titik \(A(1, -2)\) terhadap garis \(ax + by + 2 = 0\) adalah \(A'(3, 4)\). Nilai \(a + b\) adalah ....
  1. \(-\dfrac{6}{5}\)
  2. \(\dfrac{2}{5}\)
  3. \(-\dfrac{2}{5}\)
  4. \(\dfrac{8}{5}\)
  5. \(-\dfrac{8}{5}\)
SKMP September 2020
Pembahasan:
Garis cermin \(ax + by + 2 = 0\) merupakan garis sumbu simetri (tegak lurus dan membagi dua sama panjang) ruas garis \(AA'\).

1. Titik tengah ruas garis \(AA'\): \[B = \left(\dfrac{1 + 3}{2}, \dfrac{-2 + 4}{2}\right) = (2, 1)\] Karena titik tengah \(B(2, 1)\) dilalui oleh garis cermin \(ax + by + 2 = 0\): \[\begin{aligned} a(2) + b(1) + 2 &= 0\\ 2a + b &= -2 \quad \dots(1) \end{aligned}\] 2. Gradien dan syarat tegak lurus: Gradien garis \(AA'\): \[m_{AA'} = \dfrac{y_{A'} - y_A}{x_{A'} - x_A} = \dfrac{4 - (-2)}{3 - 1} = \dfrac{6}{2} = 3\] Gradien garis cermin \(ax + by + 2 = 0\) adalah \(m = -\dfrac{a}{b}\).
Karena garis cermin tegak lurus terhadap \(AA'\): \[\begin{aligned} m \cdot m_{AA'} &= -1\\ -\dfrac{a}{b} \cdot 3 &= -1\\ \dfrac{3a}{b} &= 1 \implies b = 3a \quad \dots(2) \end{aligned}\] Substitusikan persamaan (2) ke persamaan (1): \[\begin{aligned} 2a + 3a &= -2\\ 5a &= -2 \implies a = -\dfrac{2}{5} \end{aligned}\] Maka nilai \(a + b\): \[\begin{aligned} a + b &= a + 3a = 4a\\ &= 4\left(-\dfrac{2}{5}\right)\\ &= -\dfrac{8}{5} \end{aligned}\]
Jadi, \(a + b = -\dfrac{8}{5}\).
