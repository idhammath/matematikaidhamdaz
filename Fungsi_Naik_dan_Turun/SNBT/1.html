Berikut adalah soal tingkat ... materi Fungsi Naik dan Turun

Diketahui fungsi kubik \(f(x) = 2x^3 - 9x^2 - 24x + 15\). Jika fungsi \(f(x)\) turun pada interval \(a < x < b\), maka nilai dari \(2a + b\) adalah ....

  1. \(-3\)
  2. \(-1\)
  3. \(2\)
  4. \(5\)
  5. \(7\)
SNBT / UTBK
Pembahasan:

Langkah 1: Menentukan turunan pertama fungsi \(f(x)\)

Diberikan fungsi:

\[ f(x) = 2x^3 - 9x^2 - 24x + 15 \]

Turunan pertamanya adalah:

\[ f'(x) = 6x^2 - 18x - 24 \]

Langkah 2: Menerapkan syarat fungsi turun

Suatu fungsi \(f(x)\) dikatakan turun pada suatu interval jika turunan pertamanya bernilai negatif (\(f'(x) < 0\)):

\[ 6x^2 - 18x - 24 < 0 \]

Bagi kedua ruas dengan \(6\):

\[ x^2 - 3x - 4 < 0 \]

Langkah 3: Menentukan pembuat nol dan interval pertidaksamaan

Faktorkan persamaan kuadrat pembuat nol:

\[ (x - 4)(x + 1) = 0 \implies x = -1 \quad \text{atau} \quad x = 4 \]

Uji tanda pada garis bilangan:

  • Untuk \(x < -1\) (misal \(x = -2\)): \((-2 - 4)(-2 + 1) = (-6)(-1) = +6 > 0\) (Positif)
  • Untuk \(-1 < x < 4\) (misal \(x = 0\)): \((0 - 4)(0 + 1) = -4 < 0\) (Negatif)
  • Untuk \(x > 4\) (misal \(x = 5\)): \((5 - 4)(5 + 1) = (1)(6) = +6 > 0\) (Positif)

Karena disyaratkan \(f'(x) < 0\) (tanda negatif), maka interval fungsi turun adalah:

\[ -1 < x < 4 \]

Langkah 4: Menghitung nilai \(2a + b\)

Berdasarkan bentuk interval \(a < x < b\), diperoleh batas-batas:

\[ a = -1 \quad \text{dan} \quad b = 4 \]

Sehingga nilai yang dicari adalah:

\[ 2a + b = 2(-1) + 4 = -2 + 4 = 2 \]
Jadi, nilai dari \(2a + b\) adalah 2.
