Tentukan persamaan garis singgung lingkaran \(x^2 + y^2 - 4x - 6y - 27 = 0\) pada titik \((8, 5)\).

brainly.co.id
Pembahasan:
Persamaan garis singgung lingkaran \(x^2 + y^2 + Ax + By + C = 0\) pada titik \((x_1, y_1)\) yang terletak pada lingkaran dirumuskan oleh persamaan bagi adil: \[ x_1 x + y_1 y + \dfrac{A}{2}(x + x_1) + \dfrac{B}{2}(y + y_1) + C = 0 \] Dari persamaan lingkaran \(x^2 + y^2 - 4x - 6y - 27 = 0\), diketahui: \[ A = -4, \quad B = -6, \quad C = -27 \] Substitusikan titik \((x_1, y_1) = (8, 5)\): \[\begin{aligned} x_1 x + y_1 y - \dfrac{4}{2}(x + x_1) - \dfrac{6}{2}(y + y_1) - 27 &= 0 \\ 8x + 5y - 2(x + 8) - 3(y + 5) - 27 &= 0 \\ 8x + 5y - 2x - 16 - 3y - 15 - 27 &= 0 \\ 6x + 2y - 58 &= 0 \quad (\text{kedua ruas dibagi } 2) \\ 3x + y - 29 &= 0 \end{aligned}\]
Jadi, persamaan garis singgung lingkaran \(x^2 + y^2 - 4x - 6y - 27 = 0\) pada titik \((8, 5)\) adalah \(3x + y - 29 = 0\).

Tentukan persamaan garis singgung lingkaran \(x^2 + y^2 + 6x - 8y - 4 = 0\) pada titik \((2, 2)\).

Grup Telegram
Pembahasan:
Periksa kedudukan titik \((2, 2)\) terhadap lingkaran: \[ 2^2 + 2^2 + 6(2) - 8(2) - 4 = 4 + 4 + 12 - 16 - 4 = 0 \] Karena bernilai \(0\), maka titik \((2, 2)\) terletak pada lingkaran.

Persamaan garis singgung pada titik \((x_1, y_1) = (2, 2)\): \[\begin{aligned} x_1 x + y_1 y + \dfrac{6}{2}(x + x_1) - \dfrac{8}{2}(y + y_1) - 4 &= 0 \\ 2x + 2y + 3(x + 2) - 4(y + 2) - 4 &= 0 \\ 2x + 2y + 3x + 6 - 4y - 8 - 4 &= 0 \\ 5x - 2y - 6 &= 0 \end{aligned}\]
Jadi, persamaan garis singgung lingkaran \(x^2 + y^2 + 6x - 8y - 4 = 0\) pada titik \((2, 2)\) adalah \(5x - 2y - 6 = 0\).
