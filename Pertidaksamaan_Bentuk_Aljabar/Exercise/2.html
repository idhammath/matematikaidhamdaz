Himpunan penyelesaian dari pertidaksamaan rasional \(\dfrac{2x}{(x-1)^2}\geq\dfrac4x\) adalah ....
Grup Telegram
Pembahasan:
\(\begin{aligned} \dfrac{2x}{(x-1)^2}&\geq\dfrac4x\\[4pt] \dfrac{2x}{(x-1)^2}-\dfrac4x&\geq0\\[4pt] \dfrac{2x(x)-4(x-1)^2}{x(x-1)^2}&\geq0\\[4pt] \dfrac{2x^2-4\left(x^2-2x+1\right)}{x(x-1)^2}&\geq0\\[4pt] \dfrac{2x^2-4x^2+8x-4}{x(x-1)^2}&\geq0\\[4pt] \dfrac{-2x^2+8x-4}{x(x-1)^2}&\geq0 \qquad\color{red}{:(-2)}\\[4pt] \dfrac{x^2-4x+2}{x(x-1)^2}&\leq0 \end{aligned}\)

Pembuat nol:
  • \(x^2 - 4x + 2 = 0 \iff (x - 2)^2 = 2 \iff x = 2 \pm \sqrt{2}\)
  • \(x = 0\) (syarat penyebut \(x \neq 0\))
  • \((x - 1)^2 = 0 \iff x = 1\) (syarat penyebut \(x \neq 1\))

Dari garis bilangan diperoleh daerah penyelesaian:
Jadi, \(x \lt 0\), \(2-\sqrt2\leq x\lt1\), atau \(1\lt x\leq2+\sqrt2\).
\(\dfrac3{x^2-3x+2}\lt\dfrac5{x^2-4x+3}\), benar untuk ....
  1. \(x\gt\dfrac12\)
  2. \(x \gt 2\)
  3. \(x \gt 3\)
  1. \(\dfrac12\lt x\lt3\)
  2. \(2 \lt x \lt 3\)

Pembahasan:
\(\begin{aligned} \dfrac3{x^2-3x+2}&\lt\dfrac5{x^2-4x+3}\\[4pt] \dfrac3{x^2-3x+2}-\dfrac5{x^2-4x+3}&\lt0\\[4pt] \dfrac3{(x-1)(x-2)}-\dfrac5{(x-1)(x-3)}&\lt0\\[4pt] \dfrac{3(x-3)-5(x-2)}{(x-1)(x-2)(x-3)}&\lt0\\[4pt] \dfrac{3x-9-5x+10}{(x-1)(x-2)(x-3)}&\lt0\\[4pt] \dfrac{-2x+1}{(x-1)(x-2)(x-3)}&\lt0\\[4pt] \dfrac{2x-1}{(x-1)(x-2)(x-3)}&\gt0 \end{aligned}\)

Pembuat nol:
  • \(2x - 1 = 0 \iff x = \dfrac12\)
  • \(x - 1 = 0 \iff x = 1\)
  • \(x - 2 = 0 \iff x = 2\)
  • \(x - 3 = 0 \iff x = 3\)

Himpunan penyelesaian lengkapnya adalah \(x\lt\dfrac12\), \(1 \lt x \lt 2\), atau \(x \gt 3\). Dari pilihan jawaban yang tersedia, nilai yang selalu benar berada di dalam interval penyelesaian adalah \(x \gt 3\).
Jadi, \(\dfrac3{x^2-3x+2}\lt\dfrac5{x^2-4x+3}\), benar untuk \(x \gt 3\).
