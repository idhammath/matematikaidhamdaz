Perhatikan grafik fungsi trigonometri berikut ini:

Persamaan fungsi trigonometri yang sesuai dengan grafik di atas adalah ....

  1. \(y = 2\sin\left(3x - \dfrac{\pi}{2}\right) + 1\)
  2. \(y = 2\sin\left(3x + \dfrac{\pi}{2}\right) + 1\)
  3. \(y = 2\sin\left(2x - \dfrac{\pi}{3}\right) + 1\)
  4. \(y = 3\sin\left(2x - \dfrac{\pi}{6}\right) - 1\)
  5. \(y = 3\sin\left(3x - \dfrac{\pi}{2}\right) + 1\)
SNBT / UTBK
Pembahasan:

Bentuk umum fungsi sinus dengan pergeseran fase dan vertikal adalah:

\[ y = a\sin(k(x - \alpha)) + c \]

Langkah 1: Menentukan amplitudo (\(a\)) dan pergeseran vertikal (\(c\))

Dari grafik, terlihat bahwa:

  • Nilai maksimum: \(y_{\text{maks}} = 3\) (dicapai di \(x = \dfrac{\pi}{3}\) dan \(x = \pi\))
  • Nilai minimum: \(y_{\text{min}} = -1\) (dicapai di \(x = 0\) dan \(x = \dfrac{2\pi}{3}\))

Nilai amplitudo gelombang:

\[ a = \frac{y_{\text{maks}} - y_{\text{min}}}{2} = \frac{3 - (-1)}{2} = \frac{4}{2} = 2 \]

Garis tengah / pergeseran vertikal grafik:

\[ c = \frac{y_{\text{maks}} + y_{\text{min}}}{2} = \frac{3 + (-1)}{2} = \frac{2}{2} = 1 \]

Langkah 2: Menentukan periode gelombang (\(T\)) dan nilai \(k\)

Jarak horizontal antara dua puncak gelombang yang berdekatan (\(x = \dfrac{\pi}{3}\) dan \(x = \pi\)) adalah satu periode gelombang penuh (\(T\)):

\[ T = \pi - \frac{\pi}{3} = \frac{2\pi}{3} \]

Nilai frekuensi sudut \(k\):

\[ k = \frac{2\pi}{T} = \frac{2\pi}{\frac{2\pi}{3}} = 3 \]

Langkah 3: Menentukan pergeseran fasa horizontal (\(\alpha\))

Kurva dasar sinus standar \(y = \sin(kx)\) berawal dari garis tengah (\(y = c = 1\)) dan bergerak naik. Dari grafik, kurva memotong garis tengah \(y = 1\) dan mulai bergerak naik di absis \(x = \dfrac{\pi}{6}\). Oleh karena itu, grafik bergeser ke kanan sejauh \(\alpha = \dfrac{\pi}{6}\):

\[ \begin{aligned} y &= a\sin(k(x - \alpha)) + c \\ &= 2\sin\left(3\left(x - \frac{\pi}{6}\right)\right) + 1 \\ &= 2\sin\left(3x - \frac{3\pi}{6}\right) + 1 \\ &= 2\sin\left(3x - \frac{\pi}{2}\right) + 1 \end{aligned} \]
Jadi, persamaan grafik fungsi trigonometri tersebut adalah \(y = 2\sin\left(3x - \dfrac{\pi}{2}\right) + 1\).
