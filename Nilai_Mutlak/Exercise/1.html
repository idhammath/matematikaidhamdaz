Gunakan definisi nilai mutlak untuk menentukan nilai mutlak berikut.
Tentukan |x + 2| untuk x bilangan real.
SUMBER
ALTERNATIF PENYELESAIAN
\(\begin{aligned} x+2&\geq0\\ x&\geq-2 \end{aligned}\)

\(|x+2|=\begin{cases}x+2,\text{ untuk }x\geq-2\\-(x+2),\text{ untuk }x\lt-2\end{cases}\)
Jadi, \(|x+2|=\begin{cases}x+2,\text{ untuk }x\geq-2\\-(x+2),\text{ untuk }x\lt-2\end{cases}\).

Gunakan definisi nilai mutlak untuk menentukan nilai mutlak berikut.
Tentukan |6 − x| untuk x bilangan real.
SUMBER
ALTERNATIF PENYELESAIAN
\(\begin{aligned} 6-x&\geq0\\ 6&\geq x\\ x&\leq6 \end{aligned}\)

\(|6-x|=\begin{cases}6-x,\text{ untuk }x\leq6\\-(6-x),\text{ untuk }x\gt6\end{cases}\)
Jadi, \(|6-x|=\begin{cases}6-x,\text{ untuk }x\leq6\\-(6-x),\text{ untuk }x\gt6\end{cases}\).
