Berikut adalah soal tingkat ... materi Hubungan Garis dan Lingkaran

Diketahui garis \(g: 3x - 4y + c = 0\) dan lingkaran \(L: x^2 + y^2 - 6x - 2y + 1 = 0\). Agar garis \(g\) memotong lingkaran \(L\) di dua titik yang berbeda, maka batas-batas nilai \(c\) yang memenuhi adalah ....

  1. \(-20 < c < 10\)
  2. \(-10 < c < 20\)
  3. \(c < -20 \text{ atau } c > 10\)
  4. \(-15 < c < 15\)
  5. \(-25 < c < 5\)
SNBT / UTBK
Pembahasan:

Langkah 1: Menentukan Pusat dan Jari-jari Lingkaran

Persamaan umum lingkaran: \[x^2 + y^2 - 6x - 2y + 1 = 0\] Ubah ke bentuk kuadrat sempurna: \[(x - 3)^2 - 9 + (y - 1)^2 - 1 + 1 = 0\] \[(x - 3)^2 + (y - 1)^2 = 9\] Dari bentuk baku \((x - a)^2 + (y - b)^2 = r^2\), diperoleh:

  • Pusat lingkaran: \(P(a, b) = (3, 1)\)
  • Jari-jari lingkaran: \(r = \sqrt{9} = 3\)

Langkah 2: Menentukan Syarat Garis Memotong Lingkaran di Dua Titik Berbeda

Ada dua metode yang dapat digunakan:

Metode 1: Menggunakan Jarak Titik Pusat ke Garis (\(d < r\))

Suatu garis \(Ax + By + C = 0\) memotong lingkaran yang berjari-jari \(r\) di dua titik berlainan jika dan hanya jika jarak tegak lurus dari titik pusat lingkaran ke garis tersebut (\(d\)) lebih kecil daripada jari-jarinya (\(d < r\)).

Rumus jarak titik \((x_1, y_1)\) ke garis \(Ax + By + C = 0\) adalah: \[d = \frac{|Ax_1 + By_1 + C|}{\sqrt{A^2 + B^2}}\] Substitusikan titik pusat \(P(3, 1)\) dan persamaan garis \(3x - 4y + c = 0\) (\(A = 3\), \(B = -4\), \(C = c\)): \[d = \frac{|3(3) - 4(1) + c|}{\sqrt{3^2 + (-4)^2}} = \frac{|9 - 4 + c|}{\sqrt{9 + 16}} = \frac{|c + 5|}{\sqrt{25}} = \frac{|c + 5|}{5}\] Syarat memotong di dua titik berbeda (\(d < r\)): \[\frac{|c + 5|}{5} < 3\] \[|c + 5| < 15\] Sesuai sifat pertidaksamaan nilai mutlak \(|x| < k \iff -k < x < k\): \[-15 < c + 5 < 15\] Kurangkan \(5\) pada ketiga ruas: \[-15 - 5 < c < 15 - 5\] \[-20 < c < 10\]

Metode 2: Menggunakan Diskriminan (\(D > 0\))

Dari persamaan garis \(3x - 4y + c = 0\), nyatakan \(y\) dalam \(x\): \[4y = 3x + c \implies y = \frac{3x + c}{4}\] Substitusi ke bentuk \((x - 3)^2 + (y - 1)^2 = 9\): \[(x - 3)^2 + \left(\frac{3x + c}{4} - 1\right)^2 = 9\] \[(x - 3)^2 + \left(\frac{3x + c - 4}{4}\right)^2 = 9\] Kalikan kedua ruas dengan \(16\): \[16(x^2 - 6x + 9) + (3x + (c - 4))^2 = 144\] \[16x^2 - 96x + 144 + 9x^2 + 6(c - 4)x + (c - 4)^2 = 144\] \[25x^2 + (6c - 120)x + (c - 4)^2 = 0\] Syarat memotong di dua titik berlainan adalah diskriminan persamaan kuadrat positif (\(D > 0\)): \[D = b^2 - 4ac > 0\] \[(6c - 120)^2 - 4(25)(c - 4)^2 > 0\] \[36(c - 20)^2 - 100(c - 4)^2 > 0\] Bagi kedua ruas dengan \(4\): \[9(c - 20)^2 - 25(c - 4)^2 > 0\] Gunakan bentuk selisih kuadrat \(u^2 - v^2 = (u - v)(u + v)\) dengan \(u = 3(c - 20) = 3c - 60\) dan \(v = 5(c - 4) = 5c - 20\): \[[(3c - 60) - (5c - 20)][(3c - 60) + (5c - 20)] > 0\] \[(-2c - 40)(8c - 80) > 0\] Bagi ruas kiri dengan \(-2\) (membalik tanda ketaksamaan): \[(c + 20)(8c - 80) < 0\] Bagi lagi dengan \(8\): \[(c + 20)(c - 10) < 0\] Pembuat nol adalah \(c = -20\) dan \(c = 10\). Karena tanda ketaksamaan \(< 0\), daerah penyelesaiannya adalah: \[-20 < c < 10\]

Jadi, batas-batas nilai \(c\) yang memenuhi adalah \(-20 < c < 10\) (Pilihan A).
