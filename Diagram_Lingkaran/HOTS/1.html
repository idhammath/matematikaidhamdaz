Berikut adalah soal tingkat ... materi Diagram Lingkaran

Diagram lingkaran berikut menunjukkan distribusi pengeluaran energi sebuah rumah tangga pada Tahun 2023 yang terbagi dalam empat kategori: Listrik, Gas, Bahan Bakar Minyak (BBM), dan Sumber Lainnya.

Pada Tahun 2023:

  • Juring untuk pengeluaran Listrik membentuk sudut siku-siku (\(90^\circ\)).
  • Persentase pengeluaran untuk Gas adalah \(30\%\).
  • Perbandingan pengeluaran untuk BBM terhadap Sumber Lainnya adalah \(5 : 4\).
  • Pengeluaran untuk kategori Sumber Lainnya adalah sebesar \(\text{Rp } 360.000{,}00\) per bulan.

Pada Tahun 2024, terjadi perubahan pengeluaran rumah tangga sebagai berikut:

  • Total seluruh anggaran energi rumah tangga meningkat sebesar \(20\%\).
  • Pengeluaran untuk Listrik naik sebesar \(40\%\).
  • Pengeluaran untuk Gas naik sebesar \(25\%\).
  • Pengeluaran untuk BBM tidak mengalami perubahan (tetap).

Besar sudut pusat juring untuk kategori BBM pada diagram lingkaran konsumsi energi Tahun 2024 adalah ....

  1. \(60^\circ\)
  2. \(67{,}5^\circ\)
  3. \(72^\circ\)
  4. \(75^\circ\)
  5. \(80^\circ\)

Pembahasan:

Langkah 1: Menentukan persentase tiap kategori pada Tahun 2023

  • Persentase Listrik: \[\% \text{Listrik} = \frac{90^\circ}{360^\circ} \times 100\% = 25\%\]
  • Persentase Gas: \(\% \text{Gas} = 30\%\)
  • Jumlah persentase Listrik dan Gas: \[25\% + 30\% = 55\%\]
  • Sisa persentase untuk BBM dan Sumber Lainnya: \[100\% - 55\% = 45\%\]
  • Diketahui rasio \(\text{BBM} : \text{Sumber Lainnya} = 5 : 4\). Dengan demikian: \[\% \text{BBM} = \frac{5}{5 + 4} \times 45\% = \frac{5}{9} \times 45\% = 25\%\] \[\% \text{Sumber Lainnya} = \frac{4}{5 + 4} \times 45\% = \frac{4}{9} \times 45\% = 20\%\]

Langkah 2: Menghitung nilai nominal pengeluaran pada Tahun 2023

Diketahui pengeluaran untuk Sumber Lainnya (\(20\%\)) adalah \(\text{Rp } 360.000{,}00\). Maka total seluruh anggaran energi tahun 2023 (\(T_{2023}\)) adalah:

\[ T_{2023} = \frac{\text{Rp } 360.000}{0{,}20} = \text{Rp } 1.800.000{,}00 \] Besar pengeluaran masing-masing pos pada Tahun 2023:
  • \(\text{Listrik}_{2023} = 25\% \times 1.800.000 = \text{Rp } 450.000{,}00\)
  • \(\text{Gas}_{2023} = 30\% \times 1.800.000 = \text{Rp } 540.000{,}00\)
  • \(\text{BBM}_{2023} = 25\% \times 1.800.000 = \text{Rp } 450.000{,}00\)
  • \(\text{Sumber Lainnya}_{2023} = \text{Rp } 360.000{,}00\)

Langkah 3: Menghitung kondisi pengeluaran pada Tahun 2024

  • Total anggaran energi tahun 2024 naik sebesar \(20\%\): \[T_{2024} = (1 + 0{,}20) \times 1.800.000 = 1{,}20 \times 1.800.000 = \text{Rp } 2.160.000{,}00\]
  • Pengeluaran Listrik 2024 naik sebesar \(40\%\): \[\text{Listrik}_{2024} = 1{,}40 \times 450.000 = \text{Rp } 630.000{,}00\]
  • Pengeluaran Gas 2024 naik sebesar \(25\%\): \[\text{Gas}_{2024} = 1{,}25 \times 540.000 = \text{Rp } 675.000{,}00\]
  • Pengeluaran BBM 2024 tetap: \[\text{BBM}_{2024} = \text{Rp } 450.000{,}00\]

Langkah 4: Menghitung besar sudut pusat juring BBM pada Tahun 2024

Besar sudut juring untuk kategori BBM dihitung dengan membandingkan nilai BBM terhadap total anggaran baru (\(T_{2024}\)):

\[ \begin{aligned} \theta_{\text{BBM}, 2024} &= \frac{\text{BBM}_{2024}}{T_{2024}} \times 360^\circ \\[8pt] &= \frac{450.000}{2.160.000} \times 360^\circ \\[8pt] &= \frac{45}{216} \times 360^\circ \\[8pt] &= \frac{5}{24} \times 360^\circ \\[8pt] &= 5 \times 15^\circ = 75^\circ \end{aligned} \]
