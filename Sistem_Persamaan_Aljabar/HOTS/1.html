Diketahui \(x, y, z,\) dan \(t\) adalah bilangan real tidak nol dan memenuhi persamaan: \[\begin{aligned} x + y + z &= t \\ \dfrac{1}{x} + \dfrac{1}{y} + \dfrac{1}{z} &= \dfrac{1}{t} \\ x^3 + y^3 + z^3 &= 1000^3 \end{aligned}\] Nilai dari \(x + y + z + t\) adalah ....
Matematika Zone Id
Pembahasan:
Dari persamaan kedua: \[\begin{aligned} \dfrac{1}{x} + \dfrac{1}{y} + \dfrac{1}{z} &= \dfrac{1}{t} \\ \dfrac{xy + yz + zx}{xyz} &= \dfrac{1}{t} \\ xy + yz + zx &= \dfrac{xyz}{t} \end{aligned}\] Gunakan identitas aljabar untuk jumlah pangkat tiga: \[\begin{aligned} x^3 + y^3 + z^3 &= (x + y + z)^3 - 3(x + y + z)(xy + yz + zx) + 3xyz \\ 1000^3 &= t^3 - 3t\left(\dfrac{xyz}{t}\right) + 3xyz \\ 1000^3 &= t^3 - 3xyz + 3xyz \\ 1000^3 &= t^3 \implies t = 1000 \end{aligned}\] Maka nilai yang dicari: \[\begin{aligned} x + y + z + t &= t + t \\ &= 2t \\ &= 2(1000) = 2000 \end{aligned}\]
Jadi, nilai dari \(x + y + z + t\) adalah 2000.
Diketahui \((x, y)\) memenuhi dua persamaan: \[\begin{aligned} x^3 - 3x^2 + 5x + 2016 &= 2017 \\ y^3 - 3y^2 + 5y + 2017 &= 2022 \end{aligned}\] Carilah nilai dari \(^{\frac{1}{16}}\log(x + y)\).
Matematika Zone Indonesia
Pembahasan:
Ubah persamaan pertama ke dalam bentuk \((x - 1)\): \[\begin{aligned} x^3 - 3x^2 + 5x + 2016 &= 2017 \\ (x - 1)^3 + 2(x - 1) + 2 &= 0 \end{aligned}\] Misalkan \(p = x - 1\), maka \(p^3 + 2p + 2 = 0\).

Ubah persamaan kedua ke dalam bentuk \((y - 1)\): \[\begin{aligned} y^3 - 3y^2 + 5y + 2017 &= 2022 \\ (y - 1)^3 + 2(y - 1) - 2 &= 0 \end{aligned}\] Misalkan \(q = y - 1\), maka \(q^3 + 2q - 2 = 0\).

Jumlahkan kedua persamaan: \[\begin{aligned} (p^3 + 2p + 2) + (q^3 + 2q - 2) &= 0 \\ p^3 + q^3 + 2(p + q) &= 0 \\ (p + q)(p^2 - pq + q^2) + 2(p + q) &= 0 \\ (p + q)\left(p^2 - pq + q^2 + 2\right) &= 0 \end{aligned}\] Karena \(p^2 - pq + q^2 + 2 = \left(p - \dfrac{q}{2}\right)^2 + \dfrac{3}{4}q^2 + 2 > 0\), maka haruslah: \[\begin{aligned} p + q &= 0 \\ (x - 1) + (y - 1) &= 0 \\ x + y &= 2 \end{aligned}\] Nilai logaritma yang dicari: \[^{\frac{1}{16}}\log(x + y) = ^{2^{-4}}\log 2 = -\dfrac{1}{4}\]
Jadi, \(^{\frac{1}{16}}\log(x + y) = -\dfrac{1}{4}\).

Pembahasan:
Dari persamaan ketiga: \[p^2 + q^2 = r^2 - 13\] Kuadratkan persamaan pertama: \[\begin{aligned} (p + q + r)^2 &= 9^2 \\ p^2 + q^2 + r^2 + 2(pq + qr + pr) &= 81 \\ (r^2 - 13) + r^2 + 2(pq + qr + pr) &= 81 \\ 2r^2 + 2(pq + qr + pr) &= 94 \\ pq + qr + pr &= 47 - r^2 \end{aligned}\] Berdasarkan rumus Vieta, \(p, q,\) dan \(r\) adalah akar-akar dari polinomial: \[x^3 - (p+q+r)x^2 + (pq+qr+pr)x - pqr = 0\] \[x^3 - 9x^2 + (47 - r^2)x - 10 = 0\] Karena \(r\) adalah salah satu akar, substitusikan \(x = r\): \[\begin{aligned} r^3 - 9r^2 + (47 - r^2)r - 10 &= 0 \\ r^3 - 9r^2 + 47r - r^3 - 10 &= 0 \\ -9r^2 + 47r - 10 &= 0 \\ 9r^2 - 47r + 10 &= 0 \\ (9r - 2)(r - 5) &= 0 \end{aligned}\] Diperoleh \(r = \dfrac{2}{9}\) atau \(r = 5\). Karena yang diminta adalah nilai bulat, maka \(r = 5\).
Jadi, nilai \(r\) bulat yang memenuhi adalah 5.
Diketahui \(a, b,\) dan \(c\) adalah tiga bilangan real yang memenuhi persamaan: \[\begin{aligned} a^2 - bc &= 7 \\ b^2 + ac &= 7 \\ c^2 + ab &= 7 \end{aligned}\] maka \(a^2 + b^2 + c^2 = \dots\)

Pembahasan:
Kurangkan persamaan pertama dengan persamaan kedua: \[\begin{aligned} (a^2 - bc) - (b^2 + ac) &= 7 - 7 \\ a^2 - b^2 - ac - bc &= 0 \\ (a + b)(a - b) - c(a + b) &= 0 \\ (a + b)(a - b - c) &= 0 \end{aligned}\] Untuk \(a - b - c = 0 \implies a = b + c\).

Jumlahkan ketiga persamaan: \[\begin{aligned} (a^2 - bc) + (b^2 + ac) + (c^2 + ab) &= 7 + 7 + 7 \\ a^2 + b^2 + c^2 + a(b + c) - bc &= 21 \end{aligned}\] Substitusikan \(b + c = a\): \[\begin{aligned} a^2 + b^2 + c^2 + a(a) - bc &= 21 \\ a^2 + b^2 + c^2 + (a^2 - bc) &= 21 \end{aligned}\] Karena \(a^2 - bc = 7\): \[\begin{aligned} a^2 + b^2 + c^2 + 7 &= 21 \\ a^2 + b^2 + c^2 &= 14 \end{aligned}\]
Jadi, \(a^2 + b^2 + c^2 = 14\).

Pembahasan:
Kurangkan persamaan pertama dengan persamaan kedua: \[\begin{aligned} a(b + c - 5) - b(a + c - 5) &= 0 \\ ab + ac - 5a - (ab + bc - 5b) &= 0 \\ (a - b)c - 5(a - b) &= 0 \\ (a - b)(c - 5) &= 0 \end{aligned}\] Kasus 1: \(a = b\)
Dari persamaan ketiga: \[a^2 + a^2 = 50 \implies 2a^2 = 50 \implies a = \pm 5\]
  • Untuk \(a = b = 5\): \[5(5 + c - 5) = 7 \implies 5c = 7 \implies c = \dfrac{7}{5}\] Diperoleh solusi \(\left(5, 5, \dfrac{7}{5}\right)\).
  • Untuk \(a = b = -5\): \[-5(-5 + c - 5) = 7 \implies -5(c - 10) = 7 \implies -5c = -43 \implies c = \dfrac{43}{5}\] Diperoleh solusi \(\left(-5, -5, \dfrac{43}{5}\right)\).
Kasus 2: \(c = 5\)
Substitusi ke persamaan pertama: \[a(b + 5 - 5) = 7 \implies ab = 7 \implies b = \dfrac{7}{a}\] Substitusikan ke persamaan ketiga: \[\begin{aligned} a^2 + \left(\dfrac{7}{a}\right)^2 &= 50 \\ a^4 - 50a^2 + 49 &= 0 \\ (a^2 - 1)(a^2 - 49) &= 0 \end{aligned}\] Diperoleh:
  • \(a^2 = 1 \implies a = \pm 1\) dan \(b = \pm 7\), sehingga solusinya \((1, 7, 5)\) dan \((-1, -7, 5)\).
  • \(a^2 = 49 \implies a = \pm 7\) dan \(b = \pm 1\), sehingga solusinya \((7, 1, 5)\) dan \((-7, -1, 5)\).
Jadi, himpunan \((a, b, c) = \left\{\left(5, 5, \dfrac{7}{5}\right), \left(-5, -5, \dfrac{43}{5}\right), (-1, -7, 5), (1, 7, 5), (-7, -1, 5), (7, 1, 5)\right\}\).
Jika \(2a^2 + 2007a + 3 = 0\) dan \(3b^2 + 2007b + 2 = 0\) dengan \(ab \ne 1\), tentukan nilai dari \(\dfrac{a}{b}\).
Matematika Zone Indonesia
Pembahasan:
Kalikan persamaan pertama dengan \(b\) dan persamaan kedua dengan \(a\): \[\begin{aligned} 2a^2b + 2007ab + 3b &= 0 \\ 3ab^2 + 2007ab + 2a &= 0 \end{aligned}\] Kurangkan kedua persamaan: \[\begin{aligned} (2a^2b - 3ab^2) + (3b - 2a) &= 0 \\ ab(2a - 3b) - (2a - 3b) &= 0 \\ (ab - 1)(2a - 3b) &= 0 \end{aligned}\] Karena diketahui \(ab \ne 1\), maka haruslah: \[\begin{aligned} 2a - 3b &= 0 \\ 2a &= 3b \\ \dfrac{a}{b} &= \dfrac{3}{2} \end{aligned}\]
Jadi, \(\dfrac{a}{b} = \dfrac{3}{2}\).
Jika \(2017a^2 + 2018a + 2019 = 0\) dan \(2019b^2 + 2018b + 2017 = 0\) dengan \(ab \ne 1\), tentukan nilai dari \(\dfrac{a}{b}\).
Matematika Zone Indonesia
Pembahasan:
Kalikan persamaan pertama dengan \(b\) dan persamaan kedua dengan \(a\): \[\begin{aligned} 2017a^2b + 2018ab + 2019b &= 0 \\ 2019ab^2 + 2018ab + 2017a &= 0 \end{aligned}\] Kurangkan kedua persamaan: \[\begin{aligned} (2017a^2b - 2019ab^2) + (2019b - 2017a) &= 0 \\ ab(2017a - 2019b) - (2017a - 2019b) &= 0 \\ (ab - 1)(2017a - 2019b) &= 0 \end{aligned}\] Karena \(ab \ne 1\), maka: \[\begin{aligned} 2017a - 2019b &= 0 \\ 2017a &= 2019b \\ \dfrac{a}{b} &= \dfrac{2019}{2017} \end{aligned}\]
Jadi, \(\dfrac{a}{b} = \dfrac{2019}{2017}\).
Diketahui \(x - y = 9\) dan \(2x^2 + xy - 3y^2 = 45\). Jika \(a\) dan \(b\) adalah bilangan bulat terbesar yang kurang dari atau sama dengan \(x\) dan \(y\), maka hasil kali \(a\) dan \(b\) adalah ....
  1. \(-18\)
  2. \(-12\)
  3. 14
  4. 18
KSP SMP 2020
Pembahasan:
Faktorkan bentuk aljabar persamaan kedua: \[2x^2 + xy - 3y^2 = (x - y)(2x + 3y)\] Bagi dengan persamaan pertama \(x - y = 9\): \[\begin{aligned} \dfrac{2x^2 + xy - 3y^2}{x - y} &= \dfrac{45}{9} \\ 2x + 3y &= 5 \end{aligned}\] Eliminasi sistem persamaan: \[\begin{aligned} 2(x - y) &= 2(9) \implies 2x - 2y = 18 \\ 2x + 3y &= 5 \quad - \\ \hline -5y &= 13 \implies y = -\dfrac{13}{5} = -2{,}6 \end{aligned}\] Maka nilai \(x\): \[x = y + 9 = -2{,}6 + 9 = 6{,}4\] Fungsi tangga (floor): \[\begin{aligned} a &= \lfloor x \rfloor = \lfloor 6{,}4 \rfloor = 6 \\ b &= \lfloor y \rfloor = \lfloor -2{,}6 \rfloor = -3 \end{aligned}\] Hasil kali \(a\) dan \(b\): \[a \cdot b = 6 \cdot (-3) = -18\]
Jadi, hasil kali \(a\) dan \(b\) adalah \(-18\).

Jika \(x + y + 3\sqrt{x + y} = 18\) dan \(x - y - 2\sqrt{x - y} = 15\), maka \(x \cdot y = \dots\)
Diktat Pembinaan Olimpiade
Pembahasan:
Misalkan \(a = \sqrt{x + y} \ge 0\) dan \(b = \sqrt{x - y} \ge 0\).

Persamaan pertama: \[\begin{aligned} a^2 + 3a - 18 &= 0 \\ (a + 6)(a - 3) &= 0 \end{aligned}\] Karena \(a \ge 0\), maka \(a = 3 \implies x + y = 3^2 = 9\).

Persamaan kedua: \[\begin{aligned} b^2 - 2b - 15 &= 0 \\ (b + 3)(b - 5) &= 0 \end{aligned}\] Karena \(b \ge 0\), maka \(b = 5 \implies x - y = 5^2 = 25\).

Gunakan identitas aljabar: \[\begin{aligned} x \cdot y &= \dfrac{(x + y)^2 - (x - y)^2}{4} \\[4pt] &= \dfrac{9^2 - 25^2}{4} \\[4pt] &= \dfrac{81 - 625}{4} \\[4pt] &= \dfrac{-544}{4} = -136 \end{aligned}\]
Jadi, \(x \cdot y = -136\).
Diketahui \(a - b = 1\) dan \(a^2 - b^2 = 3\). Tentukan nilai dari \(a^3 - b^3\).
Strategi Pendidikan Olimpiade Matematika
Pembahasan:
Faktorkan selisih kuadrat: \[\begin{aligned} a^2 - b^2 &= 3 \\ (a - b)(a + b) &= 3 \\ 1 \cdot (a + b) &= 3 \implies a + b = 3 \end{aligned}\] Eliminasi sistem persamaan: \[\begin{aligned} a - b &= 1 \\ a + b &= 3 \quad + \\ \hline 2a &= 4 \implies a = 2 \end{aligned}\] Nilai \(b\): \[b = 3 - a = 3 - 2 = 1\] Maka: \[\begin{aligned} a^3 - b^3 &= 2^3 - 1^3 \\ &= 8 - 1 = 7 \end{aligned}\]
Jadi, \(a^3 - b^3 = 7\).
