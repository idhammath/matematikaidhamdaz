Ringkasan dan penjelasan lengkap materi Bilangan Kompleks

1. Pengertian Satuan Imajiner dan Bilangan Kompleks

Dalam himpunan bilangan real ($\mathbb{R}$), persamaan kuadrat seperti $x^2 + 1 = 0$ atau $x^2 = -1$ tidak memiliki penyelesaian karena kuadrat dari setiap bilangan real selalu bernilai non-negatif ($x^2 \ge 0$). Untuk memperluas sistem bilangan agar setiap persamaan polinomial memiliki akar, didefinisikan satuan imajiner $i$ (notasi Euler) yang memenuhi: $$i = \sqrt{-1} \iff i^2 = -1$$

Dengan menggunakan satuan imajiner $i$, akar kuadrat dari sembarang bilangan real negatif $-p$ (dengan $p > 0$) dapat dituliskan sebagai: $$\sqrt{-p} = \sqrt{p \cdot (-1)} = \sqrt{p} \cdot i = i\sqrt{p}$$ Catatan Penting: Sifat $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$ tidak berlaku apabila $a < 0$ dan $b < 0$ sekaligus. Jika menjumpai perkalian akar negatif, ubahlah ke dalam bentuk $i$ terlebih dahulu: $$\sqrt{-4} \cdot \sqrt{-9} = (2i)(3i) = 6i^2 = -6 \quad \left(\text{bukan } \sqrt{(-4)(-9)} = \sqrt{36} = 6\right)$$

1.1. Siklus Perpangkatan Satuan Imajiner ($i^n$)

Perpangkatan bilangan bulat dari satuan imajiner $i$ berulang secara periodik setiap $4$ pangkat ($i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$). Untuk sembarang bilangan bulat $n$, nilai $i^n$ ditentukan oleh sisa pembagian $n$ oleh $4$:

Bentuk Pangkat ($k \in \mathbb{Z}$) Sisa Pembagian $n \bmod 4$ Nilai $i^n$ Contoh Perhitungan
$$i^{4k}$$ $0$ $$1$$ $i^{2024} = i^{4(506)} = 1$, $\quad i^0 = 1$
$$i^{4k + 1}$$ $1$ $$i$$ $i^{2025} = i^{2024 + 1} = i$
$$i^{4k + 2}$$ $2$ $$-1$$ $i^{2026} = i^{2024 + 2} = -1$
$$i^{4k + 3}$$ $3$ $$-i$$ $i^{2027} = i^{2024 + 3} = -i$, $\quad i^{-1} = \frac{1}{i} = -i$

Sifat Penjumlahan Empat Pangkat Berurutan: Jumlah dari empat perpangkatan $i$ yang berurutan selalu bernilai nol: $$i^n + i^{n+1} + i^{n+2} + i^{n+3} = i^n(1 + i + i^2 + i^3) = i^n(1 + i - 1 - i) = 0$$

1.2. Bentuk Umum (Kartesius) dan Kesamaan Bilangan Kompleks

Bilangan kompleks adalah bilangan yang dinyatakan dalam bentuk standar (bentuk Kartesius/aljabar): $$z = a + bi \quad \text{dengan } a, b \in \mathbb{R} \text{ dan } i^2 = -1$$ Himpunan seluruh bilangan kompleks dilambangkan dengan $\mathbb{C} = \{a + bi \mid a, b \in \mathbb{R}\}$, di mana berlaku rantai himpunan bagian $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$.

  • Bagian Real ($\text{Re}(z)$): Bilangan real $a$ disebut bagian real dari $z$, ditulis $\text{Re}(z) = a$.
  • Bagian Imajiner ($\text{Im}(z)$): Bilangan real $b$ (koefisien dari $i$, tanpa menyertakan huruf $i$) disebut bagian imajiner dari $z$, ditulis $\text{Im}(z) = b$.
  • Jika $b = 0$, maka $z = a$ adalah bilangan real murni. Jika $a = 0$ dan $b \neq 0$, maka $z = bi$ disebut bilangan imajiner murni.
  • Kesamaan Dua Bilangan Kompleks: Dua bilangan kompleks $z_1 = a + bi$ dan $z_2 = c + di$ dikatakan sama jika dan hanya jika bagian realnya sama dan bagian imajinernya sama: $$a + bi = c + di \iff a = c \quad \text{dan} \quad b = d$$

2. Operasi Aljabar dan Sekawan (Konjugat) Bilangan Kompleks

Misalkan diketahui dua bilangan kompleks $z_1 = a + bi$ dan $z_2 = c + di$ dengan $a, b, c, d \in \mathbb{R}$. Operasi hitung dasar pada $\mathbb{C}$ didefinisikan sebagai berikut:

  1. Penjumlahan dan Pengurangan: Jumlahkan atau kurangkan bagian real dengan bagian real, serta bagian imajiner dengan bagian imajiner: $$z_1 \pm z_2 = (a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i$$
  2. Perkalian: Kalikan secara distributif dengan mensubstitusikan $i^2 = -1$: $$z_1 \cdot z_2 = (a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i$$
  3. Sekawan (Konjugat) Bilangan Kompleks ($\bar{z}$ atau $z^*$):
    Sekawan dari $z = a + bi$ diperoleh dengan membalik tanda pada bagian imajinernya: $$\bar{z} = \overline{a + bi} = a - bi$$ Perkalian suatu bilangan kompleks dengan sekawannya selalu menghasilkan bilangan real non-negatif (jumlah kuadrat komponennya): $$z \cdot \bar{z} = (a + bi)(a - bi) = a^2 - b^2i^2 = a^2 + b^2$$
  4. Pembagian Bilangan Kompleks (Rasionalisasi Penyebut):
    Untuk membagi $z_1$ dengan $z_2 \neq 0$, kalikan pembilang dan penyebut dengan sekawan dari penyebut ($\bar{z}_2 = c - di$): $$\frac{z_1}{z_2} = \frac{a + bi}{c + di} \cdot \frac{c - di}{c - di} = \frac{(ac + bd) + (bc - ad)i}{c^2 + d^2} = \left(\frac{ac + bd}{c^2 + d^2}\right) + \left(\frac{bc - ad}{c^2 + d^2}\right)i$$
  5. Invers Perkalian ($z^{-1}$): Untuk setiap $z = a + bi \neq 0$, invers perkaliannya adalah: $$z^{-1} = \frac{1}{z} = \frac{\bar{z}}{z \cdot \bar{z}} = \frac{a - bi}{a^2 + b^2} = \frac{a}{a^2 + b^2} - \frac{b}{a^2 + b^2}i$$
Sifat Operasi Sekawan (Konjugat) Rumus Identitas Keterangan Penting
Konjugat Ganda $$\overline{(\bar{z})} = z$$ Sekawan dari sekawan kembali ke bilangan kompleks semula.
Penjumlahan & Selisih dengan $\bar{z}$ $$z + \bar{z} = 2a = 2\,\text{Re}(z)$$$$z - \bar{z} = 2bi = 2i\,\text{Im}(z)$$ $z$ adalah bilangan real $\iff \bar{z} = z$.
$z$ adalah imajiner murni $\iff \bar{z} = -z$.
Linearitas Konjugat $$\overline{z_1 \pm z_2} = \bar{z}_1 \pm \bar{z}_2$$ Konjugat dari jumlah/selisih sama dengan jumlah/selisih konjugatnya.
Konjugat Perkalian, Pembagian & Pangkat $$\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2, \quad \overline{\left(\frac{z_1}{z_2}\right)} = \frac{\bar{z}_1}{\bar{z}_2}, \quad \overline{(z^n)} = (\bar{z})^n$$ Jika polinomial berkoefisien real $P(x) = 0$ memiliki akar kompleks $z_0$, maka $\bar{z}_0$ pasti juga merupakan akarnya (Teorema Akar Sekawan).

3. Bidang Kompleks (Diagram Argand), Modulus, dan Argumen

Secara geometris, setiap bilangan kompleks $z = a + bi$ berkorespondensi satu-satu dengan titik berkoordinat $(a, b)$ atau vektor posisi dari titik asal $O(0,0)$ menuju titik $P(a, b)$ pada bidang koordinat dua dimensi yang disebut Bidang Kompleks atau Diagram Argand:

  • Sumbu Horizontal (Sumbu-$x$): Disebut Sumbu Real ($\text{Re}$).
  • Sumbu Vertikal (Sumbu-$y$): Disebut Sumbu Imajiner ($\text{Im}$).
  • Konjugat $\bar{z} = a - bi$ secara geometris merupakan hasil pencerminan (refleksi) titik $z = a + bi$ terhadap sumbu Real.

3.1. Modulus Bilangan Kompleks ($|z|$)

Modulus (atau nilai mutlak) dari bilangan kompleks $z = a + bi$, dilambangkan dengan $|z|$ atau $r$, adalah jarak titik $z(a, b)$ ke titik asal $O(0, 0)$ pada bidang Argand: $$r = |z| = |a + bi| = \sqrt{a^2 + b^2} = \sqrt{[\text{Re}(z)]^2 + [\text{Im}(z)]^2}$$ Untuk sembarang $z, z_1, z_2 \in \mathbb{C}$, berlaku sifat-sifat modulus yang sangat ampuh untuk menyederhanakan perhitungan tanpa perlu menjabarkan bentuk aljabarnya:

  • Hubungan dengan Konjugat: $|z|^2 = z \cdot \bar{z} = a^2 + b^2$ dan $|z| = |\bar{z}| = |-z|$.
  • Modulus Perkalian dan Perpangkatan: $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$ dan $|z^n| = |z|^n$.
  • Modulus Pembagian: $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$ untuk $z_2 \neq 0$.
  • Hukum Jajargenjang (Parallelogram Law): $$|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2\left(|z_1|^2 + |z_2|^2\right)$$

3.2. Jarak, Ketaksamaan Segitiga, dan Tempat Kedudukan (Lokus) Geometri

Selisih dua bilangan kompleks $z_1 - z_2$ merepresentasikan vektor dari titik $z_2$ ke titik $z_1$, sehingga jarak Euclid antara titik $z_1 = x_1 + y_1i$ dan $z_2 = x_2 + y_2i$ pada bidang Argand adalah: $$d(z_1, z_2) = |z_1 - z_2| = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

Ketaksamaan Segitiga (Triangle Inequality):
Panjang sisi ketiga segitiga tidak pernah melebihi jumlah panjang dua sisi lainnya dan tidak kurang dari selisih keduanya: $$\big||z_1| - |z_2|\big| \le |z_1 \pm z_2| \le |z_1| + |z_2|$$

  • Batas maksimum $|z_1 + z_2| = |z_1| + |z_2|$ tercapai jika dan hanya jika vektor $z_1$ dan $z_2$ searah ($z_1 = k z_2$ untuk suatu bilangan real $k \ge 0$).
  • Batas minimum $|z_1 - z_2| = \big||z_1| - |z_2|\big|$ juga tercapai ketika $z_1$ dan $z_2$ searah dari titik asal.

Persamaan / Pertidaksamaan Kompleks BentukTempat Kedudukan (Lokus) pada Bidang Argand
$$|z - z_0| = R \quad (R > 0)$$ Lingkaran yang berpusat di titik $z_0(x_0, y_0)$ dengan jari-jari $R$. (Untuk $|z - z_0| \le R$ berupa cakram tertutup di dalam dan pada lingkaran).
$$|z - z_1| = |z - z_2|$$ Garis Sumbu (Perpendicular Bisector), yaitu garis lurus yang membagi dua sama panjang dan tegak lurus terhadap segmen penghubung titik $z_1$ dan $z_2$.
$$|z - z_1| + |z - z_2| = 2a \quad (2a > |z_1 - z_2|)$$ Elips dengan kedua titik fokus di $z_1$ dan $z_2$ serta panjang sumbu mayor $2a$. (Jika $2a = |z_1 - z_2|$, lokusnya berupa ruas garis lurus penghubung $z_1$ dan $z_2$).
$$\arg(z - z_0) = \alpha$$ Sinar Garis (Half-Line) yang berpangkal di titik $z_0$ (tanpa memuat titik $z_0$) dan membentuk sudut berarah $\alpha$ terhadap sumbu Real positif.

3.3. Argumen Bilangan Kompleks ($\arg(z)$ dan $\text{Arg}(z)$)

Untuk $z = a + bi \neq 0$, argumen dari $z$ (ditulis $\arg(z) = \theta$) adalah sudut berarah yang dibentuk oleh sumbu Real positif terhadap vektor posisi $z$ (berlawanan arah jarum jam bernilai positif) yang memenuhi: $$\cos \theta = \frac{a}{r}, \qquad \sin \theta = \frac{b}{r}, \qquad \tan \theta = \frac{b}{a}$$ Karena fungsi trigonometri berperiode $2\pi$ ($360^\circ$), nilai $\arg(z) = \theta + 2k\pi$ ($k \in \mathbb{Z}$) memiliki tak hingga banyaknya nilai. Nilai tunggal $\theta$ yang dibatasi pada interval utama $-\pi < \theta \le \pi$ (atau pada beberapa kurikulum $0 \le \theta < 2\pi$) disebut Argumen Utama dan ditulis dengan huruf kapital $\text{Arg}(z)$. Pastikan selalu memeriksa kuadran titik $(a, b)$ saat menentukan $\theta$:

  • Kuadran I ($a > 0, b > 0$): $\theta = \arctan\left(\left|\frac{b}{a}\right|\right)$
  • Kuadran II ($a < 0, b > 0$): $\theta = 180^\circ - \arctan\left(\left|\frac{b}{a}\right|\right)$ atau $\pi - \alpha$
  • Kuadran III ($a < 0, b < 0$): $\theta = 180^\circ + \arctan\left(\left|\frac{b}{a}\right|\right)$ (atau $-\pi + \alpha$ untuk rentang $(-\pi, \pi]$)
  • Kuadran IV ($a > 0, b < 0$): $\theta = 360^\circ - \arctan\left(\left|\frac{b}{a}\right|\right)$ (atau $-\alpha$ untuk rentang $(-\pi, \pi]$)

4. Bentuk Polar (Trigonometri) dan Bentuk Eksponensial (Euler)

Dari hubungan koordinat kutub $a = r \cos \theta$ dan $b = r \sin \theta$, setiap bilangan kompleks $z = a + bi \neq 0$ dapat disajikan dalam tiga bentuk yang ekuivalen:

  1. Bentuk Kartesius (Aljabar): $z = a + bi$
  2. Bentuk Polar (Trigonometri): $$z = r(\cos \theta + i \sin \theta) = r\,\text{cis}\,\theta$$ di mana $\text{cis}\,\theta$ adalah singkatan standar dari $\cos \theta + i \sin \theta$.
  3. Bentuk Eksponensial (Rumus Euler): Berdasarkan Formula Euler $e^{i\theta} = \cos \theta + i \sin \theta$, maka: $$z = r e^{i\theta}$$ Khusus untuk $\theta = \pi$, diperoleh Identitas Euler yang sangat terkenal: $e^{i\pi} + 1 = 0$.

4.1. Perkalian dan Pembagian dalam Bentuk Polar / Eksponensial

Misalkan $z_1 = r_1(\cos \theta_1 + i \sin \theta_1) = r_1 e^{i\theta_1}$ dan $z_2 = r_2(\cos \theta_2 + i \sin \theta_2) = r_2 e^{i\theta_2}$. Dengan menggunakan rumus jumlah dan selisih sudut trigonometri, berlaku:

  • Perkalian (Modulus dikalikan, Argumen dijumlahkan): $$z_1 \cdot z_2 = r_1 r_2 \big[\cos(\theta_1 + \theta_2) + i \sin(\theta_1 + \theta_2)\big] = r_1 r_2\,\text{cis}(\theta_1 + \theta_2) = r_1 r_2 e^{i(\theta_1 + \theta_2)}$$ Makna Geometris: Mengalikan bilangan kompleks $z_1$ dengan $z_2 = r_2\,\text{cis}\,\theta_2$ sama dengan memutar (merotasikan) vektor $z_1$ terhadap titik asal $O(0,0)$ sebesar sudut $\theta_2$ berlawanan arah jarum jam sekaligus mendilatasikannya dengan faktor skala $r_2$. Khususnya, perkalian dengan $i = 1\,\text{cis}\,90^\circ$ adalah rotasi $90^\circ$ berlawanan arah jarum jam!
  • Pembagian (Modulus dibagi, Argumen dikurangkan): $$\frac{z_1}{z_2} = \frac{r_1}{r_2} \big[\cos(\theta_1 - \theta_2) + i \sin(\theta_1 - \theta_2)\big] = \frac{r_1}{r_2}\,\text{cis}(\theta_1 - \theta_2) = \frac{r_1}{r_2} e^{i(\theta_1 - \theta_2)} \quad (z_2 \neq 0)$$

5. Teorema De Moivre, Akar Pangkat-$n$, dan Akar-Akar Satuan

5.1. Teorema De Moivre (Perpangkatan Bilangan Kompleks)

Untuk setiap bilangan kompleks $z = r(\cos \theta + i \sin \theta)$ dan sembarang bilangan bulat $n \in \mathbb{Z}$, berlaku Teorema De Moivre: $$z^n = \big[r(\cos \theta + i \sin \theta)\big]^n = r^n (\cos n\theta + i \sin n\theta) = r^n\,\text{cis}(n\theta) = r^n e^{in\theta}$$ Teorema ini sangat efektif untuk menghitung perpangkatan tinggi seperti $(1 + i\sqrt{3})^{12}$ tanpa menggunakan ekspansi Binomial Newton.

5.2. Akar Pangkat-$n$ dari Bilangan Kompleks

Setiap bilangan kompleks tak nol $z = r\,\text{cis}\,\theta$ memiliki tepat $n$ buah akar pangkat-$n$ yang berbeda ($w^n = z$), yang diberikan oleh rumus: $$w_k = \sqrt[n]{r} \left[\cos\left(\frac{\theta + 2k\pi}{n}\right) + i \sin\left(\frac{\theta + 2k\pi}{n}\right)\right]$$ $$\text{atau } w_k = \sqrt[n]{r}\,\text{cis}\left(\frac{\theta + k \cdot 360^\circ}{n}\right), \quad k = 0, 1, 2, \dots, n - 1$$

Sifat Geometris Akar Pangkat-$n$:
Untuk $n \ge 3$, kesemua $n$ titik akar $w_0, w_1, \dots, w_{n-1}$ terletak pada lingkaran berjari-jari $R = \sqrt[n]{r}$ yang berpusat di $O(0,0)$ dengan selisih sudut antar-akar yang berdekatan sebesar $\Delta\theta = \frac{2\pi}{n} = \frac{360^\circ}{n}$, sehingga titik-titik tersebut membentuk titik-titik sudut segi-$n$ beraturan!

5.3. Akar-Akar Satuan (Roots of Unity) & Sifat Khusus $\omega$

Penyelesaian dari persamaan $z^n = 1 = 1\,\text{cis}\,0^\circ$ disebut akar pangkat-$n$ dari satuan, yaitu $\zeta_k = \text{cis}\left(\frac{2k\pi}{n}\right) = e^{i 2k\pi / n}$ untuk $k = 0, 1, \dots, n-1$. Jumlah seluruh $n$ akar satuan untuk $n \ge 2$ selalu bernilai nol ($\sum_{k=0}^{n-1} \zeta_k = 0$).

💡 Akar Pangkat Tiga dari Satuan ($\omega$) — Senjata Ampuh Soal Olimpiade / HOTS:
Persamaan $z^3 = 1 \iff (z - 1)(z^2 + z + 1) = 0$ memiliki tiga akar, yaitu $1$, $\omega$, dan $\omega^2$, di mana: $$\omega = \cos 120^\circ + i \sin 120^\circ = -\frac{1}{2} + \frac{1}{2}\sqrt{3}\,i \quad \text{dan} \quad \omega^2 = \bar{\omega} = -\frac{1}{2} - \frac{1}{2}\sqrt{3}\,i$$ Sifat fundamental $\omega$:
1. $\omega^3 = 1 \implies \omega^{3k} = 1, \quad \omega^{3k+1} = \omega, \quad \omega^{3k+2} = \omega^2$
2. $1 + \omega + \omega^2 = 0 \implies \omega + \omega^2 = -1, \quad 1 + \omega = -\omega^2, \quad 1 + \omega^2 = -\omega$
3. Jika suatu bilangan memenuhi $z + \frac{1}{z} = -1$ (atau $z^2 + z + 1 = 0$), maka pasti $z^3 = 1$. Sebaliknya, jika $z + \frac{1}{z} = 1$ (atau $z^2 - z + 1 = 0$), maka $z = -\omega$ sehingga $z^3 = -1$ dan $z^6 = 1$.

6. Contoh Soal dan Pembahasan Terpadu

Pelajari contoh-contoh soal berjenjang berikut untuk menguasai manipulasi aljabar kompleks, sifat modulus, Teorema De Moivre, tempat kedudukan (lokus), hingga aplikasi akar satuan:

No. 1
Diketahui bilangan kompleks $z = \frac{5 + 12i}{3 - 4i} + \sum_{k=1}^{2026} i^k$. Tentukan bagian real $\text{Re}(z)$, bagian imajiner $\text{Im}(z)$, konjugat $\bar{z}$, serta modulus dari suku pecahan $\left|\frac{5 + 12i}{3 - 4i}\right|$!
Penyelesaian:

Langkah 1: Sederhanakan pembagian $\frac{5 + 12i}{3 - 4i}$ dengan sekawan penyebut

Kalikan pembilang dan penyebut dengan sekawan dari $3 - 4i$, yaitu $3 + 4i$: $$\frac{5 + 12i}{3 - 4i} \cdot \frac{3 + 4i}{3 + 4i} = \frac{15 + 20i + 36i + 48i^2}{3^2 + (-4)^2} = \frac{(15 - 48) + 56i}{9 + 16} = \frac{-33 + 56i}{25} = -\frac{33}{25} + \frac{56}{25}i$$

Langkah 2: Hitung deret perpangkatan $\sum_{k=1}^{2026} i^k$

Ingat bahwa jumlah setiap $4$ suku berurutan perpangkatan $i$ selalu bernilai $0$. Karena $2026 = 4 \times 506 + 2$, maka $2024$ suku pertama habis bernilai $0$, menyisakan dua suku terakhir: $$\sum_{k=1}^{2026} i^k = \underbrace{(i^1 + i^2 + \dots + i^{2024})}_{= 0} + i^{2025} + i^{2026} = i^1 + i^2 = i - 1 = -1 + i$$

Langkah 3: Tentukan $z$, $\text{Re}(z)$, $\text{Im}(z)$, $\bar{z}$, dan modulus pecahan

$$z = \left(-\frac{33}{25} + \frac{56}{25}i\right) + (-1 + i) = -\frac{58}{25} + \frac{81}{25}i$$ Maka diperoleh $\text{Re}(z) = -\frac{58}{25}$, $\text{Im}(z) = \frac{81}{25}$, dan konjugatnya $\bar{z} = -\frac{58}{25} - \frac{81}{25}i$.
Untuk menghitung modulus suku pecahan, gunakan sifat $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$ secara langsung: $$\left|\frac{5 + 12i}{3 - 4i}\right| = \frac{|5 + 12i|}{|3 - 4i|} = \frac{\sqrt{5^2 + 12^2}}{\sqrt{3^2 + (-4)^2}} = \frac{\sqrt{25 + 144}}{\sqrt{9 + 16}} = \frac{13}{5}$$

Jadi, $\text{Re}(z) = -\frac{58}{25}$, $\text{Im}(z) = \frac{81}{25}$, $\bar{z} = -\frac{58}{25} - \frac{81}{25}i$, dan $\left|\frac{5 + 12i}{3 - 4i}\right| = \frac{13}{5}$.
No. 2
Tentukan nilai bilangan real $x$ dan $y$ yang memenuhi persamaan bilangan kompleks berikut: $$(2x - 3yi)(1 + i) + (x + 2yi)(1 - 2i) = 14 - 7i$$
Penyelesaian:

Langkah 1: Jabarkan ruas kiri dan kelompokkan bagian real serta bagian imajiner

Jabarkan masing-masing perkalian dengan mengingat bahwa $i^2 = -1$: $$(2x - 3yi)(1 + i) = 2x + 2xi - 3yi - 3yi^2 = (2x + 3y) + (2x - 3y)i$$ $$(x + 2yi)(1 - 2i) = x - 2xi + 2yi - 4yi^2 = (x + 4y) + (-2x + 2y)i$$ Jumlahkan kedua hasil di atas pada ruas kiri: $$\big[(2x + 3y) + (x + 4y)\big] + \big[(2x - 3y) + (-2x + 2y)\big]i = 14 - 7i$$ $$(3x + 7y) + (-y)i = 14 - 7i$$

Langkah 2: Gunakan syarat kesamaan dua bilangan kompleks

  • Samakan bagian imajiner: $-y = -7 \implies y = 7$.
  • Samakan bagian real: $3x + 7y = 14 \implies 3x + 7(7) = 14 \implies 3x = 14 - 49 = -35 \implies x = -\frac{35}{3}$.
Jadi, nilai yang memenuhi adalah $x = -\frac{35}{3}$ dan $y = 7$.
No. 3
Dengan menggunakan bentuk polar dan Teorema De Moivre, hitunglah nilai dari: $$w = \frac{(-\sqrt{3} + i)^8}{(1 - i)^6}$$ Nyatakan hasil akhirnya dalam bentuk Kartesius $a + bi$!
Penyelesaian:

Langkah 1: Ubah $z_1 = -\sqrt{3} + i$ dan $z_2 = 1 - i$ ke dalam bentuk polar

  • Untuk $z_1 = -\sqrt{3} + i$ (berada di Kuadran II karena $a = -\sqrt{3} < 0$ dan $b = 1 > 0$): $$r_1 = \sqrt{(-\sqrt{3})^2 + 1^2} = \sqrt{3 + 1} = 2$$ $$\tan \theta_1 = \frac{1}{-\sqrt{3}} \implies \theta_1 = 180^\circ - 30^\circ = 150^\circ \implies z_1 = 2\,\text{cis}\,150^\circ$$
  • Untuk $z_2 = 1 - i$ (berada di Kuadran IV karena $a = 1 > 0$ dan $b = -1 < 0$): $$r_2 = \sqrt{1^2 + (-1)^2} = \sqrt{2}$$ $$\tan \theta_2 = \frac{-1}{1} = -1 \implies \theta_2 = -45^\circ \implies z_2 = \sqrt{2}\,\text{cis}(-45^\circ)$$

Langkah 2: Terapkan Teorema De Moivre dan aturan pembagian polar

$$z_1^8 = \left(2\,\text{cis}\,150^\circ\right)^8 = 2^8\,\text{cis}(8 \times 150^\circ) = 256\,\text{cis}(1200^\circ)$$ $$z_2^6 = \left(\sqrt{2}\,\text{cis}(-45^\circ)\right)^6 = (\sqrt{2})^6\,\text{cis}(6 \times (-45^\circ)) = 2^3\,\text{cis}(-270^\circ) = 8\,\text{cis}(-270^\circ)$$ Bagikan kedua bentuk polar tersebut: $$w = \frac{256\,\text{cis}(1200^\circ)}{8\,\text{cis}(-270^\circ)} = \frac{256}{8}\,\text{cis}\big(1200^\circ - (-270^\circ)\big) = 32\,\text{cis}(1470^\circ)$$

Langkah 3: Sederhanakan sudut dan ubah kembali ke bentuk Kartesius

Karena $1470^\circ = 4 \times 360^\circ + 30^\circ$, maka: $$w = 32(\cos 30^\circ + i \sin 30^\circ) = 32\left(\frac{1}{2}\sqrt{3} + \frac{1}{2}i\right) = 16\sqrt{3} + 16i$$

Jadi, hasil dari $\frac{(-\sqrt{3} + i)^8}{(1 - i)^6}$ adalah $16\sqrt{3} + 16i$.
No. 4
Diketahui bilangan kompleks $z$ memenuhi persamaan tempat kedudukan $|z - (3 + 4i)| = 2$. Tentukan nilai maksimum dan nilai minimum dari $|z|$, serta tentukan bilangan kompleks $z$ saat nilai maksimum tersebut tercapai!
Penyelesaian:

Langkah 1: Interpretasi geometris pada bidang Argand (atau Ketaksamaan Segitiga)

Persamaan $|z - z_0| = R$ dengan $z_0 = 3 + 4i$ dan $R = 2$ menyatakan bahwa titik $z$ bergerak pada lingkaran yang berpusat di $P(3, 4)$ dengan jari-jari $R = 2$.
Jarak dari titik asal $O(0, 0)$ ke pusat lingkaran $z_0 = 3 + 4i$ adalah: $$|z_0| = |3 + 4i| = \sqrt{3^2 + 4^2} = 5$$

Langkah 2: Hitung nilai maksimum dan minimum $|z|$

Berdasarkan ketaksamaan segitiga pada $z = z_0 + (z - z_0)$: $$\big||z_0| - |z - z_0|\big| \le |z| \le |z_0| + |z - z_0|$$ $$|5 - 2| \le |z| \le 5 + 2 \iff 3 \le |z| \le 7$$ Dengan demikian, $|z|_{\text{min}} = 3$ dan $|z|_{\text{maks}} = 7$.

Langkah 3: Tentukan titik $z$ saat $|z|$ mencapai maksimum

Nilai maksimum $|z| = 7$ tercapai ketika titik $z$ terletak pada perpanjangan garis dari titik asal $O(0,0)$ melewati pusat $z_0$ (vektor $z$ searah dengan $z_0$, namun berjarak $7$ satuan dari titik asal): $$z_{\text{maks}} = \frac{|z|_{\text{maks}}}{|z_0|} \cdot z_0 = \frac{7}{5}(3 + 4i) = \frac{21}{5} + \frac{28}{5}i$$

Jadi, nilai minimum $|z|$ adalah $3$, nilai maksimum $|z|$ adalah $7$, dan nilai maksimum tersebut dicapai pada $z = \frac{21}{5} + \frac{28}{5}i$.
No. 5
Misalkan $z$ adalah bilangan kompleks yang memenuhi persamaan $z + \frac{1}{z} = -1$. Tentukan nilai dari: $$S = z^{2026} + \frac{1}{z^{2026}} + \left(1 + z - z^2\right)^3$$
Penyelesaian:

Langkah 1: Identifikasi sifat akar pangkat tiga dari satuan ($\omega$)

Kalikan kedua ruas persamaan $z + \frac{1}{z} = -1$ dengan $z$ ($z \neq 0$): $$z^2 + 1 = -z \iff z^2 + z + 1 = 0$$ Kalikan kedua ruas dengan $(z - 1)$: $$(z - 1)(z^2 + z + 1) = 0 \iff z^3 - 1 = 0 \implies z^3 = 1$$ Dengan demikian, $z = \omega$ adalah akar pangkat tiga tak-real dari satuan yang memenuhi $z^3 = 1$ dan $1 + z + z^2 = 0$.

Langkah 2: Hitung nilai $z^{2026} + \frac{1}{z^{2026}}$ dan $(1 + z - z^2)^3$

  • Karena $2026 = 3 \times 675 + 1$, maka $z^{2026} = \left(z^3\right)^{675} \cdot z^1 = 1^{675} \cdot z = z$. Akibatnya: $$z^{2026} + \frac{1}{z^{2026}} = z + \frac{1}{z} = -1$$
  • Dari sifat $1 + z + z^2 = 0$, kita peroleh $1 + z = -z^2$. Substitusikan ke dalam suku kedua: $$\left(1 + z - z^2\right)^3 = \left(-z^2 - z^2\right)^3 = \left(-2z^2\right)^3 = -8\left(z^3\right)^2 = -8(1)^2 = -8$$

Langkah 3: Jumlahkan kedua hasil

$$S = -1 + (-8) = -9$$

Jadi, nilai dari $S = z^{2026} + \frac{1}{z^{2026}} + \left(1 + z - z^2\right)^3$ adalah $-9$.
