Berikut adalah soal tingkat ... materi Integral Trigonometri Tak Tentu

Hasil dari integral tak tentu: \[\int \frac{\cos(2x)}{(\sin x + \cos x)^2} \, dx\] adalah ....

  1. \(\ln|\sin x + \cos x| + C\)
  2. \(-\ln|\sin x + \cos x| + C\)
  3. \(\dfrac{1}{\sin x + \cos x} + C\)
  4. \(-\dfrac{1}{\sin x + \cos x} + C\)
  5. \(\ln|\cos(2x)| + C\)
SNBT / UTBK
Pembahasan:

Langkah 1: Menguraikan Pembilang Menggunakan Identitas Trigonometri

Ingat identitas sudut rangkap untuk kosinus: \[\cos(2x) = \cos^2 x - \sin^2 x\] Bentuk ini merupakan selisih dua kuadrat yang dapat difaktorkan menjadi: \[\cos^2 x - \sin^2 x = (\cos x - \sin x)(\cos x + \sin x)\]

Langkah 2: Menyederhanakan Bentuk Pecahan

Substitusikan bentuk faktorisasi pembilang ke dalam pecahan integran: \[\frac{\cos(2x)}{(\sin x + \cos x)^2} = \frac{(\cos x - \sin x)(\cos x + \sin x)}{(\cos x + \sin x)^2}\] Sederhanakan dengan membagi faktor persekutuan \((\cos x + \sin x)\): \[= \frac{\cos x - \sin x}{\cos x + \sin x} = \frac{\cos x - \sin x}{\sin x + \cos x}\]

Langkah 3: Menggunakan Metode Substitusi

Misalkan: \[u = \sin x + \cos x\] Turunkan kedua ruas terhadap \(x\): \[\frac{du}{dx} = \cos x - \sin x \implies du = (\cos x - \sin x) \, dx\]

Langkah 4: Menghitung Integral

Substitusikan \(u\) dan \(du\) ke dalam bentuk integral: \[\int \frac{\cos x - \sin x}{\sin x + \cos x} \, dx = \int \frac{1}{u} \, du\] \[= \ln|u| + C\] Kembalikan \(u\) ke variabel aslinya: \[= \ln|\sin x + \cos x| + C\]

Jadi, hasil dari integral tak tentu tersebut adalah \(\ln|\sin x + \cos x| + C\) (Pilihan A).
