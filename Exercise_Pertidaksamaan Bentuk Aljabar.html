No. 1

Himpunan penyelesaian pertidaksamaan \(\dfrac4{x-2}\lt\dfrac{x}2\) adalah
  1. {x | x < −4 atau −2 < x < 2}
  2. {x | x < −2 atau 2 < x < 4}
  3. {x | x < −1 atau 2 < x < 4}
  1. {x | −2 < x < 2 atau x > 4}
  2. {x | −4 < x < −2 atau x > 2}
Grup WhatsApp
ALTERNATIF PENYELESAIAN
\(\begin{aligned} \dfrac4{x-2}&\lt\dfrac{x}2\\[8pt] \dfrac4{x-2}-\dfrac{x}2&\lt0\\[8pt] \dfrac{8-x(x-2)}{2(x-2)}&\lt0\\[8pt] \dfrac{8-x^2+2x}{2(x-2)}&\lt0\\[8pt] \dfrac{-x^2+2x+8}{2(x-2)}&\lt0\\[8pt] \dfrac{x^2-2x-8}{2(x-2)}&\gt0\\[8pt] \dfrac{(x-4)(x+2)}{2(x-2)}&\gt0 \end{aligned}\)
Pembuat nol:
  • x − 4 = 0
    x = 4
  • x + 2 = 0
    x = −2
  • x − 2 = 0
    x = 2
−2 < x < 2 atau x > 4.
Jadi, Hp = {x | −2 < x < 2 atau x > 4}

No. 2

Semua bilangan real x yang memenuhi \(\dfrac{x^2-3x-4}{x+5}\leq0\) adalah
  1. x < −5 atau x ≥ 4
  2. x ≤ −4 atau 1 ≤ x < 5
  3. −4 ≤ x ≤ 1 atau x > 5
  1. x < −5 atau −1 ≤ x ≤ 4
  2. −5 < x ≤ −1 atau x ≥ 4
Grup WhatsApp
ALTERNATIF PENYELESAIAN
Pembatas:
  • x2 − 3x − 4 = 0
    (x + 1)(x − 4) = 0
    x = −1 dan x = 4
  • x + 5 = 0
    x = −5

x < −5 atau −1 ≤ x ≤ 4
Jadi, x < −5 atau −1 ≤ x ≤ 4.
JAWAB: D
