Nilai x yang memenuhi persamaan \(\dfrac{\sqrt[3]{(0{,}008)^{7-2x}}}{(0{,}2)^{-4x+5}}=1\) adalah....
  1. −3
  2. −2
  3. −1
  4. 0
  5. 1
Sumber: Matematika Zone Id
Pembahasan:
\(\begin{aligned} \dfrac{\sqrt[3]{(0{,}008)^{7-2x}}}{(0{,}2)^{-4x+5}}&=1\\[4pt] \dfrac{\sqrt[3]{\left((0{,}2)^3\right)^{7-2x}}}{(0{,}2)^{-4x+5}}&=1\\[4pt] \dfrac{(0{,}2)^{7-2x}}{(0{,}2)^{-4x+5}}&=1\\[4pt] (0{,}2)^{7-2x-(-4x+5)}&=1\\ (0{,}2)^{7-2x+4x-5}&=1\\ (0{,}2)^{2x+2}&=(0{,}2)^0\\ 2x+2&=0\\ 2x&=-2\\ x&=-1 \end{aligned}\)
Jadi, nilai x yang memenuhi persamaan \(\dfrac{\sqrt[3]{(0{,}008)^{7-2x}}}{(0{,}2)^{-4x+5}}=1\) adalah −1.

Nilai x yang memenuhi persamaan: \[9^{x-2}=\left(\dfrac13\right)^{x^2-4x+1}\]
Sumber: Grup Telegram
Pembahasan:
\(\begin{aligned} 9^{x-2}&=\left(\dfrac13\right)^{x^2-4x+1}\\ \left(3^2\right)^{x-2}&=\left(3^{-1}\right)^{x^2-4x+1}\\ 3^{2x-4}&=3^{-x^2+4x-1}\\ 2x-4&=-x^2+4x-1\\ x^2-2x-3&=0\\ (x+1)(x-3)&=0 \end{aligned}\)
x = −1 dan x = 3.
Jadi, nilai x yang memenuhi adalah −1 dan 3.
Tentukan himpunan penyelesaian ${(2x+1)^{x-6}=(x+5)^{x-6}}$
Sumber: Grup Telegram
Pembahasan:
  • 2x + 1 = x + 5
    x = 4
  • x − 6 = 0
    x = 6
    Syarat:
    • 2x + 1 ≠ 0
      \(\begin{aligned} 2(6)+1&\neq0\\ 13&\neq0 \end{aligned}\)
      BENAR
    • x + 5 ≠ 0
      \(\begin{aligned} 6+5&\neq0\\ 11&\neq0 \end{aligned}\)
      BENAR
  • x − 6 = 1
    x = 7
  • x − 6 = −1
    x = 5
Jadi, Hp = {4, 5, 6, 7}.
Himpunan penyelesaian dari persamaan eksponen di bawah ini adalah .... \[{3^{x^2-6x-10}=\dfrac1{27}}\]
  1. (−2, −1)
  2. (−1, 7)
  3. (2, 5)
  4. (1, 10)
Sumber: Grup Telegram
Pembahasan:
\(\begin{aligned} 3^{x^2-6x-10}&=\dfrac1{27}\\ 3^{x^2-6x-10}&=\dfrac1{3^3}\\ 3^{x^2-6x-10}&=3^{-3}\\ x^2-6x-10&=-3\\ x^2-6x-7&=0\\ (x+1)(x-7)&=0 \end{aligned}\)
x = −1 atau x = 7
Jadi, himpunan penyelesaiannya adalah (−1, 7).

Jika x memenuhi \(\sqrt{3^{8x^3}}=\dfrac1{81}\), maka nilai dari 10x3 − 20x adalah
  1. 10
  2. 12
  3. 14
  4. 16
  5. 18
Sumber: SKMP Juli 2020
Pembahasan:
\(\begin{aligned} \sqrt{3^{8x^3}}&=\dfrac1{81}\\ 3^{\frac{8x^3}2}&=\dfrac1{3^4}\\ 3^{4x^3}&=3^{-4}\\ 4x^3&=-4\\ x^3&=-1\\ x&=-1 \end{aligned}\)
\(\begin{aligned} 10x^3- 20x&=10(-1)-20(-1)\\ &=-10+20\\ &=\boxed{\boxed{10}} \end{aligned}\)
Jadi, 10x3 − 20x = 10.

Nilai x yang merupakan solusi dari persamaan 52x + 51 + x − 6 = 0
  1. Hanya −6
  2. Hanya 0
  3. Hanya 2
  4. −6 dan 0
  5. 2 dan 0
Sumber: Grup Telegram
Pembahasan:
\(\begin{aligned} 5^{2x}+5^{1+x}-6&=0\\ 5^{x\cdot2}+5^1\cdot5^x-6&=0\\ \left(5^x\right)^2+5\cdot5^x-6&=0 \end{aligned}\)
Misal 5x = p
\(\begin{aligned} p^2+5p-6&=0\\ (p+6)(p-1)&=0 \end{aligned}\)
p = −6 atau p = 1
\(\begin{aligned} p&=-6\\ 5^x&=-6 \end{aligned}\)
Tidak ada nilai x yang memenuhi		 \(\begin{aligned} p&=1\\ 5^x&=5^0\\ x&=0 \end{aligned}\)
Jadi, nilai x yang merupakan solusi dari persamaan 52x + 51 + x − 6 = 0 adalah hanya 0.

Nilai x yang memenuhi persamaan \(3^{3x-5}=\sqrt[3]{27^{x+7}}\) adalah ....
Sumber: Latihan USBN SMK
Pembahasan:
\(\begin{aligned} 3^{3x-5}&=\sqrt[3]{27^{x+7}}\\ 3^{3x-5}&=\left(3^3\right)^{\frac{x+7}{3}}\\ 3^{3x-5}&=3^{x+7}\\ 3x-5&=x+7\\ 3x-x&=7+5\\ 2x&=12\\ x&=\dfrac{12}{2}\\ &=\boxed{\boxed{6}} \end{aligned}\)
Jadi, nilai x yang memenuhi persamaan \(3^{3x-5}=\sqrt[3]{27^{x+7}}\) adalah 6.
Jika x1 dan x2 merupakan akar-akar persamaan 5x + 1 + 52 − x = 126, maka x1 + x2 = ....
  1. \(25\dfrac15\)
  2. 5
  3. 1
  4. −1
  5. −3
Sumber: SIMAK UI 2009 Kode 911
Pembahasan:
\(\begin{aligned} 5^{x+1}+5^{2-x}&=126\\ 5^x\cdot5+\dfrac{5^2}{5^x}&=126\\[4pt] 5\cdot5^x+\dfrac{25}{5^x}&=126&{\color{red}\times5^x}\\[4pt] 5\cdot\left(5^x\right)^2+25&=126\cdot5^x\\ 5\cdot\left(5^x\right)^2-126\cdot5^x+25&=0 \end{aligned}\)

\(\begin{aligned} 5^{x_1+x_2}&=5^{x_1}\cdot5^{x_2}\\ &=\dfrac{25}5\\ &=\boxed{\boxed{5}} \end{aligned}\)
Jadi, x1 + x2 = 1.
