Ringkasan dan pembahasan mendalam materi Fungsi Trigonometri

1. Definisi dan Konsep Dasar Fungsi Trigonometri

Trigonometri berasal dari bahasa Yunani: trigonon (tiga sudut) dan metron (mengukur). Pada tingkatan fungsi, fungsi trigonometri memetakan suatu bilangan real atau ukuran sudut (dalam derajat maupun radian) ke suatu rasio geometris pada lingkaran satuan (unit circle).

Misalkan lingkaran satuan $x^2 + y^2 = 1$ memiliki titik pusat di origin $O(0,0)$. Jika sebuah titik $P(x, y)$ terletak pada lingkaran dan membentuk sudut baku $\theta$ dengan sumbu-$X$ positif berlawanan arah jarum jam, maka rasio trigonometri didefinisikan secara aljabar sebagai:

$$\sin \theta = y$$ $$\cos \theta = x$$ $$\tan \theta = \frac{y}{x} = \frac{\sin \theta}{\cos \theta} \quad (x \neq 0)$$

Fungsi kebalikan (resiprokal) didefinisikan sebagai: $$\csc \theta = \frac{1}{\sin \theta}, \quad \sec \theta = \frac{1}{\cos \theta}, \quad \cot \theta = \frac{1}{\tan \theta}$$

2. Ukuran Sudut: Derajat dan Radian

Dalam kalkulus dan analisis grafik fungsi trigonometri, variabel input sudut hampir selalu dinyatakan dalam ukuran radian karena radian merupakan perbandingan tak berdimensi dari panjang busur terhadap panjang jari-jari ($s = r\theta$).

$$\pi \text{ rad} = 180^\circ \iff 1 \text{ rad} = \frac{180^\circ}{\pi} \approx 57{,}296^\circ$$ $$1^\circ = \frac{\pi}{180} \text{ rad}$$

3. Nilai Sudut Istimewa pada Kuadran I - IV

Tanda positif atau negatif nilai fungsi trigonometri ditentukan oleh posisi kuadran sudut:

  • Kuadran I ($0 < \theta < \frac{\pi}{2}$): Semua fungsi bernilai positif ($x > 0, y > 0$).
  • Kuadran II ($\frac{\pi}{2} < \theta < \pi$): Hanya $\sin$ dan $\csc$ yang bernilai positif ($x < 0, y> 0$).
  • Kuadran III ($\pi < \theta < \frac{3\pi}{2}$): Hanya $\tan$ dan $\cot$ yang bernilai positif ($x < 0, y < 0$).
  • Kuadran IV ($\frac{3\pi}{2} < \theta < 2\pi$): Hanya $\cos$ dan $\sec$ yang bernilai positif ($x > 0, y < 0$).
$\theta$ (Derajat) $0^\circ$ $30^\circ$ $45^\circ$ $60^\circ$ $90^\circ$ $180^\circ$ $270^\circ$ $360^\circ$
$\theta$ (Radian) $0$ $\frac{\pi}{6}$ $\frac{\pi}{4}$ $\frac{\pi}{3}$ $\frac{\pi}{2}$ $\pi$ $\frac{3\pi}{2}$ $2\pi$
$\sin \theta$ $0$ $\frac{1}{2}$ $\frac{1}{2}\sqrt{2}$ $\frac{1}{2}\sqrt{3}$ $1$ $0$ $-1$ $0$
$\cos \theta$ $1$ $\frac{1}{2}\sqrt{3}$ $\frac{1}{2}\sqrt{2}$ $\frac{1}{2}$ $0$ $-1$ $0$ $1$
$\tan \theta$ $0$ $\frac{1}{3}\sqrt{3}$ $1$ $\sqrt{3}$ Tak Terdefinisi $0$ Tak Terdefinisi $0$

4. Karakteristik Grafik Fungsi Baku

Tiga grafik dasar trigonometri memiliki sifat periodik dan domain/range tersendiri:

A. Grafik Sinus: $f(x) = \sin x$

  • Domain: $D_f = \mathbb{R}$
  • Range: $R_f = [-1, 1]$
  • Periode: $T = 2\pi$
  • Amplitudo: $A = 1$
  • Titik Penting: $(0, 0)$, $(\frac{\pi}{2}, 1)$, $(\pi, 0)$, $(\frac{3\pi}{2}, -1)$, $(2\pi, 0)$
  • Sifat Simetri: Fungsi ganjil, $\sin(-x) = -\sin x$ (simetris terhadap titik asal $O$).

B. Grafik Cosinus: $f(x) = \cos x$

  • Domain: $D_f = \mathbb{R}$
  • Range: $R_f = [-1, 1]$
  • Periode: $T = 2\pi$
  • Amplitudo: $A = 1$
  • Titik Penting: $(0, 1)$, $(\frac{\pi}{2}, 0)$, $(\pi, -1)$, $(\frac{3\pi}{2}, 0)$, $(2\pi, 1)$
  • Sifat Simetri: Fungsi genap, $\cos(-x) = \cos x$ (simetris terhadap sumbu-$Y$).

C. Grafik Tangen: $f(x) = \tan x$

  • Domain: $D_f = \{x \in \mathbb{R} \mid x \neq \frac{\pi}{2} + k\pi, k \in \mathbb{Z}\}$
  • Range: $R_f = (-\infty, \infty)$
  • Periode: $T = \pi$
  • Asimtot Tegak: Garis $x = \frac{\pi}{2} + k\pi$ untuk $k \in \mathbb{Z}$.
  • Sifat Simetri: Fungsi ganjil, $\tan(-x) = -\tan x$.

5. Bentuk Umum dan Transformasi Fungsi Gelombang

Bentuk umum gelombang sinusoidal dinyatakan dengan parameter: $$y = A \sin(B(x - C)) + D \quad \text{atau} \quad y = A \sin(Bx - \alpha) + D$$ $$y = A \cos(B(x - C)) + D \quad \text{atau} \quad y = A \cos(Bx - \alpha) + D$$

  1. Amplitudo ($A$): Setengah selisih nilai maksimum dan minimum. $$\text{Amplitudo} = \vert{}A\vert{} = \frac{y_{\max} - y_{\min}}{2}$$
  2. Periode ($T$): Panjang interval satu siklus penuh berulang. $$T = \frac{2\pi}{\vert{}B\vert{}} \quad (\text{untuk sinus dan cosinus}), \qquad T = \frac{\pi}{\vert{}B\vert{}} \quad (\text{untuk tangen})$$
  3. Pergeseran Fasa / Horizontal ($C$): Grafik bergeser sejauh $C = \frac{\alpha}{B}$ ke arah kanan jika bertanda negatif $(x - C)$, atau ke kiri jika bertanda positif $(x + C)$.
  4. Pergeseran Vertikal / Garis Tengah ($D$): Garis keseimbangan (garis ekuilibrium gelombang) adalah $y = D$. $$D = \frac{y_{\max} + y_{\min}}{2}$$
  5. Nilai Ekstrem (Maksimum & Minimum): $$y_{\max} = \vert{}A\vert{} + D$$ $$y_{\min} = -\vert{}A\vert{} + D$$

6. Identitas-Identitas Penting Trigonometri

Identitas dasar yang esensial dalam menyelesaikan persamaan dan memanipulasi bentuk fungsi:

Kategori Identitas Rumus Aljabar Trigonometri
Identitas Phytagoras $\sin^2 x + \cos^2 x = 1$
$1 + \tan^2 x = \sec^2 x$
$1 + \cot^2 x = \csc^2 x$
Jumlah & Selisih Sudut $\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$
$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$
$\tan(\alpha \pm \beta) = \dfrac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$
Sudut Rangkap (Ganda) $\sin(2x) = 2\sin x \cos x$
$\cos(2x) = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$
$\tan(2x) = \dfrac{2\tan x}{1 - \tan^2 x}$
Bentuk Khusus Linear $a\cos x + b\sin x = k\cos(x - \alpha)$
dengan $k = \sqrt{a^2 + b^2}$ dan $\tan\alpha = \dfrac{b}{a}$

7. Contoh Aplikasi Soal dan Pemecahan

Contoh Soal: Tentukan nilai maksimum, nilai minimum, periode, serta amplitudo dari fungsi berikut: $$f(x) = -3\cos\left(2x - \frac{\pi}{3}\right) + 5$$

Penyelesaian:
Dari fungsi $f(x) = A\cos(B(x - C)) + D$, diperoleh:
  • $A = -3 \implies \text{Amplitudo } \vert{}A\vert{} = \vert{}-3\vert{} = 3$
  • $B = 2 \implies \text{Periode } T = \dfrac{2\pi}{B} = \dfrac{2\pi}{2} = \pi$
  • Pergeseran vertikal $D = 5$
Maka nilai ekstremnya: $$y_{\max} = \vert{}A\vert{} + D = 3 + 5 = 8$$ $$y_{\min} = -\vert{}A\vert{} + D = -3 + 5 = 2$$ Jadi, fungsi memiliki amplitudo $3$, periode $\pi$, nilai maksimum $8$, dan nilai minimum $2$.
