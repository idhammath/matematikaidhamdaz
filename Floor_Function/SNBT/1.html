Berikut adalah soal tingkat ... materi Floor Function

Diketahui \(x\) adalah bilangan real yang memenuhi persamaan:

\[ 2x - \lfloor x \rfloor = 7{,}4 \]

dengan \(\lfloor x \rfloor\) menyatakan bilangan bulat terbesar yang tidak lebih dari \(x\). Jumlah seluruh nilai real \(x\) yang memenuhi persamaan tersebut adalah ....

  1. \(13{,}5\)
  2. \(13{,}7\)
  3. \(13{,}9\)
  4. \(14{,}1\)
  5. \(14{,}3\)
SNBT / UTBK
Pembahasan:

Langkah 1: Dekomposisi bilangan real ke dalam bagian bulat dan bagian pecahan

Setiap bilangan real \(x\) dapat dinyatakan sebagai:

\[ x = n + \{x\} \]

dengan \(n = \lfloor x \rfloor \in \mathbb{Z}\) (bagian bulat) dan \(\{x\} = x - \lfloor x \rfloor\) merupakan bagian pecahan yang memenuhi interval baku:

\[ 0 \le \{x\} < 1 \]

Langkah 2: Substitusi ke dalam persamaan

Gantikan \(x = n + \{x\}\) dan \(\lfloor x \rfloor = n\) ke dalam persamaan semula:

\[ \begin{aligned} 2(n + \{x\}) - n &= 7{,}4 \\ 2n + 2\{x\} - n &= 7{,}4 \\ n + 2\{x\} &= 7{,}4 \\ 2\{x\} &= 7{,}4 - n \\ \{x\} &= \frac{7{,}4 - n}{2} \end{aligned} \]

Langkah 3: Menerapkan batasan interval bagian pecahan

Karena \(0 \le \{x\} < 1\), maka:

\[ \begin{aligned} 0 \le \frac{7{,}4 - n}{2} &< 1 \\[6pt] 0 \le 7{,}4 - n &< 2 \end{aligned} \]

Kurangkan \(7{,}4\) dari semua ruas:

\[ -7{,}4 \le -n < 2 - 7{,}4 \implies -7{,}4 \le -n < -5{,}4 \]

Kalikan dengan \(-1\) (tanda ketidaksamaan berbalik arah):

\[ 5{,}4 < n \le 7{,}4 \]

Karena \(n\) harus berupa bilangan bulat (\(n \in \mathbb{Z}\)), maka nilai \(n\) yang memenuhi hanyalah:

\[ n = 6 \quad \text{atau} \quad n = 7 \]

Langkah 4: Menentukan nilai solusi \(x\) untuk masing-masing \(n\)

  • Kasus 1: Untuk \(n = 6\) \[ \{x\} = \frac{7{,}4 - 6}{2} = \frac{1{,}4}{2} = 0{,}7 \] \[ x_1 = n + \{x\} = 6 + 0{,}7 = 6{,}7 \] (Uji: \(2(6{,}7) - \lfloor 6{,}7 \rfloor = 13{,}4 - 6 = 7{,}4\) — Memenuhi!)
  • Kasus 2: Untuk \(n = 7\) \[ \{x\} = \frac{7{,}4 - 7}{2} = \frac{0{,}4}{2} = 0{,}2 \] \[ x_2 = n + \{x\} = 7 + 0{,}2 = 7{,}2 \] (Uji: \(2(7{,}2) - \lfloor 7{,}2 \rfloor = 14{,}4 - 7 = 7{,}4\) — Memenuhi!)

Langkah 5: Menghitung jumlah seluruh solusi

\[ x_1 + x_2 = 6{,}7 + 7{,}2 = 13{,}9 \]
Jadi, jumlah seluruh nilai real \(x\) yang memenuhi adalah 13,9.
