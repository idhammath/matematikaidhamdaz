Ringkasan dan penjelasan lengkap materi Bilangan Real

1. Pengertian & Hierarki Sistem Bilangan Real

Bilangan Real (dilambangkan dengan $\mathbb{R}$) adalah himpunan seluruh bilangan yang dapat direpresentasikan sebagai titik pada garis bilangan yang kontinu (tanpa celah). Himpunan bilangan real merupakan gabungan dari dua himpunan yang saling lepas, yaitu Bilangan Rasional ($\mathbb{Q}$) dan Bilangan Irasional ($\mathbb{I}$ atau $\mathbb{R} \setminus \mathbb{Q}$): $$\mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$

Berikut adalah rincian sub-himpunan di dalam sistem bilangan real:

  • Bilangan Asli ($\mathbb{N}$): Bilangan bulat positif untuk membilang: $\{1, 2, 3, 4, \dots\}$.
  • Bilangan Cacah ($\mathbb{W}$): Gabungan bilangan asli dengan angka nol: $\{0, 1, 2, 3, \dots\}$.
  • Bilangan Bulat ($\mathbb{Z}$): Mencakup bilangan bulat negatif, nol, dan bilangan bulat positif: $\{\dots, -2, -1, 0, 1, 2, \dots\}$.
  • Bilangan Rasional ($\mathbb{Q}$): Bilangan yang dapat dinyatakan dalam bentuk pecahan $\frac{p}{q}$ dengan $p, q \in \mathbb{Z}$ dan $q \neq 0$.
  • Bilangan Irasional ($\mathbb{R} \setminus \mathbb{Q}$): Bilangan real yang tidak dapat dinyatakan sebagai perbandingan dua bilangan bulat $\frac{p}{q}$ (contoh: $\sqrt{2}, \sqrt{3}, \pi, e, \log_2 3$).

2. Ciri Desimal: Rasional vs Irasional

Ketika suatu bilangan real diubah ke dalam bentuk desimal, kita dapat membedakan bilangan rasional dan irasional dari pola angka di belakang komanya:

Jenis Bilangan Ciri Bentuk Desimal Contoh
Bilangan Rasional ($\mathbb{Q}$) Desimalnya berhenti (terbatas) ATAU tak hingga tetapi berulang secara periodik. $\frac{3}{8} = 0{,}375$
$\frac{2}{11} = 0{,}181818\dots = 0{,}\overline{18}$
Bilangan Irasional ($\mathbb{R} \setminus \mathbb{Q}$) Desimalnya tak hingga dan TIDAK berulang (tidak memiliki pola periodik). $\sqrt{2} = 1{,}41421356\dots$
$\pi = 3{,}14159265\dots$
💡 Trik Cepat Mengubah Desimal Berulang ke Pecahan $\frac{p}{q}$:
Banyaknya angka yang berulang di belakang koma menentukan banyaknya angka $9$ pada penyebut:
• $0{,}\overline{a} = 0{,}aaa\dots = \frac{a}{9}$     • $0{,}\overline{ab} = 0{,}abab\dots = \frac{ab}{99}$     • $0{,}\overline{abc} = \frac{abc}{999}$
Contoh Campuran: $x = 0{,}2\overline{35} \implies 1000x - 10x = 235{,}\overline{35} - 2{,}\overline{35} \implies 990x = 233 \implies x = \frac{233}{990}$.

3. Garis Bilangan Real & Konstruksi Geometri $\sqrt{2}$

Sifat Kelengkapan (Completeness) & Kerapatan (Density):
Di antara sembarang dua bilangan real yang berbeda $a < b$, selalu terdapat tak hingga banyaknya bilangan rasional maupun bilangan irasional (contohnya rata-rata aritmetika $\frac{a+b}{2}$ selalu berada tepat di tengah $a$ dan $b$).

Meskipun $\sqrt{2} \approx 1{,}414\dots$ memiliki desimal tak berujung, posisinya pada garis bilangan real dapat ditentukan secara eksak menggunakan geometri:

  1. Buat segitiga siku-siku dengan alas $1$ satuan (dari $0$ ke $1$) dan tinggi $1$ satuan.
  2. Berdasarkan Teorema Pythagoras, panjang sisi miringnya adalah $\sqrt{1^2 + 1^2} = \sqrt{2}$.
  3. Jangkakan busur lingkaran berpusat di $0$ dari ujung sisi miring hingga memotong sumbu positif tepat di titik $\sqrt{2}$.

4. Sifat-Sifat Aljabar (Field) dan Urutan Bilangan Real

Untuk setiap bilangan real $a, b, c \in \mathbb{R}$, berlaku aksioma medan (field) dan sifat urutan yang menjadi fondasi seluruh manipulasi persamaan dan pertidaksamaan:

  • Unsur Identitas & Invers:
    • Identitas penjumlahan adalah $0$ ($a + 0 = a$), dan invers penjumlahan (lawan) dari $a$ adalah $-a$ sehingga $a + (-a) = 0$.
    • Identitas perkalian adalah $1$ ($a \cdot 1 = a$), dan invers perkalian (kebalikan) dari $a \neq 0$ adalah $a^{-1} = \frac{1}{a}$ sehingga $a \cdot \frac{1}{a} = 1$.
  • Sifat Trikotomi: Untuk sembarang dua bilangan real $a$ dan $b$, tepat satu dari tiga hubungan berikut pasti berlaku: $$a < b, \quad a = b, \quad \text{atau} \quad a > b$$
  • Sifat Perkalian Pertidaksamaan (Sangat Penting!):
    • Jika $a < b$ dan dikalikan bilangan positif ($c > 0$), tanda pertidaksamaan tetap: $ac < bc$.
    • Jika $a < b$ dan dikalikan bilangan negatif ($c < 0$), tanda pertidaksamaan berbalik arah: $ac > bc$.
  • Sifat Kuadrat Non-Negatif: Untuk setiap $x \in \mathbb{R}$, selalu berlaku $x^2 \ge 0$. Akibatnya, jika $x^2 + y^2 = 0$ untuk $x, y \in \mathbb{R}$, maka satu-satunya kemungkinan adalah $x = 0$ dan $y = 0$.

5. Notasi Selang (Interval) pada Garis Bilangan

Himpunan bagian dari bilangan real yang berupa ruas garis dinyatakan menggunakan notasi selang (interval):

  • Kurung siku [ atau ] menandakan titik ujung termasuk dalam himpunan ($\le$ atau $\ge$), digambarkan dengan bulatan penuh ($\bullet$).
  • Kurung biasa ( atau ) menandakan titik ujung tidak termasuk dalam himpunan ($<$ atau $>$), digambarkan dengan bulatan kosong ($\circ$).
Notasi Interval Notasi Pembentuk Himpunan Keterangan
$(a, b)$ $\{x \in \mathbb{R} \mid a < x < b\}$ Interval terbuka (ujung $a$ dan $b$ tidak ikut).
$[a, b]$ $\{x \in \mathbb{R} \mid a \le x \le b\}$ Interval tertutup (ujung $a$ dan $b$ ikut).
$[a, b)$ $\{x \in \mathbb{R} \mid a \le x < b\}$ Interval setengah terbuka (kanan terbuka).
$[a, \infty)$ $\{x \in \mathbb{R} \mid x \ge a\}$ Interval tak hingga ke kanan (simbol $\pm\infty$ selalu memakai kurung biasa).

6. Nilai Mutlak (Absolute Value) pada Bilangan Real

Secara geometris, nilai mutlak $|x|$ adalah jarak dari titik $x$ ke titik asal $0$ pada garis bilangan real. Secara umum, $|x - y|$ menyatakan jarak antara titik $x$ dan titik $y$. Karena jarak tidak pernah negatif, nilai mutlak didefinisikan secara sepotong-sepotong (piecewise): $$|x| = \begin{cases} x, & \text{jika } x \ge 0 \\ -x, & \text{jika } x < 0 \end{cases}$$

Sifat Penting Akar Kuadrat & Pertidaksamaan Nilai Mutlak:

  1. Hubungan dengan Akar Kuadrat: Untuk setiap $x \in \mathbb{R}$, berlaku: $$\sqrt{x^2} = |x| \quad (\text{BUKAN sekadar } x!)$$ Sebagai contoh, jika $x < 2$, maka $\sqrt{(x - 2)^2} = |x - 2| = -(x - 2) = 2 - x$.
  2. Pertidaksamaan Nilai Mutlak ($a > 0$):
    • $|x| \le a \iff -a \le x \le a$
    • $|x| \ge a \iff x \le -a \quad \text{atau} \quad x \ge a$
  3. Ketaksamaan Segitiga: Untuk setiap $x, y \in \mathbb{R}$, berlaku: $$|x + y| \le |x| + |y| \quad \text{dan} \quad |x - y| \ge \big||x| - |y|\big|$$

Contoh Soal & Pembahasan

No. 1
Jika bilangan desimal berulang $0{,}454545\dots + 0{,}333\dots$ dinyatakan dalam bentuk pecahan paling sederhana $\frac{p}{q}$ dengan $p$ dan $q$ bilangan asli yang saling prima, maka nilai dari $p + q$ adalah ....
  1. $35$
  2. $47$
  3. $59$
  4. $64$
  5. $79$
Penyelesaian:

1. Ubah masing-masing desimal berulang ke dalam bentuk pecahan biasa:

  • $0{,}454545\dots = 0{,}\overline{45} = \frac{45}{99} = \frac{5}{11}$ (dibagi $9$)
  • $0{,}333\dots = 0{,}\overline{3} = \frac{3}{9} = \frac{1}{3}$

2. Jumlahkan kedua pecahan tersebut dengan menyamakan penyebutnya: $$\frac{5}{11} + \frac{1}{3} = \frac{15 + 11}{33} = \frac{26}{33}$$

Karena $\text{FPB}(26, 33) = 1$, maka pecahan $\frac{26}{33}$ sudah paling sederhana dengan $p = 26$ dan $q = 33$. Dengan demikian: $$p + q = 26 + 33 = 59$$

Jadi, nilai dari $p + q$ adalah $59$ (Jawaban C).
No. 2
Diketahui bilangan real $x$ memenuhi $-3 < x < 2$. Bentuk paling sederhana dari $\sqrt{x^2 - 4x + 4} + \sqrt{x^2 + 6x + 9}$ adalah ....
  1. $2x + 1$
  2. $2x - 5$
  3. $-2x - 1$
  4. $1$
  5. $5$
Penyelesaian:

1. Faktorkan bentuk kuadrat di dalam tanda akar, lalu gunakan sifat $\sqrt{A^2} = |A|$: $$\sqrt{(x - 2)^2} + \sqrt{(x + 3)^2} = |x - 2| + |x + 3|$$

2. Analisis tanda dari masing-masing bentuk di dalam nilai mutlak untuk domain $-3 < x < 2$:

  • Karena $x < 2$, maka $x - 2 < 0$ (negatif), sehingga $|x - 2| = -(x - 2) = 2 - x$.
  • Karena $x > -3$, maka $x + 3 > 0$ (positif), sehingga $|x + 3| = x + 3$.

3. Jumlahkan hasilnya: $$|x - 2| + |x + 3| = (2 - x) + (x + 3) = 5$$

Jadi, bentuk paling sederhananya adalah $5$ (Jawaban E).
No. 3
Jika $x$ dan $y$ adalah bilangan real yang memenuhi $-4 \le x \le 3$ dan $-2 \le y \le 5$, maka nilai minimum dari $x^2 - 2y$ adalah ....
  1. $-10$
  2. $-6$
  3. $-1$
  4. $4$
  5. $20$
Penyelesaian:

Agar nilai $x^2 - 2y$ mencapai minimum, maka suku $x^2$ harus dibuat sekecil mungkin dan pengurangnya ($2y$) harus dibuat sebesar mungkin:

1. Batas nilai $x^2$:
Hati-hati! Karena interval $-4 \le x \le 3$ memuat angka $0$, nilai kuadrat terkecil dari bilangan real pada interval tersebut bukanlah $(-4)^2$ atau $3^2$, melainkan $0^2 = 0$ (saat $x = 0$): $$0 \le x^2 \le 16 \implies (x^2)_{\text{min}} = 0$$

2. Batas nilai $2y$:
Dari $-2 \le y \le 5$, diperoleh $-4 \le 2y \le 10$, sehingga nilai maksimum dari $2y$ adalah $10$ (saat $y = 5$).

3. Hitung nilai minimum $x^2 - 2y$: $$(x^2 - 2y)_{\text{min}} = (x^2)_{\text{min}} - (2y)_{\text{maks}} = 0 - 10 = -10$$

Jadi, nilai minimum dari $x^2 - 2y$ adalah $-10$ (Jawaban A).
No. 4
Diketahui $a, b,$ dan $c$ adalah bilangan real yang memenuhi persamaan $a^2 + b^2 + c^2 - 2a + 4b - 6c + 14 = 0$. Nilai dari $a + b + c$ adalah ....
  1. $-2$
  2. $0$
  3. $2$
  4. $4$
  5. $6$
Penyelesaian:

Kelompokkan suku-suku berdasarkan variabelnya dan ubah menjadi bentuk kuadrat sempurna (pecah konstanta $14 = 1 + 4 + 9$): $$(a^2 - 2a + 1) + (b^2 + 4b + 4) + (c^2 - 6c + 9) = 0$$ $$(a - 1)^2 + (b + 2)^2 + (c - 3)^2 = 0$$

Karena $a, b, c \in \mathbb{R}$, setiap bentuk kuadrat selalu bernilai non-negatif: $$(a - 1)^2 \ge 0, \quad (b + 2)^2 \ge 0, \quad (c - 3)^2 \ge 0$$ Jumlah ketiganya bernilai $0$ jika dan hanya jika masing-masing suku bernilai $0$:

  • $a - 1 = 0 \implies a = 1$
  • $b + 2 = 0 \implies b = -2$
  • $c - 3 = 0 \implies c = 3$

Dengan demikian, nilai dari $a + b + c = 1 + (-2) + 3 = 2$.

Jadi, nilai dari $a + b + c$ adalah $2$ (Jawaban C).
