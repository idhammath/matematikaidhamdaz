Berikut adalah soal tingkat ... materi Bilangan Real

Diberikan bilangan real non-negatif \(l, m, n, a,\) dan \(s\) yang memenuhi: \[l + m + n + a + s = 28\] Misalkan \(x = \max\{l + m + n,\; m + n + a,\; n + a + s\}\). Nilai terkecil yang mungkin dari \(x\) adalah ....
  1. 28
  2. 20
  3. 24
  4. 14
  5. 27
LMNAS Ke-28 SMA
Pembahasan:
Perhatikan jumlah dari dua suku di dalam ekspresi maksimum: \[ \begin{aligned} (l + m + n) + (n + a + s) &= (l + m + n + a + s) + n \\ &= 28 + n \end{aligned} \] Karena \(n\) adalah bilangan real non-negatif (\(n \ge 0\)), maka: \[(l + m + n) + (n + a + s) \ge 28\] Berdasarkan sifat nilai maksimum dari dua bilangan real: \[ \max\{l + m + n,\; n + a + s\} \ge \dfrac{(l + m + n) + (n + a + s)}{2} \ge \dfrac{28}{2} = 14 \] Karena \(x = \max\{l + m + n,\; m + n + a,\; n + a + s\} \ge \max\{l + m + n,\; n + a + s\}\), maka haruslah: \[x \ge 14\] Nilai minimum \(x = 14\) dapat dicapai ketika kita memilih: \[n = 0,\quad m = 0,\quad a = 0,\quad l = 14,\quad s = 14\] Pemeriksaan kondisi:
  • \(l + m + n + a + s = 14 + 0 + 0 + 0 + 14 = 28\) (memenuhi)
  • \(l + m + n = 14 + 0 + 0 = 14\)
  • \(m + n + a = 0 + 0 + 0 = 0\)
  • \(n + a + s = 0 + 0 + 14 = 14\)
  • \(x = \max\{14, 0, 14\} = 14\)
Jadi, nilai terkecil yang mungkin dari \(x\) adalah 14.
