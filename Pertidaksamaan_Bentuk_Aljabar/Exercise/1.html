Himpunan penyelesaian pertidaksamaan \(\dfrac4{x-2}\lt\dfrac{x}2\) adalah
  1. \(\{x \mid x \lt -4 \text{ atau } -2 \lt x \lt 2\}\)
  2. \(\{x \mid x \lt -2 \text{ atau } 2 \lt x \lt 4\}\)
  3. \(\{x \mid x \lt -1 \text{ atau } 2 \lt x \lt 4\}\)
  1. \(\{x \mid -2 \lt x \lt 2 \text{ atau } x \gt 4\}\)
  2. \(\{x \mid -4 \lt x \lt -2 \text{ atau } x \gt 2\}\)
Grup WhatsApp
Pembahasan:
\(\begin{aligned} \dfrac4{x-2}&\lt\dfrac{x}2\\[8pt] \dfrac4{x-2}-\dfrac{x}2&\lt0\\[8pt] \dfrac{8-x(x-2)}{2(x-2)}&\lt0\\[8pt] \dfrac{8-x^2+2x}{2(x-2)}&\lt0\\[8pt] \dfrac{-x^2+2x+8}{2(x-2)}&\lt0\\[8pt] \dfrac{x^2-2x-8}{2(x-2)}&\gt0\\[8pt] \dfrac{(x-4)(x+2)}{2(x-2)}&\gt0 \end{aligned}\)

Pembuat nol:
  • \(x - 4 = 0 \iff x = 4\)
  • \(x + 2 = 0 \iff x = -2\)
  • \(x - 2 = 0 \iff x = 2\)
Uji tanda pada garis bilangan menghasilkan interval penyelesaian \(-2 \lt x \lt 2\) atau \(x \gt 4\).
Jadi, \(\text{HP} = \{x \mid -2 \lt x \lt 2 \text{ atau } x \gt 4\}\).

Semua bilangan real \(x\) yang memenuhi \(\dfrac{x^2-3x-4}{x+5}\leq0\) adalah
  1. \(x \lt -5\) atau \(x \ge 4\)
  2. \(x \le -4\) atau \(1 \le x \lt 5\)
  3. \(-4 \le x \le 1\) atau \(x \gt 5\)
  1. \(x \lt -5\) atau \(-1 \le x \le 4\)
  2. \(-5 \lt x \le -1\) atau \(x \ge 4\)
Grup WhatsApp
Pembahasan:
Pembatas:
  • \(x^2 - 3x - 4 = 0 \iff (x + 1)(x - 4) = 0 \iff x = -1 \text{ atau } x = 4\)
  • \(x + 5 = 0 \iff x = -5\) (syarat penyebut \(x \neq -5\))

Dari garis bilangan diperoleh daerah bernilai negatif (\(\le 0\)):
\(x \lt -5\) atau \(-1 \le x \le 4\).
Jadi, \(x \lt -5\) atau \(-1 \le x \le 4\).

Tentukan penyelesaian dari: \[\dfrac{x-5}{x^2+6x+9}\leq0\]
Grup Telegram
Pembahasan:
\(\begin{aligned} \dfrac{x-5}{x^2+6x+9}&\leq0\\[4pt] \dfrac{x-5}{(x+3)^2}&\leq0 \end{aligned}\)

Pembuat nol:
  • \(x - 5 = 0 \iff x = 5\)
  • \(x + 3 = 0 \iff x = -3\) (syarat penyebut \(x \neq -3\))
Karena \((x+3)^2 \gt 0\) untuk semua \(x \neq -3\), tanda pecahan hanya ditentukan oleh pembilang \(x - 5 \le 0 \iff x \le 5\) dengan \(x \neq -3\).

Jadi, \(x \lt -3\) atau \(-3 \lt x \le 5\).

Tentukan penyelesaian dari: \[\dfrac1{x-2}\gt\dfrac2{x+3}\]
Grup Telegram
Pembahasan:
\(\begin{aligned} \dfrac1{x-2}&\gt\dfrac2{x+3}\\[4pt] \dfrac1{x-2}-\dfrac2{x+3}&\gt0\\[4pt] \dfrac{1(x+3)-2(x-2)}{(x-2)(x+3)}&\gt0\\[4pt] \dfrac{x+3-2x+4}{(x-2)(x+3)}&\gt0\\[4pt] \dfrac{-x+7}{(x-2)(x+3)}&\gt0\\[4pt] \dfrac{x-7}{(x-2)(x+3)}&\lt0 \end{aligned}\)

Pembuat nol:
  • \(x - 7 = 0 \iff x = 7\)
  • \(x - 2 = 0 \iff x = 2\)
  • \(x + 3 = 0 \iff x = -3\)
Jadi, \(x \lt -3\) atau \(2 \lt x \lt 7\).

Pembahasan:

Pembuat nol:
  • \(x + 1 = 0 \iff x = -1\)
  • \(x - 10 = 0 \iff x = 10\)
  • \(x - 5 = 0 \iff x = 5\) (syarat penyebut \(x \neq 5\))
Jadi, \(x \le -1\) atau \(5 \lt x \le 10\).

Grup Telegram
Pembahasan:
\(\begin{aligned} \dfrac{8-2x}{2x}&\geq0\\[4pt] \dfrac{2x-8}{2x}&\leq0\\[4pt] \dfrac{x-4}x&\leq0 \end{aligned}\)

Pembuat nol:
  • \(x - 4 = 0 \iff x = 4\)
  • \(x = 0\) (syarat penyebut \(x \neq 0\))

Nilai \(x\) yang memenuhi \(\dfrac{2x-1}{3x-5}\geq1\) adalah
Grup Telegram
Pembahasan:
\(\begin{aligned} \dfrac{2x-1}{3x-5}&\geq1\\[4pt] \dfrac{2x-1}{3x-5}-1&\geq0\\[4pt] \dfrac{2x-1-(3x-5)}{3x-5}&\geq0\\[4pt] \dfrac{2x-1-3x+5}{3x-5}&\geq0\\[4pt] \dfrac{-x+4}{3x-5}&\geq0\\[4pt] \dfrac{x-4}{3x-5}&\leq0 \end{aligned}\)

Pembuat nol:
  • \(x - 4 = 0 \iff x = 4\)
  • \(3x - 5 = 0 \iff x = \dfrac53\) (syarat penyebut \(x \neq \dfrac53\))
Jadi, nilai \(x\) yang memenuhi \(\dfrac{2x-1}{3x-5}\geq1\) adalah \(\dfrac53\lt x\leq4\).
